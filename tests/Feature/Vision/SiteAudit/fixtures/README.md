# HTML fixtures SP-E8-01B

These files are synthetic, static public-site samples for deterministic HTTP-fake tests. The fictional product price, identifiers, company, dimensions and delivery conditions exercise extraction only. They are not application billing, tariff or plan values and are never seeded into runtime commercial configuration.

`home.html` and `product.html` preserve source-page attribution for JSON-LD and visible text. The sitemap, robots and llms files exercise separate auxiliary requests. No fixture URL is requested from a real network; tests replace DNS and HTTP explicitly. Synthetic fixtures prove extraction/scoring behavior, not real LLM-run equivalence.
