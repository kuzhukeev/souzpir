# Manrope

Unmodified local font files copied from the supplied `eyon-pilot/public/brand` donor.
Normal variable face, weight range 200–800. CSS unicode ranges retain the donor's
Cyrillic/Latin split; missing glyphs use the system sans-serif fallback.
