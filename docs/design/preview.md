# Первые макеты: S-0.1 и S-1.2

Это отдельный local/testing preview для согласования внешнего вида. Авторизация и бизнес-модули не реализованы этим экраном. Root /preview остаётся техническим smoke; страницы макетов — /preview/login и /preview/attention.

Панель «Макеты · демонстрационные данные» добавлена для честного обозначения режима и управления состояниями. На мобильном её подписи компактнее. Она не является production-навигацией.

## Реализация

React + Tailwind 4 utilities; общие цвета, радиусы, Manrope и brand presets из F01. Никаких растровых нарезок: eye/wordmark, pyro sunburst, empty check, декоративные дуги и loading skeleton созданы SVG/CSS/компонентами. Использован lucide-react для линейных интерфейсных иконок.

Сохраняется исходная структура меню: Главная; Модули — Видение/Продавец; Кабинет — Компания и бренды/Команда/Тариф и оплата/Интеграции/Журнал/Настройки/Помощь. Активная Главная имеет полную зелёную заливку как PNG 13. Нет выбора нескольких организаций или удаления организации.

Темы neutral/pyro/confectionery меняют брендовые акценты. Семантика зелёного действия/nav и accessible ink остаётся общей, согласно F01. Три темы и выбор состояния доступны в панели. Query parameters state/theme содержат только allowlisted presentation values; пароль, код MFA и черновики туда не записываются. History state Inertia сохраняется при изменении адреса.

## Состояния и локальные действия

Вход: default, invalid, locked, mfa, loading. Проверка заполнения/формата локальная; eye toggle и remember работают в памяти. Шестизначный MFA input демонстрирует форму и честно сообщает об отсутствии проверки. Submit не выполняет вход, не отправляет запрос, очищает пароль. Переключение состояния сбрасывает sensitive input. Forgotten password/registration/legal links показывают объяснение будущей функции.

Кабинет: full, empty, loading, error. Модуль, важность, локальный/глобальный поиск работают на одном демонстрационном массиве; reset очищает обе строки поиска. Контекстное «Отложить на 7 дней» скрывает событие в памяти страницы, не планирует реальную доставку/напоминание. «Открыть» показывает drawer с объяснением и локальным черновиком заметки. Черновик существует только в React state; обновление страницы его удаляет. «Сбросить демо» восстанавливает данные.

Все числа, включая 80% и 5 дней, иллюстративны и не являются утверждёнными тарифами/лимитами. Будущие разделы не показывают ложного успеха. Нет POST/PUT/PATCH/DELETE от preview interactions, localStorage/sessionStorage не используются.

## Доступность и проверка

Нативные labels/dialog и собственный select-only combobox с listbox, активной опцией, стрелками/Home/End/Enter/Escape/Tab и поиском по буквам; title landmarks, skip link кабинета, aria feedback, явные disabled/loading состояния, reduced-motion skeleton. Dialog focus удерживается нативно, Escape возвращает его к opener. Context/header menu dismissal возвращает focus, удаление строки передаёт его следующему action trigger или заголовку. Мобильные фильтры сохраняют выбранные значения в двух колонках и отдельную строку поиска.

Playwright проверяет 3 themes × 3 widths × 2 screens, семь дополнительных состояний, browser errors, horizontal overflow, axe WCAG 2A/AA/2.1AA, локальные interactions/storage/network, drawer/menu focus и ширину 1920. Screenshots сохраняются локально в .local/screenshots/preview. Критические отличия от плоских оригиналов: нормализация размеров, доступные цвета/границы, мобильная перестройка и служебная preview-панель. Это честная визуальная реконструкция, не pixel-perfect обещание.

После merge интегратор проверяет совмещённый main, сохраняет финальные screenshots и показывает пользователю. Следующие бизнес-задачи не запускать до новой команды пользователя.

Уточнения первого просмотра: основной текст и элементы управления 14 px, подпись бренда и счётчики не меньше 13 px. Подпись бренда переносится на следующую строку; подменю состоит из синих иконок и подписей с тонкой направляющей без общей подложки. В компактной панели пункты представлены иконками с доступными подписями. У доступных интерактивных элементов cursor: pointer. Высота оболочки растёт через flex внутри min-height: 100dvh, без добавления фиксированной высоты панели к высоте окна.
