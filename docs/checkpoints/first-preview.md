# Первый просмотр — обязательная остановка

31.10.2026 пользователь после разрешения разработки уточнил: «когда база будет поднята и будут сверстаны первые макеты, остановись, дай мне сначала посмотреть, что получилось и после продолжим, когда скажу».

Разрешённый текущий набор: SP-C-01, SP-T-01 (уже запущенные эталоны), SP-E0-01 (Laravel/React и окружение), SP-E0-02 (организация, бренды, участники), SP-F-01 (темы), SP-P-01 (первые макеты). Остальные задачи остаются в очереди до следующей команды.

Условия показа:

- Отдельная PostgreSQL БД проекта, миграции и изолированная тестовая БД; локальные доступы только в игнорируемых настройках.
- Laravel 13 / PHP 8.4 и React 19 / Inertia 3 обслуживаются на souzpir.local из public.
- Экран входа S-0.1 со всеми состояниями из папки 1 и оболочка S-1.2 «Требует вашего действия» с заполненным/пустым состоянием из папки 13. Проверить 1440/1024/390 и три темы.
- Переключатели, поиск, фильтры, меню и мобильная навигация работают для предпросмотра. Форма входа пока демонстрационная и не аутентифицирует. Не сохранять введённые пароли, не отправлять их внешним сервисам.
- Это проверка внешнего вида до полной реализации авторизации и бизнес-модулей. Демонстрационный режим явно обозначен; будущие действия не выдают фиктивного успеха.
- Пройти предусмотренные task checks, сохранить коммиты и результаты, интегрировать в main и отправить в приватный GitHub.

После достижения точки: выключить souzpir в tasks.local, проверить отсутствие активных исполнителей, дать пользователю ссылки и перечень ограничений. Не брать новых задач и не возобновлять очередь без его команды.

Весь корпус из 308 исходных изображений остаётся источником для последующих задач, включая состояния. WebP-копии не считаются отдельными макетами. Отменённые пользователем функции не восстанавливаются из изображений.

Уточнение пользователя: изображения — плоские визуальные эталоны, без слоёв. Элементы, SVG-иконки/логотипы и анимированные skeleton состояния создаются кодом; интерфейс не нарезается из картинок.
