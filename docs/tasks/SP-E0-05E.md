# SP-E0-05E · Просмотр неопределённых расходов ИИ

Владелец должен видеть вызовы ИИ с неопределённым результатом, не считая их стоимость подтверждённой. Серверный список `GET /ai/recovery/calls` уже существует и сам проверяет владельца, права, активную сессию и бренд. Это отдельный срез существующей SP-E0-05B, без операции восстановления расхода.

Создать доступный владельцу экран кабинета, читающий существующий реальный endpoint, и понятный переход на него из раздела тарифа. Показывать только данные, которые endpoint уже разрешает; нейтрально объяснить, что состояние и резерв не подтверждают итоговую стоимость. Не выводить технические секреты, не добавлять действий восстановления, фиктивных сумм или внешних запросов.

При смене бренда, отзыве сессии или устаревшем ответе старый список не должен оставаться видимым. Обработать загрузку, пустое состояние, отказ, повтор и переход по страницам. Проверить права владельца, другого участника и изоляцию брендов на настоящем HTTP-пути, а также 1440/1024/390 и клавиатуру. Реальные вызовы ИИ запрещены. Отдельный worktree, атомарный claim, результат в `docs/results/SP-E0-05E.md`, затем submit. Общий интерфейс существующего endpoint и учёт ИИ не менять.
