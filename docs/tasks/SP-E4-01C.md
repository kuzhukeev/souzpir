# SP-E4-01C · Действия со входящими предложениями знаний

**Размер:** 1–3 часа; функциональный остаток, не сверх ТЗ.

**Зачем:** Backlog E4-01, экран D-4.2: неизвестный вопрос, неверный факт и предложение из доклада можно применить к черновику.

**Часть чего:** SP-E4-01. После B сравнения релизов эта C закрывает остаток D-4.2; новых продолжений E4-01 не будет.

Зависимости: SP-E4-01B, SP-E4-02, SP-E4-03, SP-E4-08.

Scope: `app/Seller/Knowledge/Releases/`, `resources/js/pages/Seller/Knowledge/Releases/`, `routes/features/E4-01.php`, `tests/Feature/Seller/Knowledge/Releases/`, `tests/Browser/E4-01/`, `docs/results/SP-E4-01C.md`. Сгенерированные типы разрешены общим правилом.

Использовать существующие API черновика фактов, условий и образцов; не менять чужие модули. Проверить версию черновика, права и изоляцию бренда, пометить обработанное предложение.

Приёмка: HTTP/feature принятие и отказ, 409 при устаревшей версии, экран D-4.2. Общий экран релизов даёт ссылку на редактор образцов речи D-4.8. Итоговый отчёт до 30 строк.
