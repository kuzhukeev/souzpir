# SP-E0-07B · Постоянные процессы на изолированной очереди

Продолжение SP-E0-07: проверить запуск, работу и остановку постоянных worker и scheduler на отдельной тестовой очереди с синтетическими заданиями и fake-доставкой. Эти проверки процессов выполняются только на Linux, в CI; на Windows тесты должны явно пропускаться и не запускать процессы. Проверить идемпотентность выбранного тестового расписания, если оно входит в законченный срез. Рабочие процессы и реальные отправки не включать.

Общее исправление безопасных логов и bootstrap вынесено в SP-E0-07C; в этой задаче их не изменять и не считать проверенными. Работа 1–3 часа, отдельный worktree и claim; отчёт и submit по AGENTS.md.
