# SP-UI-09 · Сброс фильтров команды

На экране команды есть три фильтра (роль, бренд, статус), но нет одного действия возврата к списку всех участников. Добавить кнопку «Сбросить фильтры», видимую при любом активном фильтре; использовать существующий changeFilters для возврата всех значений в all и первой страницы. Сохранить права и текущие состояния загрузки и ошибки. Проверить клавиатуру, 390/1440 и пустую выдачу. Для браузерного fixture использовать уже запускаемый CI Vite на 127.0.0.1:5237; новый порт без запуска в CI не заводить.

Работа 1–3 часа. Локально запустить lint и целевые проверки, приложить скриншот 1440 при видимом изменении; отчёт и submit по AGENTS.md.
