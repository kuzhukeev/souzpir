# SP-R-03B · Удаление копий проверки тестовой БД

Продолжение SP-R-03. Перевести дублирующие проверки в `tests/Feature/` на опорный helper из TestCase. Для race worker-скриптов и browser fixtures использовать один общий helper вместо отдельных копий; сохранить все прежние ограничения конкретных запусков. Выполнять по подмодулям законченными срезами по 1–3 часа, сохраняя число существующих тестов до и после каждого среза. Golden fixtures не менять.

Тесты только в изолированных БД; race-группа по правилам проекта отдельно. Перед началом и в отчёте указать число тестов своего затронутого набора, результат до и после, а найденное попутно — в «Техдолг». Claim, worktree, отчёт, submit и CI по AGENTS.md.
