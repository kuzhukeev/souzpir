# SP-R-09 · Карточка вызова ИИ в биллинге

На странице неподтверждённых вызовов биллинга выделить локальный компонент карточки вызова из списка, сохранив статус, дату, порядок и доступность. Оставить API и пагинацию прежними. Перед началом и в отчёте указать число существующих тестов модуля до и после: оно должно совпасть, и все тесты должны быть зелёными. Существующие тесты не менять, кроме импортов и имён классов; golden fixtures не трогать. Попутное записать строкой в «Техдолг». Поведение и внешний вид не менять.

Работа 1–3 часа. Локально запустить lint и целевые проверки, приложить скриншот 1440 при видимом изменении; отчёт и submit по AGENTS.md.
