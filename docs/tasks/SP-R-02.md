# SP-R-02 · Support: штатная работа с Request

Эпик R. Убрать ReflectionProperty(Request::class, convertedFiles) из SupportController::store средствами Laravel, сохранив очистку всех ссылок на входящие файлы, запрос и секреты. Существующие проверки и их число не менять; убедиться, что очищается и внутренний кэш преобразованных файлов, а не только files bag. Если штатный API не позволяет сохранить это поведение, не ослаблять очистку: зафиксировать точный блокер и остаток.

Перед началом посчитать и запустить существующие тесты модуля, записать число и результат; после работы повторить тот же набор: число и зелёный результат должны совпасть. Существующие тесты не менять, кроме импортов и имён классов; golden fixtures не менять. Все попутные находки одной строкой в «Техдолг» отчёта. Отдельный worktree, claim, commit, docs/results, submit, CI и review по AGENTS.md. Время: 1–3 часа.

## Уточнение 08.11.2026 (планировщик, по причине возврата)
- Блокер подтверждён прошлым запуском: у Laravel Request нет публичного API для сброса `convertedFiles` существующего экземпляра. Допустимый результат: Reflection оставить (очистку не ослаблять), вынести сброс в небольшой приватный метод с комментарием, почему нужен Reflection; если и это не даёт пользы — сдать только `docs/results/SP-R-02.md` с точным блокером (класс, метод, версия Laravel) и числом/результатом тестов модуля. Возврат в очередь по этой причине больше не нужен.
