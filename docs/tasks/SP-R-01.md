# SP-R-01 · Общий безопасный контекст запроса

Эпик R. Централизовать проверку безопасного контекста и прямого loopback для перечисленных текущих потребителей. Сохранить все различия поведения, включая localhost только там, где он уже разрешён в testing; имя локального хоста брать из конфигурации с совместимым текущим значением. Добавить отдельно запрошенный unit-тест. Существующие тесты неизменны; сравнивать их число отдельно от нового теста. Изменять только явные вызовы и минимальную конфигурацию; не начинать при занятом пересекающемся модуле.

Перед началом посчитать и запустить существующие тесты модуля, записать число и результат; после работы повторить тот же набор: число и зелёный результат должны совпасть. Существующие тесты не менять, кроме импортов и имён классов; golden fixtures не менять. Все попутные находки одной строкой в «Техдолг» отчёта. Отдельный worktree, claim, commit, docs/results, submit, CI и review по AGENTS.md. Время: 1–3 часа.
