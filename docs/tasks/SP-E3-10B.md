# SP-E3-10B · Отрасль бренда в остальных стадиях продавца

**Зачем:** решение владельца от 02.11.2026: второй бренд не должен получать чужую отрасль, город и компанию.
**Часть чего:** незавершённая часть SP-E3-10 — пять v1-стадий и выбор версий prompt sets.
**Зависимости:** SP-E3-10, SP-E3-03.

Убрать пиротехнику, Москву и компанию прототипа из остальных стадий для других брендов: использовать данные persona/policy/facts текущего бренда и версионированный per-brand prompt set. Дополнить загрузчики и seeder, сохраняя неизменными исходную v1-версию и golden-фикстуры прототипа. Живые вызовы запрещены.

Приёмка: импортированные знания «Союз Пир» сохраняют golden-ответы всех стадий; бренд другой отрасли и города не получает чужих отраслевых или московских формулировок ни в одной стадии. Проверить изоляцию брендов, отсутствующие знания и fake-LLM.
