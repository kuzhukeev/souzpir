**Часть чего:** остаток SP-E4-05D, `docs/results/SP-E4-05D.md`.

## Приёмка
- Выполнить интеграционную проверку защищённого Guard с непривилегированной ролью PostgreSQL: настоящий первый ход записывает срабатывания опубликованных правил только своего бренда, повторная проверка не удваивает счётчик.
