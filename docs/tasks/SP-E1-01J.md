# SP-E1-01J · Регистрация: поле кода только при заданном коде

**Зачем:** приёмка экрана S-0.2 после повторного аудита 08.11.2026 (последние частичные экраны).
**Зависимости:** SP-E1-01I.

## Приёмка
- S-0.2: если features.E1-01.defaults.bootstrap_token_hash пуст — поля «Код создания кабинета» и подсказки про код на странице нет, сервер код не требует и не проверяет; форма совпадает с макетом [2] журнала docs/sources/02b_mockup_journal.md.
- S-0.2: если хэш задан — поведение как сейчас: поле видно, код обязателен, сверка sha256 через hash_equals, длина 32–256, ошибка по-русски без раскрытия причины.
- Правило одного владельца не меняется: регистрация отказывает, если у организации уже есть владелец (в обоих режимах); гонка двух одновременных регистраций без кода даёт ровно одного владельца.
- Страница получает только булев признак «нужен код», хэш и значение кода в props, логи и ответы не попадают.
- Feature-тест на оба режима и гонку; browser-тест S-0.2 без кода на 1440/390. Живые внешние вызовы выключены. Запись в docs/decisions-pending.md: на проде код задаётся при развёртывании (чек-лист запуска).

Scope: `app/Shell/Auth/Http/RegisterController.php`, `resources/js/pages/Shell/Auth/Register.tsx`, `config/features/E1-01.php`, `tests/Feature/Shell/Auth/RegisterBootstrapE101JTest.php`, `tests/Browser/E1-01J/`, `docs/results/SP-E1-01J.md`.
