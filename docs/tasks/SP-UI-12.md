# SP-UI-12 · Прямые ссылки на вкладки бренда

В настройках бренда вкладки сейчас живут только в памяти: обновление страницы возвращает «Основное». Сохранять выбранную вкладку в query-параметре `tab`, открывать корректную вкладку по прямой ссылке и при Back/Forward, неизвестное значение вести к «Основное». Данные форм, серверные маршруты и другие страницы не менять. Проверить клавиатуру, 390 и две вкладки. Для браузерного fixture использовать уже запускаемый CI Vite на 127.0.0.1:5237; новый порт без запуска в CI не заводить.

Работа 1–3 часа. Локально запустить lint и целевые проверки, приложить скриншот 1440 при видимом изменении; отчёт и submit по AGENTS.md.
