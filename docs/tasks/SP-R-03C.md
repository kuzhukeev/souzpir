# SP-R-03C · Проверки БД остальных тестовых модулей

После SP-R-03B переносить оставшиеся копии проверки из `tests/Feature/`, race worker-скриптов и browser fixtures на общий helper TestCase. Каждый законченный срез ограничить одним тестовым модулем на 1–3 часа; следующий модуль выносить в отдельную карточку до отметки done. Сохранять специфичные ограничения запуска и поведение, golden fixtures не менять.

Перед началом и в отчёте указать число существующих тестов затронутого модуля и результат до и после; число совпадает, все зелёные. Использовать только изолированные БД. Claim, worktree, отчёт, submit и CI по AGENTS.md.
