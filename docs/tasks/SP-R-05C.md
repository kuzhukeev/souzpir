# SP-R-05C · Кабинет: общие UI-компоненты

Эпик R. Вынести подтверждённые повторяющиеся Tailwind-константы в общие UI-компоненты кабинета без изменения поведения; применять только к согласованному минимальному срезу. Не затрагивать занятые feature-модули.

Перед началом посчитать и запустить существующие тесты модуля, записать число и результат; после работы повторить тот же набор: число и зелёный результат должны совпасть. Существующие тесты не менять, кроме импортов и имён классов; golden fixtures не менять. Все попутные находки одной строкой в «Техдолг» отчёта. Отдельный worktree, claim, commit, docs/results, submit, CI и review по AGENTS.md. Время: 1–3 часа.
