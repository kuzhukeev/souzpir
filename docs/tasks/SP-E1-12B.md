# SP-E1-12B · Устаревшие заглушки, битая ссылка меню и статус сервиса

**Зачем:** решение владельца от 03.11.2026 закрыть незапланированные расхождения с макетами по итогам аудита 160 экранов; экраны S-8.3, D-4.1, D-11.1, D-11.2, D-5.1.
**Часть чего:** дефекты из аудита 160 экранов по макетам: тексты и ссылки, которые противоречат уже сданному коду.
**Зависимости:** нет.

- Пункт меню «Сценарий» (resources/js/components/navigation/navigation.json, path `/seller/scenario/fields`) ведёт на несуществующий маршрут. Он должен открывать существующую страницу полей карточки клиента D-5.1, либо пункт нужно убрать. Ни один пункт меню Seller не отдаёт 404; это проверяет тест.
- Releases/Index.tsx (D-4.1, журнал [49]): удалить устаревший текст «Редактирование условий и образцов будет подключено отдельно.»: экраны условий и образцов уже есть. Вместо него дать ссылки на D-4.5 и D-4.8.
- Settings/Limits/Index.tsx: метки «Режим работы · Скоро», «Распределение · Скоро» и «Уведомления · Скоро» устарели, потому что страницы D-11.1/D-11.2 уже сданы (журнал [76], [77]). Заменить их ссылками на действующие страницы; «Скоро» оставить только для реально отсутствующего.
- S-8.3 (журнал [36]): StatusQuery отдаёт демонстрационные данные, поэтому на странице нужен бейдж «Демонстрационные данные», как на макете. Реальные компоненты (cabinet, database, cooldown провайдеров) помечаются отдельно от демонстрационных. Блок «Инциденты за 30 дней» и состояния skeleton / нет данных / ERR_LOAD соответствуют макету.
- Каждый пункт покрыт Feature- или Browser-тестом; данные только текущего бренда, проверены права ролей; состояния пусто / загрузка / ошибка как на макете; в отчёте скриншоты каждого экрана рядом с макетом.
- Без живых и платных внешних вызовов без разрешения владельца; если пункт макета противоречит ТЗ или требует решения владельца, исполнитель не выдумывает, а записывает вопрос в docs/decisions-pending.md и делает остальное.

Scope: `app/Shell/Support/StatusQuery.php`, `resources/js/pages/Shell/Support/Status.tsx`, `resources/js/pages/Seller/Knowledge/Releases/Index.tsx`, `resources/js/pages/Seller/Settings/Limits/Index.tsx`, `resources/js/components/navigation/navigation.json`, `tests/Feature/Shell/Support/`, `tests/Browser/E1-12B/`, `docs/results/SP-E1-12B.md`.
