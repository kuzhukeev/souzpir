# SP-E9-02D · Продолжение переноса подготовленной копии

Продолжение SP-E9-02C. Текущий импорт в отдельную тестовую PostgreSQL переносит только имена организации и брендов и привязывает заранее созданного владельца. Добавить согласованные поля и членство владельца из подготовленной копии, расширить снимок batch и безопасный откат. Поля брать из существующих контрактов и схемы; неизвестные данные не выдумывать. Проверить повтор, конфликт изменённых записей, внешние ключи и изоляцию.

Рабочую БД и реальные внешние сервисы не использовать. Локальные тесты — только отдельная тестовая БД и синтетическая SQLite-копия. Работа 1–3 часа: сдать законченный безопасный срез, а оставшийся перенос описать для следующей карточки; не объявлять полный импорт готовым до покрытия всего формата. Claim, worktree, отчёт, submit и CI по AGENTS.md.
