# SP-UI-02 · Период использования в тарифе

На `/billing/usage` поле «С» можно поставить позже «По» и отправить бессмысленный диапазон. Показать понятную ошибку рядом с формой до запроса, сохранить введённые даты и возможность исправить их. Корректный диапазон, загрузка, пустое состояние и серверная ошибка продолжают работать. Проверить клавиатуру и ширину 390; не менять тарифные значения, API и другие модули. Локально запустить lint и целевую проверку формы. Работа 1–3 часа, отчёт и submit по AGENTS.md.
