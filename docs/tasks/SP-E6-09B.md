# SP-E6-09B · Настройка и доставка CRM-вебхука

Не включать реальные отправки. После готовности общей доставки добавить ссылку на `/seller/integrations/crm` в каталог интеграций; общий файл каталога изменять только в рамках указанного scope и после освобождения владельца. Если весь путь не помещается в 1–3 часа, сдать законченный безопасный срез, а остаток описать в отчёте. Отдельный worktree, claim, тесты и submit по AGENTS.md.
