# SP-CI-06 · Довести PHP CI до шести минут

**Сверх ТЗ: прямое поручение владельца от 2026-11-02, пункт A2. Размер:** 1–3 часа; код приложения не менять.

**Зачем:** Цель A2 — самый долгий php-tests job около 6 минут. SP-CI-04 дала 6:27 в ветке, но зелёный main #471 занял 8:21 на CoreTurnsA.

**Часть чего:** SP-CI-04, повторная балансировка по измеренному main. После этой карточки продолжений CI-балансировки не планируется.

Зависимости: SP-CI-04.

Scope: `phpunit.xml`, `.github/workflows/ci.yml`, `docs/results/SP-CI-06.md`. Файлы приложения, golden fixtures и политика concurrency main вне scope.

Объединить лёгкий Core с Shell и распределить FirstTurnStateTest на три стабильные части по локальному JUnit-профилю. Каждый тестовый файл остаётся в одном suite, каждый метод тяжёлого класса запускается в одном job; новые методы распределяются автоматически.

Приёмка: coverage guard зелёный, полная branch CI зелёная; замерить самый долгий php-tests job и весь прогон в branch и main. Не менять число проверок.
