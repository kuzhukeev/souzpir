# SP-UI-01 · История действий «Видения» без подмены текущими

На `/vision/actions/history` пустая история сейчас подменяется текущими действиями (`history.length ? history : actions`). Убрать подмену: история показывает только завершённые исторические записи и честное пустое состояние. Текущие действия остаются на своём экране. Проверить 390/1024/1440, клавиатуру и три темы, приложить скриншот пустой истории. Изменять только страницу «Сайт/Действия» и её узкий browser-тест; не менять API, хранилище и другие модули. Локально запустить lint и целевой тест. Работа 1–3 часа, отчёт и submit по AGENTS.md.
