# SP-UI-07 · Состояния переключателей модулей бренда

На странице модулей заблокированный переключатель не объясняет причину недоступности. Показывать рядом краткую причину для приостановленного бренда или недоступного по тарифу модуля, не меняя доступ и серверную логику. Проверить клавиатуру, 390/1024/1440 и три темы.

Работа 1–3 часа. Только указанный модуль и собственные тесты; локально запустить lint и целевые проверки, приложить 1 скриншот 1440, сдать отчёт и submit по AGENTS.md.
