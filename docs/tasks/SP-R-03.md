# SP-R-03 · Одна проверка тестовой БД: опорный helper

Область этой карточки — только `tests/TestCase.php`, `tests/Support/` и адресный `tests/Feature/Support/IsolatedDatabaseMigrationsTest.php`. Не менять feature-тесты других модулей, worker-скрипты, browser fixtures и golden fixtures: их перенос — SP-R-03B.

Перед началом записать число и результат тестов модуля Support; после работы тот же набор должен сохранить число существующих тестов и пройти. Поведение не менять. Тесты править только для переноса существующей проверки и импортов. Отдельная тестовая БД, claim, worktree, отчёт до 30 строк, submit и CI по AGENTS.md. Время 1–3 часа.
