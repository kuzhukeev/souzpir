# SP-R-03 · Тестовая инфраструктура: единая проверка БД

Эпик R. Оставить единственную проверку безопасной изолированной БД в TestCase, вспомогательные классы делегируют ей. Для race worker-скриптов и browser-fixture — общий helper; сохранять все необходимые ограничения и особенности запуска. Править тестовые файлы только для переноса существующих проверок и импортов, не менять количество, поведение и golden fixtures. Тестировать только в отдельных тестовых БД.

Перед началом посчитать и запустить существующие тесты модуля, записать число и результат; после работы повторить тот же набор: число и зелёный результат должны совпасть. Существующие тесты не менять, кроме импортов и имён классов; golden fixtures не менять. Все попутные находки одной строкой в «Техдолг» отчёта. Отдельный worktree, claim, commit, docs/results, submit, CI и review по AGENTS.md. Время: 1–3 часа.
