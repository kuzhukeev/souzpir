# SP-E1-11E · Срок доступности экспортов

**Зачем:** привести срок новых экспортов данных к подтверждённому владельцем сроку 30 дней.
**Часть чего:** остаток SP-E1-11D, `docs/results/SP-E1-11D.md`.
**Зависимости:** дождаться слияния SP-E1-11D.

## Приёмка
- Установить срок по умолчанию для новых экспортов 30 дней в конфигурации и серверном запасном значении; сохранить существующую возможность настройки окружением.
- Не менять сроки уже созданных архивов и не добавлять новую автоматическую очистку. Экран продолжает показывать фактический срок каждого архива.
- Проверить срок нового экспорта, существующие архивы, права и изоляцию брендов; без живых вызовов.

Scope: `config/features/E1-11.php`, `app/Shell/Data/`, `tests/Feature/Shell/Data/`, `tests/Feature/Owner/E1-11E/`, `docs/results/SP-E1-11E.md`.
