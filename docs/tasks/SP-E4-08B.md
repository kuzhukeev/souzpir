# SP-E4-08B · Плохие образцы и добавление из диалога

**Зачем:** D-4.8, макет 56: пользователь должен отмечать неподходящие ответы и добавлять реплику менеджера в образцы речи из своего диалога.

**Часть чего:** SP-E4-08 дала редактор положительных образцов и предпросмотр. Здесь остаются bad examples и «Добавить из диалога»; после B остаётся только проверка попадания образца в промпт песочницы (SP-E4-08C).

Размер 1–3 часа. Зависимости: SP-E4-08, SP-E5-04B. Scope: `app/Seller/Knowledge/Fewshot/`, `resources/js/pages/Seller/Knowledge/Fewshot/`, `routes/features/E4-08.php`, `tests/Feature/Seller/Knowledge/Fewshot/`, `tests/Browser/E4-08/`, `docs/results/SP-E4-08B.md`. Только свои организация/бренд и доступные диалоги; чужой модуль диалогов читать через существующий API, не менять. Проверить фильтр, отрицательный образец, права, ошибку и два размера экрана. Без живого LLM.
