# SP-E0-05G · Подтверждённая стоимость AI-сверки оператору

**Зачем:** решение владельца от 06.11.2026.
**Часть чего:** остаток SP-E0-05F, docs/results/SP-E0-05F.md.
**Зависимости:** SP-E0-05F.

## Приёмка
- Только оператору внутреннего экрана сверки с платформенным флагом показывать подтверждённую провайдером сумму USD; клиенту USD нигде не показывать. Неподтверждённую стоимость не выдумывать, коэффициент пересчёта в тарифные единицы не задавать.
- Проверить права, изоляцию брендов, ошибочные и пустые состояния; только fake внешние вызовы.

Scope: `app/Ai/Recovery/`, `app/Shell/Billing/`, `resources/js/pages/Shell/Billing/`, `resources/js/features/Shell/Billing/AiRecovery/`, `tests/Feature/Ai/Recovery/`, `tests/Browser/E0-05G/`, `docs/results/SP-E0-05G.md`.

## Решение владельца 06.11
- Внутренний оператор — платформенный флаг через консольную команду или конфиг, не роль бренда; без флага USD не видит никто. Утечку в клиентском API устраняет SP-E0-05H.

## Уточнение интегратора 06.11
- Использовать конфиг `config/platform-operators.php` со списком идентификаторов пользователей; пустой список по умолчанию. Проверять флаг на сервере для отдельного внутреннего API и экрана сверки; клиентские API остаются без USD даже для владельца бренда.
- Для реализации дополнительно разрешены только `app/Ai/Http/RecoverCallController.php`, `app/Ai/Http/OperatorRecoveryController.php`, `routes/features/E0-05B.php` и `config/platform-operators.php`. Не включать флаг никому автоматически. Проверить обычного владельца, оператора, отсутствие флага и границы бренда.
