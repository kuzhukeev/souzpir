# SP-E1-09B · Пустой фильтр участника в журнале

При переходе из карточки участника в журнал передаётся фильтр `actor`. Если у участника нет доступных событий, выбранный фильтр остаётся действующим на сервере, но его значение не отображается в списке фильтра. Из-за этого кажется, что журнал показывает все события.

Исправить отображение активного фильтра без раскрытия персональных данных: если идентификатор не входит в список доступных участников, показать нейтральную подпись «Выбранный участник». Не добавлять запросы за именами и не менять фильтрацию, права и объём доступных записей.

Критерии: действующий фильтр остаётся видимым при пустом результате, сброс показывает все доступные события, при наличии имени сохраняется обычная подпись; проверки включают браузерный переход и ограничение доступа. Отдельный worktree и атомарный claim, адресные тесты, результат в `docs/results/SP-E1-09B.md`, затем submit на проверку. Реальных отправок нет.
