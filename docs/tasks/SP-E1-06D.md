# SP-E1-06D · Достоверное время последнего входа

На экране команды по S-3.1 требуется «Последний вход». Не выводить время последней активности сессии как время входа: это разные события, а старые сессии очищаются.

Добавить запись времени успешного завершённого входа через существующее событие `SessionRegistered` после всех обязательных проверок, включая MFA. Сохранять только идентификатор пользователя и время, без IP, User-Agent и секретов. Историю до включения функции не выдумывать: если данных нет, сообщать «Нет данных». Новый обработчик и отсутствие его миграции не должны ломать существующий вход.

Предоставить защищённое чтение времени для участников текущей организации с проверкой сессии, прав и изоляции, без раскрытия других организаций. Создать компонент для показа времени в списке команды; подключение компонента к общему экрану сделает интегратор при объединении, поскольку файл принадлежит SP-E1-06. Проверить настоящий login после успешного MFA, неуспешный вход, повторный вход, отсутствие исторических данных и ограничение ролей и tenant, а также ошибки/отсутствующую миграцию. Тесты — только отдельная база и синтетические данные. После commit с проверками и отчётом `docs/results/SP-E1-06D.md` передать задачу на проверку. Рабочую БД не мигрировать.
