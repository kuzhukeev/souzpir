## Приёмка
- Парсер доказательств из env VISION_EVIDENCE_PARSER_MODEL (по умолчанию google/gemini-2.5-flash), temperature 0, max_tokens 1200 в config/features/E8-01.php; формат проходит проверку MeasurementRunner.php:57–63. Fake-режим и настройки ответов замера не меняются.
- Оценка доказательств одинакова с очередью и без неё: после слота со статусом ok next() вызывает EvidenceStore::evaluate при тех же условиях, что RunMeasurement.php:34; общий метод, не копия условия.
- Отчёт строится из живых доказательств: после всех слотов и подтверждения видимость/упоминания отчёта берутся из результата парсера, а не из fake-артефактов.
- Ошибка парсера: слот остаётся ok, доказательство помечается неразобранным, повтор не зацикливается; ответы модели и ключи не попадают в лог. Исключение лимита (BudgetExhausted из SP-L1-01, наследник LogicException) обрабатывается так же; MeasurementRunner не менять (scope SP-L1-01).
- Тест tests/Feature/Launch/L1-02/ с Http::fake на OpenRouter: старт → слоты (через очередь и через next()) → парсер → доказательства → подтверждение → отчёт; Http::assertSent проверяет model google/gemini-2.5-flash, temperature 0, max_tokens 1200 для запроса парсера.
- Feature-тесты только с Http::fake/Queue::fake, без живых и платных вызовов; ключи и токены только из env/config, не в коде и не в логах. Рефакторинг сверх нужного запрещён; чужие модули не менять; итоговый отчёт docs/results/SP-L1-02.md до 30 строк (тесты, долг, решения).
