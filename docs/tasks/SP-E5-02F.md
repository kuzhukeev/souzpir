# SP-E5-02F · Остаток настроек виджета

Часть SP-E5-02D, экраны D-9.2 и D-9.4. Лимит сообщений (D-9.4) сдан и принят 07.11. Остаток — активная проверка установки виджета (D-9.2c) по решению владельца 07.11 (Telegram, Q1, `docs/decisions-pending.md`).

## Остаток (решение владельца 07.11, Q1)

Как в Яндекс Метрике: два способа подтверждения, установка подтверждена, если сработал любой.

1. Активная проверка по кнопке «Проверить установку» на вкладке «Установка»: сервер делает GET страницы сайта клиента — только домен из сохранённых `origins` настроек виджета (если доменов несколько — проверить каждый или первый, показать результат по домену) — и ищет в HTML код виджета с `public_key` этого бренда. Статусы как у Метрики: «Код установлен», «Код не найден на странице», «Сайт недоступен» (с HTTP-кодом или «таймаут»), «Проверка не удалась». Макеты `70/37df8e4f-D-9.2c-detected.webp`, `70/79c7e5d4-D-9.2c-not-detected.webp`.
2. Пассивная: виджет сам прислал сигнал (`last_seen_at`) — статус «Виджет работает, последний сигнал …». Уже есть, сохранить.

Защита исходящего запроса обязательна — отдельный сервис `app/Seller/Channels/Widget/WidgetInstallationChecker.php`: только http/https и порты 80/443; DNS резолвится и проверяется до запроса — запрет приватных, loopback, link-local и metadata-адресов (10/8, 172.16/12, 192.168/16, 127/8, 169.254/16, 0.0.0.0, ::1, fc00::/7, fe80::/10), повторная проверка после каждого редиректа, не больше 3 редиректов (редиректы Laravel-клиента отключить, обрабатывать вручную); таймаут 5 с; читать не больше 1 МБ ответа; свой User-Agent `SouzpirWidgetCheck/1.0`; не чаще 1 проверки в 30 с на сайт (RateLimiter или отметка в настройках виджета); без cookies и без выполнения JS. Исходящий доступ разрешён только этому сервису: остальные внешние запросы по-прежнему запрещены, `Http::preventStrayRequests()` в тестах не трогать.

Тесты только с `Http::fake` (найден код / не найден / 500 / таймаут-исключение / приватный адрес отклонён до запроса / частота 30 с). Живых запросов в тестах нет. Результат проверки показывать на вкладке «Установка» (статус + время), текст «Активная проверка сайта не выполняется» убрать.
