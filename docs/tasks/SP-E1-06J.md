# SP-E1-06J · Карточка участника: фото и настройки

**Зачем:** конкретные незакрытые пункты S-3.2 из матрицы экранов и журнала макетов [20].
**Часть чего:** остаток SP-E1-06I.
**Зависимости:** SP-E1-06I.

## Приёмка
- S-3.2: отображать фото участника, если оно доступно по подтверждённой политике приватности; для карточки другого участника использовать отдельную защищённую проверку просмотра участника, организации и общего бренда, без публичных файлов и без изменения личного /profile/avatar. При отсутствии разрешённого фото показывать инициалы.
- S-3.2: ссылка «Настроить уведомления» ведёт в предусмотренный макетом D-11.4 для пользователя с соответствующим доступом; не подменять настройки другого участника своим личным профилем. Ссылка на отчёты V-11.5 сохраняет действующие проверки прав и бренда.
- Проверить реальные маршрут и ответ, авторизованные и запрещённые роли, отсутствие доступа к другому бренду и пользователю без прав, отсутствующее фото и действие ссылки; внешние отправки отключены.
- Сохранить существующую приватность личного профиля и данные; если действующий контракт не допускает показ чужого фото даже с проверенными правами, не ослаблять его и явно зафиксировать конкретный блокер.
