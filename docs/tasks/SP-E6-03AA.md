# SP-E6-03AA · Напоминания: согласие и план отправки

**Зачем:** закрыть конкретный остаток D-2.5 из SP-E6-03K.
**Часть чего:** SP-E6-03K, docs/results/SP-E6-03K.md.
**Зависимости:** SP-E6-03K в done. Продуктовый блокер снят решением владельца 07.11.2026.

## Приёмка
- Сохранять отдельные события согласия на рассылку с источником, временем и основанием: явное «да» на вопрос о напоминаниях/предложениях (`dialog`, id сообщения); отметка менеджера в карточке клиента с комментарием (`manager`); явно обозначенное поле согласия на рассылку из CRM (`import`). Согласие на передачу контактов не считать согласием на рассылку.
- Записывать события отписки: стоп-фразы клиента («стоп», «отпишись», «не пишите» и аналоги), снятие согласия менеджером, блокировка бота/адреса каналом. После отписки запрещать отправку клиенту; показывать число событий отписки.
- D-2.5: массовая отправка только при подтверждённом согласии, сохранённое плановое время для всех типов и достоверный видимый результат. Проверить экран, маршрут, обработчик, хранение, очередь и fake-доставку, права, изоляцию брендов, ошибки и остановку после отписки. Живые отправки не включать.
