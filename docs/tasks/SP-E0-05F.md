# SP-E0-05F · Операторское действие сверки расходов ИИ

**Сверх ТЗ: осознанное решение владельца от 2026-11-02.** Это последнее продолжение E0-05; дальше E0-05 не дробить.

**Зачем:** подтверждённая провайдером сверка неопределённых расходов ИИ нужна до live shadow SP-E9-03. Сейчас backend SP-E0-05B готов, но оператор не может вызвать его через штатный маршрут и экран.

**Часть чего:** SP-E0-05B. Закрыть оставшиеся POST-маршрут и операторское действие на существующем экране; после карточки в SP-E0-05B не остаётся пользовательского пути для сверки. Прочие E0-05C/D/E имеют отдельные завершённые области.

Размер: 1–3 часа. Старт после SP-E0-05B, SP-E0-05E и SP-E3-09 по уточнённому приоритету владельца от 2026-11-02. SP-E9-03 ждёт эту карточку. Выдавать после SP-E3-09, перед остальными свободными задачами Vision.

Подключить `POST /ai/recovery/calls/{callId}/reconcile` с именем `ai.recovery.calls.reconcile` к существующему `RecoverCallController` в `routes/features/E0-05B.php`. На экране `/billing/ai-recovery` добавить явное действие сверки с подтверждением, состояниями отправки/успеха/ошибки и обновлением списка. Показывать результат и фактическую стоимость без поля для ручного ввода суммы. Если провайдер не подтвердил вызов, резерв остаётся заблокированным; оплаченный вызов не повторять автоматически.

Scope: `routes/features/E0-05B.php`, `resources/js/pages/Shell/Billing/AiRecovery.tsx`, `resources/js/features/Shell/Billing/AiRecovery/`, `tests/Feature/Ai/Recovery/`, `tests/Browser/E0-05E/`, `docs/modules/E0-05B.md`, `docs/results/SP-E0-05F.md`. Сгенерированные типы разрешены общим правилом AGENTS.md. Не менять реализацию `RecoverCall` и чужие модули.

Приёмка: route вызывает существующий backend только для действующего владельца с `billing.manage` в текущем бренде; чужой вызов/роль отклоняются. UI на русском, доступное подтверждение действия, loading/empty/error и повтор после сбоя; результат и список обновляются без утечки приватных полей. Feature и browser проверки используют только fake/HTTP fixtures, без живых и платных вызовов. Отчёт и submit по AGENTS.md.
