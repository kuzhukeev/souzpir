# Эталон базы знаний продавца

Источник: resources/knowledge/*.yaml из предоставленного Laravel-прототипа, распакованного локально в .local/references/laravel-prototype. Десять файлов включены в закрытый репозиторий как fixtures E3-01. tests/fixtures/knowledge/prototype-sha256.json содержит SHA-256 исходных файлов после приведения CRLF к LF: Git на Windows может менять окончания строк, но не содержимое. Суммы получены из распакованного оригинала, а не созданного среза.

YamlKnowledgeImporter читает только десять ожидаемых имён, проверяет наличие, размер и запрет симлинков, разбирает их без выполнения PHP-объектов. Каталог передаёт доверенный оператор или серверный код; класс не является публичным endpoint и не предоставляет пользователю доступ к произвольным файлам. Все данные проверяются до публикации. Импорт создаёт черновик, помечает факты источником import и атомарно публикует новый срез; существующий черновик не перезаписывается. Ошибка откатывает созданные записи и аудит. Права и границы организации и бренда проверяет KnowledgeRepository.

export возвращает YAML-строки в памяти только для указанной опубликованной версии текущего бренда; сохранение файлов и авторизация HTTP-читателя остаются ответственностью вызывающего слоя. Сравниваются исходные массивы, типы и порядок списков; различие порядка ключей объектов допустимо. Факты прототипа не содержат статусов, поэтому исходно активны; экспорт не должен использоваться для обхода редактора статусов.

Проверки: сравнение всех десяти исходных namespaces и экспортируемых YAML с прототипом; контрольные суммы, запрет невалидного ввода, проверка прав, отказ перезаписи и откат после частичной записи. Платные модели и внешние соединения не вызываются.
