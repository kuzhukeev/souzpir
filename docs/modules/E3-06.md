# E3-06 — оценки и fake-симуляции

`SellerPersonaSeeder::seedForBrand(TenantContext)` переносит 29 синтетических персон из оригинального `tools/personas.yaml` в `seller_personas` выбранного бренда. Повторный вызов не меняет уже созданные записи.

`SimulateFakeJob` принимает проверенные fake-ходы и сохраняет их в `seller_sim_runs`. `JudgeFakeJob` принимает структурированный fake-результат судьи, проверяет пять оценок и типы проблем через `Supervisor`, затем сохраняет `seller_evaluations`. Оба задания записывают минимальные события аудита без текста диалога. Результат доступен редактору и выше через `GET /seller/evaluations/{id}` в текущем бренде.

Словарь Supervisor содержит 5 слоёв, 24 именованных типа проблем и `other`; служебная расшифровка хода сохраняет intent, goal, tools и Guard.

Текущий симулятор принимает готовые fake-ходы. Генерация клиентских реплик и ответов через полный runtime `open/turn` ожидает SP-E3-08; до этого момента задания не вызывают LLM и доставку.
