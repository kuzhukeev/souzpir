# SP-E8-05C · Публичные отчёты

`GET /vision/publications` показывает подтверждённые внутренние отчёты и ссылки выбранного бренда. Создание требует `vision.report.read` и `vision.measure.run`, проверяет снимок через `VisionReportReader`, сохраняет только агрегированные числовые метрики. Текст вопросов, ответы ИИ, внутренние факты, промпты и реквизиты в публичную проекцию не попадают. Ссылка с 256-битным случайным токеном показывается один раз; в таблице хранится SHA-256 токена.

Срок ссылки выбирается из `config/features/E8-05C.php` (по умолчанию 1, 7 или 30 дней). Публикацию можно отозвать в кабинете. Публичный `GET /v/{token}` рендерит отдельный Blade SSR отчёт, каждый раз проверяет `expires_at` и `revoked_at`, возвращает 410 после срока или отзыва, 404 для неизвестного токена. Заголовки `noindex`, `no-store` и `no-referrer` запрещают индексирование и сохранение в клиентском кэше.

React SSR entrypoint добавлен в Vite и проверен сборкой. Глобальный Inertia SSR остаётся выключен до отдельного запуска Node SSR процесса; публичный отчёт уже рендерится сервером через Blade. Навигационная ссылка из внутреннего отчёта принадлежит SP-E8-05, требуется интегратору.
