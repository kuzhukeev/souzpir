# Импорт подготовленной копии организации

Команды разрешены только в `APP_ENV=testing` при PostgreSQL на loopback и совпадении `DB_DATABASE` с отдельной `DB_TEST_DATABASE` вида `souzpir_test_*`. Нужны заранее созданные тестовая база, миграции и владелец. Источник — подготовленная SQLite-копия с полями `id`, `name`, `brands.organization_id`.

```text
php artisan migration:import-organization-copy <путь-к-копии> <ULID-организации> <ULID-владельца> --env=testing
php artisan migration:rollback-organization-copy <ULID-batch> --env=testing
```

Импортирует имена организации и брендов, привязывает существующего владельца, фиксирует batch и возвращает его при повторе неизменённой копии. Другая организация в целевой базе, отсутствующий владелец и изменённая копия вызывают отказ. Остальные поля и членство владельца не переносятся.

Откат сравнивает текущие записи со снимком batch и проверяет зависимости по внешним ключам PostgreSQL; при изменениях или зависимостях возвращается конфликт без удаления. Связи, существующие только внутри JSON или внешних систем, автоматически не проверяются: полноценный перенос и откат данных требуют отдельной задачи. Рабочие базы не поддерживаются.
