# Планы и лимиты

`plans` содержит определения тарифов, `plan_limits` — необязательные значения и единицы, `organization_plan` — единственный источник назначений. Значений, цен и тарифов по умолчанию нет. Периоды полуоткрытые `[starts_at, ends_at)`; PostgreSQL exclusion constraint запрещает пересечение периодов одной организации, в том числе при конкурентных записях. Для миграции требуется доступное доверенное расширение `btree_gist`; оно не удаляется при откате, поскольку может использоваться другими модулями.

`PlanLimits::get(TenantContext, key)` требует идентификатор организации, изолирует назначения и возвращает точное десятичное значение строкой. Отсутствие назначения, ключа или null значения даёт `configured=false`, `value=null`; заданный ноль остаётся реальным ограничением. Форматирование отсутствующего значения — `—`. `LimitEnforcer::assertWithin` сравнивает неотрицательные десятичные строки без float и при превышении выбрасывает validation exception с HTTP 422. Текущее время передаётся в SQL с часовым поясом.

`UsageReader` по умолчанию возвращает для запрошенных метрик `unavailable` и null, не подменяя их нулями. Домены регистрируют `UsageContributor` через feature registry с ключом `usage.*`; неизвестные, дублирующиеся или некорректные метрики отклоняются. Будущие подключения E7-04/E8-07 должны реализовать этот контракт и не выполнять запросы в чужие tenant-данные.
