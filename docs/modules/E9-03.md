# Теневой запуск

Инфраструктура и контракт для сравнения ответов старого прототипа и нового движка на одном входе («тень»). Запись выключена по умолчанию (`features.E9-03.defaults.shadow_enabled`); живой 2-недельный параллельный прогон начинается только после отдельного разрешения владельца с данными и бюджетом — это отдельный операторский этап, не часть этой задачи.

```text
php artisan shadow:record <ULID-бренда> <канал> <текст входящего> <ответ прототипа> <ответ нового движка>
php artisan shadow:report <ULID-бренда>
```

`shadow:record` сверяет бренд и владельца организации, после включения флага сравнивает нормализованные (регистр, пробелы) ответы и сохраняет запись `shadow_comparisons` с вердиктом `match`/`mismatch` и заметкой. `shadow:report` печатает число сравнений и расхождений по бренду; выборка строго по организации и бренду аргумента.

Judge — детерминированное текстовое сравнение, без вызовов ИИ: для MVP расхождение фиксируется по факту несовпадения ответов, а не по оценке качества формулировки. Таблица append-only: обновление и удаление запрещены на уровне модели.
