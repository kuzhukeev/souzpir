# Очистка реестра сессий

Команда `auth:prune-session-registry --limit=100` удаляет одну партию до 500 записей: отозванные до порога хранения или неотозванные, срок которых истёк до порога. Активные, недавно отозванные и недавно истёкшие записи не удаляются. PostgreSQL SKIP LOCKED пропускает запись, которую проверяет другой процесс; следующая команда вернётся к ней.

Предварительное значение SESSION_REGISTRY_RETENTION_DAYS = 90 дней; разрешён диапазон 30–3650. Точный срок должен соответствовать принятой политике хранения перед включением автоматического запуска. Самостоятельного расписания нет; SP-E0-07 отвечает за контролируемый планировщик. Команда пишет только количество и безопасную ошибку, без идентификаторов сессий. Организации, пользователей и журнал аудита не удаляет.
