# Журнал действий и уведомлений

Маршруты: GET /journal, GET /journal/export, GET /journal/notifications, POST /journal/notifications/{id}/retry.

Аудит ограничивается текущей организацией и брендом, владельцу и администратору дополнительно доступны события организации без бренда. Редактору видны только разрешённые ему модули. CSV содержит те же ограниченные и отфильтрованные данные. Поля до/после выводятся только из уже очищенной аудит-записи.

Повторно отправляется только доставка в статусе failed, которая не могла быть передана провайдеру; состояние uncertain никогда не повторяется автоматически. Для внешней отправки необходимы отдельно настроенные доставка и работник очереди. Факт постановки в очередь не означает фактическую доставку.

Запись в database queue и изменение статуса происходят в одной транзакции на том же DB-соединении. Для исполнения заданий необходим запущенный worker подключения database с настроенной очередью; при несовместимой конфигурации повтор отклоняется без изменения статуса. Фильтры и отображение дат используют Europe/Moscow.
