# Проверка доказательств Видения

EvidenceEvaluator принимает только TenantContext и ID сохранённого measurement_answer; текст, профиль, модель и настройки из HTTP/аргументов не принимаются. Он требует tenant-bound measurement со статусом ответа ok, protocol_valid, неизменяемый profile_snapshot с верной CanonicalJson checksum и замороженный configuration.parser. Для parser необходимы model, temperature, max_tokens и точные значения EvidenceEvaluator::artifacts(): SHA-256 prompt/schema/confirmation_prompt, normalizer_version и confirmation_version. При несовпадении, отсутствии или ошибке возвращается unknown без факта; старые замеры с null профилем или parser не изменяются.

KnowledgeGate — обязательный deny-by-default контракт: E8-01D обязан реализовать проверку публикации, согласия, tenant, содержимого и отзыва профиля до и после вызова. Без зарегистрированной реализации сервис через контейнер недоступен. До отдельного разрешения live доступен только runtime.ai_driver=fake; любые ошибки или неизвестные/неподтверждённые ответы не становятся отрицательными фактами. Реальная передача и гонка отзыва после финальной проверки требуют отдельного допуска.

Перенесены детерминированные правила из AnswerParser, EntityNormalizer, VisibilityProfile и MentionConfirmer; синтетические donor fixtures остаются синтетическими, не являются оценкой качества модели. Цитата и claims должны буквально присутствовать в ответе, порядок компаний — соответствовать тексту, рекомендация подтверждаться контекстом. Проверенное отсутствие имён можно учесть как отрицательный результат; при неоднозначном совпадении возвращается unknown. Неоднозначное имя дополнительно проверяется только по буквальной цитате и двум разрешённым фактам, один из которых идентифицирующий; непроверенные факты не подтверждают личность.

SourceExtractor извлекает только буквальные HTTP(S)-ссылки из текста без сетевого обращения, удаляет query и fragment, отклоняет userinfo и IP, проверяет границы домена; источники провайдерских annotations пока недоступны в модели и не выдумываются.

Результат содержит status/fact/mentions/sources/signature. Он сам не сохраняет факт: E8-01 при будущей интеграции обязан перед сохранением в одной транзакции повторно сверить answer/status, tenant, immutable profile/config и KnowledgeGate. До этого отчёты остаются unknown. Отказано любому прямому user-supplied тексту или профилю; аудит и UI реализуются соответствующими владельцами.
