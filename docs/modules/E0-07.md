# E0-07 — состояние database-очередей

Одноразовая операторская команда `php artisan runtime:queue-status` показывает
для пяти очередей текущего `QUEUE_NAMESPACE` только название и агрегированные
количества ожидающих, зарезервированных и неуспешных заданий. Ожидающие — все
строки `jobs` с `reserved_at IS NULL`, включая отложенные; зарезервированные —
с ненулевым `reserved_at`, включая истёкшие резервации. Неуспешные — записи
`failed_jobs` с `connection=database` для разрешённых очередей. Другие очереди
и подключения не выводятся. SQL не читает payload или exception.

Поддержаны только database queue на PostgreSQL и database/database-uuids
хранилище ошибок на том же подключении. При других настройках, неподдерживаемом
подключении или отсутствии таблиц команда возвращает безопасную ошибку без
деталей SQL и содержимого заданий. Два источника подсчитываются одним SELECT;
команда не запускает worker, scheduler или задачи и не изменяет записи.
