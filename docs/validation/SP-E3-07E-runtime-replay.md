# SP-E3-07E: проверка подключения записей к runtime

Проверен первый вызов `persona.newbie_voronezh`: изолированный runtime вызвал `RecordedGateway` через fake-драйвер, адаптер вернул `Recorded request does not match.` Сетевые запросы, почта и очередь были отключены. Runtime получил синтетическое входящее сообщение из тестовой конфигурации, а не исходное сообщение сценария; это диагностическая проверка, не сравнение поведения сценария.

Записанный запрос имеет поля `messages` и `options`, запрос runtime содержит `model` и другие поля `AiRequest`. Адаптер сверяет хеш всего запроса, поэтому прямое подключение не воспроизводит запись. Дополнительно вызов responder с сырыми аргументами требует экземпляр `FakeDriver` в `app/Ai/Gateway.php`; записанный адаптер реализует только `Driver`. Этот общий gateway и поддержка адаптера находятся вне scope карточки.

Данное наблюдение само по себе не устанавливает эквивалентность промптов или результатов. Нужны согласованный способ сопоставления запросов и безопасное подключение записанного драйвера, а затем полный прогон 41 сценария, follow-up, ошибок и изоляции. Golden fixtures не менялись. В CI включена только отрицательная диагностическая проверка, не полный replay.
