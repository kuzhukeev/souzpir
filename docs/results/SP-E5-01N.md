# SP-E5-01N — доставка ответа менеджера в Telegram

- Очередь выбирает подготовленный Telegram-транспорт только для Telegram-диалога при включённом `features.E5-01.defaults.manager_telegram_delivery`; флаг по умолчанию выключен.
- Остальные каналы и выключенный флаг сохраняют прежний fake-транспорт. Ошибка Telegram не устанавливает `delivered_at`.
- Изолированный PostgreSQL: TelegramManagerJobE501NTest и TelegramManagerDeliveryE501LTest — 2 теста, 22 проверки: очередь, флаг, fake HTTP, права, другой бренд, ошибка и другой канал; Pint.
- Живых внешних вызовов не было; интерфейс не изменялся.
