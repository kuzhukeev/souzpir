# SP-E0-05B: частичный результат

Интегратор зарегистрировал маршрут в общем реестре и повторил шесть тестов (51 проверка) через реальный маршрут на отдельной тестовой БД. Это серверный интерфейс без страницы кабинета; восстановление по-прежнему недоступно.

Реализован read-only контроллер списка `reserved`/`uncertain` выбранного бренда с повторной проверкой активной сессии, прав и выбранного бренда, ограниченной проекцией и страницами по 50 записей. Реальные вызовы ИИ, письма и другие внешние отправки не выполнялись. Учёт, резервы и вызовы не изменяются при просмотре; обычное продление lease сессии остаётся в существующем механизме авторизации.

Проверки выполнены из отдельного worktree на собственном PostgreSQL-кластере `127.0.1.47:55689`, базе `souzpir_test_e005b_recovery` и отдельном непривилегированном владельце; перед тестами проверены basePath, адрес, имя БД и каталог кластера. HTTP fake запрещает внешние сетевые вызовы, mail подменён. `UnresolvedCallsTest`: 6 тестов, 51 assertion; покрыты разрешённый владелец и чужие роли/сессии, границы организаций и брендов, ограничение brand grants, смена бренда и устаревшая ревизия, минимальная проекция, отсутствие изменения учёта, ошибки и страницы. `pint --test` для новых PHP-файлов прошёл. Скриншоты не применимы: UI не создавался.

Ограничения: маршрут в `routes/features/E0-05B.php` находится вне scope и должен быть зарегистрирован интегратором; точный контракт приведён в `docs/modules/E0-05B.md`. Подтверждённой провайдером сверки, восстановления расходов, аудита восстановления и UI нет; существующие операции сверки остаются закрытыми, live shadow не разрешён. Список не означает, что вызов завершился или что его резерв безопасно освободить. Это частичная работа, а не выполнение всех критериев карточки; интеграция и статус карточки остаются за головным чатом.
