# SP-E1-10F — настройка webhook

- Добавлена форма создания webhook: HTTPS адрес, события, одноразовый секрет подписи. Адрес и секрет хранятся зашифрованными, в Inertia props и журнал не выводятся.
- Новый маршрут очищает входные поля до дальнейшей обработки запроса; прежний закрытый маршрут остался закрытым. Доступ ограничен владельцем и администратором выбранного бренда.
- Кнопка проверки создаёт запись «Проверено без отправки» через Guzzle MockHandler; реальная доставка остаётся выключенной.
- Тесты: `tests/Feature/SP-E1-10F/WebhookConfigurationTest.php` — 2 теста, 24 проверки; существующая проверка закрытого маршрута — 1 тест, 28 проверок; Playwright — 3 адресных теста. ESLint, TypeScript прошли.
- После CI: кнопка создания webhook отключена при небезопасном транспорте или хранилище сессий; 3 адресных Playwright-теста и `npm run lint` прошли.
- Скриншот: `.local/screenshots/sp-e1-10f/webhook-create-1440.png`.
- Ограничения: автоматическая и реальная ручная доставка выключены.

## Техдолг
- Старые webhook могут содержать открытый URL; текущий экран его не раскрывает, новое создание шифрует.

## Принято по умолчанию
- HTTPS адрес принимается только для публичного домена без query, fragment и учётных данных.

## Нужно от интегратора
- Реальную доставку включать отдельной задачей после снимка подписок и подтверждения транспорта; тогда обновить чтение зашифрованного URL в WebhookDelivery.
