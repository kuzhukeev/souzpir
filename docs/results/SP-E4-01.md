# SP-E4-01 — обзор и релизы знаний

- Добавлен обзор опубликованных знаний, создание черновика, публикация с проверкой версии, история и восстановление релиза через существующий KnowledgeRepository.
- Входящие показывают реальные неизвестные вопросы, пометки неверного факта и замечания оценок текущего бренда.
- Тесты: ReleasesTest — 3 теста, 59 проверок: публикация, откат, конфликт, входящие, права, изоляция и ошибка ввода.
- Проверки: Pint, TypeScript, ESLint экрана, генерация типов маршрутов.
- Скриншот: .local/screenshots/sp-e4-01/knowledge-1440.png (светлая тема, демонстрационные данные).
- Ограничение: входящие доступны только для просмотра; сравнение релизов и перенос предложений в факт/условие/образец не реализованы.

## Техдолг
- Входящие ограничены последними 50 записями каждого типа без пагинации.

## Принято по умолчанию
- Первый черновик пустой; последующие создаются из активного релиза. Счётчики отражают опубликованные данные.
