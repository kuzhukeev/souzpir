- Последующие fake-ходы пока используют фиксированный ответ без Policy; сценарий двух негативных сообщений в полном runtime не подключён.
- Полное расположение четырёх карточек и остальные состояния макета D-5.6 требуют отдельной UI-доработки.
- Предложение новой задачи: расширить защищённые стадии для отказа и последующих ходов, затем проверить действия сквозным fake-сценарием и завершить экран.
