Модель: Terra

## Сделано
- Источник прайса сохраняется для бренда: файл, HTTPS-ссылка или каталог с ценами. Отправка использует выбранный источник, сохраняет настройки SMTP и подпись.
- Запрос действия v2 создаёт заявку поддержки через существующий контракт и fake-доставку, повторный ключ не дублирует заявку.
- Счётчик обещаний основан на сохранённых событиях; для остальных действий без достоверных событий показывается отсутствие данных.
