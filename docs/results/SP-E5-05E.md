## Ограничения
- Дровер показывает до трёх последних сообщений; полный диалог доступен по ссылке.

## Техдолг
- Фрагменты диалогов загружаются для каждой доступной задачи отдельно; при большом числе задач запросы стоит объединить.

## Принято по умолчанию
- «В работе» считается открытым для просрочки и уведомлений; срочность определяется сохранённым приоритетом `urgent`.
