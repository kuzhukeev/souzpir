# SP-E8-16I — частичная сдача

- Уточнения выводятся страницами по 50 подтверждённых замеров текущего бренда; доступны переходы назад и далее.
- Прогресс отображается только для активного замера; ответы завершённого остаются доступны.
- Проверки: ClarificationPaginationE816ITest (41 проверка), Playwright E8-16I (2), TypeScript, Pint.
- Скриншот: `.local/screenshots/SP-E8-16I/clarifications.png` (светлая тема, 1440).

## Остаток
- V-3.3: отдельный маршрут замера, оставшееся время, уведомление, лента и число уточнений.
- V-3.4: шапка с номером, моделями и прогонами, цветная легенда.
- V-4.4: изменение видимости X → Y. Предлагается карточка-продолжение на эти пункты и сверку с макетами.

## Техдолг
- Пагинация использует смещение; при появлении новых замеров между переходами состав страниц может измениться.

## Принято по умолчанию
- Переходы доступны только при наличии предыдущей или следующей страницы.
