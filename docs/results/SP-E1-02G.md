# SP-E1-02G

Приватный SVG-логотип, сохранённый онбордингом, отображается в настройках и оформлении текущего бренда; сохранены проверка доступа, изоляция пути, CSP sandbox и запрет кеширования.
Проверки: OnboardingSvgLogoE102GTest — 14 проверок, в том числе гость, доступ другого бренда и два неверных пути; Playwright E1-02G — отображение SVG; Pint. Предупреждение тестов: отсутствует локальная .env.
Скриншот 1440: `.local/screenshots/sp-e1-02g/brand.png`.

## Техдолг
Нет.

## Принято по умолчанию
Загрузка нового SVG в настройках бренда не добавлялась: поддерживается отображение уже проверенного SVG онбординга.

## Нужно от интегратора
Экран S-0.7 использует отдельную проверку PNG в `app/Shell/Context/OrganizationSelectController.php`: для показа того же SVG там нужна отдельная правка вне scope.
