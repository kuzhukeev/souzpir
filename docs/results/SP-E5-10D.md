# SP-E5-10D — пометки во входящих

- Во входящих базы знаний показываются все шесть типов пометок, исходный ответ бота, комментарий и предложенное исправление; ссылка ведёт в исходный диалог.
- Просмотр не меняет черновик: применение и отклонение выполняются только выбранным пользователем действием. Сохранены проверки прав, принадлежности бренду и версии черновика; ошибки показываются в форме.
- На узком экране убрана лишняя горизонтальная прокрутка из заголовка таблицы публикаций.
- Проверки: PHPUnit 2 теста, 57 проверок (все типы, ручное применение, права, чужой бренд, устаревшая версия); Playwright 2 теста (три темы, 1440/1024/390, клавиатура, отказ сети); TypeScript, ESLint, Pint.
- Скриншот: `.local/screenshots/SP-E5-10D/incoming.png`.

## Принято по умолчанию
- Пометки всех типов используются как предложения; пользователь выбирает место и текст применения сам, runtime и внешние вызовы не запускаются.
