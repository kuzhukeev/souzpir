# SP-E3-03B — частичный результат
- Внутренний runtime входящего хода проверяет сессию, ревизию бренда, права и сохранённый ввод; bot использует защищённый координатор первого хода.
- Manager сохраняет терминальный ход без ИИ и доставки, поддерживает последующие входящие и повтор по ключу.
- PostgreSQL: 4 теста / 105 проверок при zend.exception_ignore_args=0; 4 предупреждения Pest. AI/HTTP/mail/queue — fake; Pint выполнен.
- Ограничения: bot только первый fake-ход; open, suggest, следующие bot-ходы, regeneration/fallback, tools и Delivery не завершены.
- Скриншоты: инфраструктурная задача без новых экранов.
## Техдолг
- Нет общего защищённого финализатора для произвольного хода и передачи результата инструментов.
## Принято по умолчанию
- До готовности защищённых этапов suggest и следующие bot-ходы возвращают unavailable; реальная доставка выключена.
## Нужно от интегратора
- Доработать общий защищённый координатор и финализатор вне разрешённой области задачи: сейчас они жёстко рассчитаны на первый bot-ход и изолируют tool calls.
- Определить и реализовать общий Delivery contract; подключить runtime к входу кабинета в принадлежащих модулях.
