# SP-E4-08J — оставшиеся fake-персоны песочницы

- В fake-предпросмотре трёх сценариев передачи известные заявления о передаче или отправке заменяются честным сообщением: действий песочница не выполняет. Затем ответ проверяется существующим Guard; обычный fallback сохранён.
- Проверены семь исходных персон с их реальными лимитами ходов: для шести доступен проверочный вход; у requisites лимит заполнен сохранёнными фактами и дополнительный вход не попадает в диалог.
- Проверены три подставленных fake-ответа о передаче, повторяемость, права, чужой бренд и отсутствие внешних вызовов. PHPUnit: 4 теста, 73 проверки на отдельной PostgreSQL; Pint. Интерфейс не менялся.

## Остаток
- Передача wants_human, requisites и big_order должна считаться выполненной только после подтверждённого действия в runtime; в песочнице реальная передача пока не реализована.
- Для requisites обеспечить проверку сценарного входа без вытеснения исходных фактов и нарушения лимита ходов; доработать оставшиеся ответы под действующий Guard без изменения golden fixtures.
- Проверка обещаний ограничена распознаванием известных формулировок этих трёх fake-персон; полная проверка прочих действий требует согласованного контракта результата инструмента.

## Техдолг
- Нет.

## Принято по умолчанию
- При неподтверждённой передаче показывается явное сообщение о тестовом режиме, а не утверждение о реальном действии.

## Нужно от интегратора
- Зарегистрировать продолжение по реальному подтверждению передачи и оставшимся сценариям; определить контракт результата действий runtime.
