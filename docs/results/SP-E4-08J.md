# SP-E4-08J — оставшиеся fake-персоны песочницы

- Подключён безопасный ответ experienced_kazan для сравнения предложений; tc_floor проверен на исходном лимите 12 ходов. Оба ответа проходят действующий Guard.
- Для wants_human, requisites и big_order известные обещания передачи в fake-предпросмотре заменяются сообщением о том, что песочница не выполняет передачу; ответ проходит Guard.
- С исходными лимитами проверены семь персон: for_self_wedding и prices_only_rude сохраняют fallback при отказе Guard; requisites не получает дополнительный сценарный вход, поскольку шесть исходных фактов заполняют лимит.
- PHPUnit: 5 тестов, 101 проверка на отдельной PostgreSQL, включая три ложных обещания, права, два бренда, Guard, fallback и отсутствие внешних вызовов; Pint. UI не менялся.

## Остаток
- wants_human, requisites и big_order: подтвердить сохранённое действие перед показом передачи; песочница сейчас не создаёт передачу менеджеру.
- requisites: включить сценарный вход в лимит шести ходов, сохранив все исходные факты; for_self_wedding и prices_only_rude: подготовить корректные ответы, проходящие текущий Guard и проверки сценария.
- Распознавание обещаний охватывает перечисленные глагольные формы; структурный результат инструмента пока не передаётся в предпросмотр.
