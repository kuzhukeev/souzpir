# SP-E8-19K — сравнение публичных показателей

- Публичный снимок сохраняет агрегированное количество подтверждённых ошибок для сопоставимых подтверждённых замеров, без текстов ответов.
- Карточки показывают изменение относительно ближайшего сопоставимого замера; график ошибок доступен при наличии непрерывных данных. При отсутствии данных показано пояснение.
- Проверки: PHPUnit — 5 тестов, 89 утверждений; Playwright — 3 теста, ширины 1440/1024/390, светлая и тёмная темы; Pint.
- Скриншот: `.local/screenshots/SP-E8-19K/report.png`.

## Техдолг
Нет.

## Принято по умолчанию
Процентные показатели сравниваются в процентных пунктах; история с пропусками не соединяется графиком.
