## Принято по умолчанию
- Не складываем разные физические единицы: график использует только подтверждённый пересчёт в тарифные единицы. При отсутствии коэффициента показаны таблица фактического расхода и пустое состояние графика.
- Конец назначения плана не считается продлением. Неуказанные цена и дата остаются неизвестными; демонстрационные значения не добавлены.
