# SP-E8-14D — частичная сдача

V-1.1: из анкеты запускается существующая проверка сохранённого сайта; есть блокировка при несохранённых данных, проверка права и отображение ошибок. Старый сохранённый результат больше не называется текущей доступностью. V-1.3: предлагаются названия товара или услуги из структурированных данных успешной страницы аудита текущего сайта.
Проверки: ProductHintsE814DTest — 1 тест, 80 проверок (права, бренд, fake HTTP); Playwright E8-14D — 2 сценария (запуск, отказ сети, несохранённый адрес, право); ESLint, TypeScript, Pint, генерация типов. PostgreSQL 16 отдельный; PHP предупреждает об отсутствующей .env.
Скриншот `.local/screenshots/SP-E8-14D/site.png` (светлая тема, 1440).

V-0.1: логотипы моделей. V-1.1: результат текущего запуска показывается в разделе «Сайт», не непосредственно в анкете. V-1.3: аудитория; V-1.4: конкуренты; V-1.5: иные факты; V-1.7: вопросы помимо заголовков. Предлагается продолжение с проверенными источниками.
