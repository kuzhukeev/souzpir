# SP-E4-01K — частичная сдача

D-4.12: восстановление скачанной JSON-копии черновика с проверкой формата, содержимого и метаданных фактов; текущий черновик сохраняется как серверная копия, публикация не меняется.
Проверки: RestoreFileE401KTest — 18 проверок, включая права, другую область бренда и два некорректных файла; Playwright E4-01K — выбор файла; TypeScript, Pint, генерация типов маршрутов.
Скриншот 1440: `.local/screenshots/sp-e4-01k/restore.png`.

## Остаток
D-4.12: защищённый fake runtime для прогона с извлечением намерений на каждом ходе и смысловая проверка произвольных критериев.

## Техдолг
Копия ограничена размером 2 МБ; при необходимости лимит можно пересмотреть по реальным данным.

## Принято по умолчанию
Восстановление создаёт новую версию черновика с номером 1 и сохраняет логические идентификаторы, источники и статусы фактов.

## Нужно от интегратора
Завести продолжение на оставшийся защищённый прогон и смысловые критерии; внутренний runtime первого хода сейчас требует HTTP-сессию.
