# SP-E5-05 — клиенты, задачи и обещания
- Список клиентов текущего бренда: KPI, поиск и фильтры, тип через Policy::clientType, менеджер и открытые задачи.
- Карточка: поля LeadState, история из messages.meta.extraction, диалоги, задачи/обещания и сохранение заметок с аудитом.
- Задачи: список/канбан, мои и просроченные, смена статуса с проверкой прав и аудитом.
- Планировщик создаёт событие seller.promise.overdue для просроченного обещания через штатный outbox.
- PostgreSQL: 2 теста / 71 проверка, 2 предупреждения Pest; Queue fake; типы маршрутов, TypeScript, ESLint и Pint.
- Скриншоты: `.local/screenshots/sp-e5-05/customers-1440.png`, `tasks-1440.png` в основном checkout; предпросмотр компонентов с демонстрационными данными, светлая тема, 1440.
- Ограничения: изменение менеджера, создание напоминаний, переход к диалогу и карточки каналов не реализованы; канбан использует доступные статусы new/done/cancelled.
- KPI и фильтры стадии/итога/канала используют последний сохранённый диалог клиента.
## Техдолг
- Список выполняет отдельные запросы к последнему диалогу и задачам каждого клиента; при большом объёме потребуется пагинация и агрегация.
## Принято по умолчанию
- Уведомление создаётся при наступлении срока активной задачи типа promise; повторное изменение срока допускает новое уведомление.
