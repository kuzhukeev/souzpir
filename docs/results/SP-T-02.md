# SP-T-02: эталонный релиз знаний

Добавлен импорт десяти YAML-файлов прототипа в атомарный draft/publish с источником фактов import и безопасный экспорт опубликованной версии. Исходные файлы и нормализованные контрольные суммы сохранены для сверки; сравнение не игнорирует типы значений и порядок списков.

Проверка на выделенной PostgreSQL: 5 тестов, 55+ утверждений (эквивалентность, экспорт, контрольные суммы, невалидные файлы, отказ viewer/перезаписи, принудительная ошибка после начала записи и полный rollback); Pint. Это серверная инфраструктура: интерфейс и скриншоты неприменимы. Публичный импорт, массовая миграция и подключение реальных данных — отдельные задачи. Внешние сервисы не вызывались.
