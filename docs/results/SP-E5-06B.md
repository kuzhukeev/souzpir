# SP-E5-06B — напоминания о контакте

- Настройка бренда сохраняется; планировщик готовит адресное событие по однозначной дате и зоне бренда, без повторов.
- Актуальность срока, назначения и доступа перепроверяется перед обработкой и fake-доставкой; личные настройки и тихие часы применяются общей системой.
- Live-доставка этого события запрещена, в том числе при смене драйвера после подготовки.
- Проверки: PHPUnit `tests/Feature/Seller/Channels/Planned` — 16 тестов, 236 проверок; `npm run typecheck` — успешно.

## Принято по умолчанию
- Дата без зоны интерпретируется в зоне бренда; относительные и неполные даты не создают событие.
- Email является персональным opt-in, как и в существующей системе уведомлений.

## Нужно от интегратора
- Для включения тестовой доставки в изолированном окружении задаётся `NOTIFICATION_DRIVER=fake`; по умолчанию драйвер не меняется.
- Скриншот D-10.3 рядом с макетом не снят; визуальная сверка остаётся для приёмки.
