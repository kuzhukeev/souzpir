# SP-E7-04O · Расписание аналитики

## Сделано
- Подготовлены команда и вклад в планировщик для еженедельного отчёта в 09:00 по часовому поясу бренда.
- Команда берёт сохранённых получателей и число диалогов за предыдущие семь дней отдельно для каждого бренда; транспорт только in-memory.
- Регистрация команды и планировщика в общем реестре не менялась: она вне scope.

## Проверено
- PHPUnit: 5 тестов, 95 проверок на отдельной PostgreSQL; расписание, изоляция брендов, сохранение подписок, права и ошибки.
- Pint и git diff --check — успешно. Живых отправок не было; интерфейс не менялся.

## Остаток
- D-8.2: событие первого получения контакта в защищённом финализаторе вне scope, расчёт времени; старым диалогам — «Нет данных».
- D-8.6: серверный PDF с кириллицей, остальные показатели отчёта и сверка экранов с макетом.

## Техдолг
- До регистрации планировщика отчёт не запускается автоматически.

## Принято по умолчанию
- Подписка проверяется ежечасно, отчёт формируется в 09:00 местного времени за семь предыдущих суток.
