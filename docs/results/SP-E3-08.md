# SP-E3-08 · Частичный HTTP-вход runtime

Добавлен fake-only HTTP-вход с проверкой прав и входных данных для существующего FirstInboundRuntime: первый bot-ход направляется в защищённый coordinator, менеджерский ход подавляется без AI и повторяется по ключу.
Проверки: TurnHttpTest — 1 тест, 12 проверок (менеджерский ход, повтор, запрет чужого бренда, права, две ошибки ввода, отсутствие HTTP-вызовов); Pint, генерация типов. Снимок неприменим: серверный API.
Ограничения: защищённый coordinator и финализатор последующих bot/suggest ходов не реализованы, поэтому эти режимы отвечают 503; HTTP-первый bot-ход отдельным тестом не проверялся. Критерии карточки выполнены частично.

## Техдолг
- Текущий FirstTurnProtectedClaim и финализатор ограничены version=0 и mode=bot; расширять их для следующих ходов нельзя.

## Принято по умолчанию
- Неподдержанный режим не создаёт фиктивный ответ; длина ключа ограничена 128 символами по существующему репозиторию.

## Нужно от интегратора
- Предложить продолжение: отдельный защищённый coordinator/finalizer в разрешённом SellerFollowup для последующих bot/suggest ходов с проверкой tenant/session/ревизии и отсутствия контактов в fake AI; это необходимо для E3-09 и финального replay.
