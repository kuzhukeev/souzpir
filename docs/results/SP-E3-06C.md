# SP-E3-06C · Judge и ежедневный Supervisor
- Judge читает завершённый прогон и ожидания персоны, вызывает только FakeDriver, проверяет пять оценок и объяснимые проблемы, сохраняет результат по бренду; повтор возвращает прежнюю оценку.
- JudgeFakeJob без переданной фикстуры результата вызывает Judge; прежний режим готового результата сохранён.
- Ежедневный Supervisor группирует оценки предыдущего дня по брендам и слоям, сохраняет итог в seller_evaluations и пишет аудит; повтор дня не создаёт второй итог.
- Проверено: тесты Evaluation — 10/53, включая fake-оценку, ошибки, расписание, повтор и два бренда; Pint. UI не менялся, скриншоты неприменимы.
## Техдолг
- Оценки, появившиеся после первого ежедневного итога за тот же день, в этот итог не попадут.
## Принято по умолчанию
- День отчёта и запуск в полночь используют Europe/Moscow; расписание действует при FEATURES_SCHEDULING_ENABLED.
- Запрос Judge требует соответствующую проверенную fake-фикстуру; живой драйвер отклоняется. Итоги отличаются маркером supervisor в существующей таблице оценок.
