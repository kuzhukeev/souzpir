# SP-E1-02: результат

Сделаны защищённый organization-only контекст для владельца, четыре адаптивных шага, серверный черновик, валидация и атомарное завершение с единственным первым брендом и audit. Повтор завершения не создаёт дубликат и не переключает уже выбранный бренд. Одновременное редактирование незавершённого черновика в нескольких вкладках пока не защищено версией. Визуальные элементы созданы кодом с учётом 13 px минимума, мягких рамок, клавиатурного фокуса и cursor:pointer. Данные тарифов не выдуманы; выбор модулей — сохранённое предпочтение, не подключение.

Реализована приватная загрузка/замена PNG, JPEG, WebP: проверка реального изображения, размера и разрешения, нормализация в PNG, выдача только текущему владельцу; SVG не допускается. Внутренние файлы не публичны, старый файл не удаляется до успешного commit. Реальное сетевое обследование сайта сознательно не выполняется до SSRF-защищённого сервиса E8-01B. Дальнейшая интеграция и ограничения описаны в `docs/modules/E1-02.md`.

Проверки на изолированной PostgreSQL роли и базах (физическая копия vendor; тесты проверяют basePath и имя БД): PHPUnit onboarding + tenancy + auth 53 теста / 411 assertions; отдельный onboarding после проверки повтора с другим выбранным брендом 15/145; `npm run typecheck`, `npm run lint`, `npm test -- --run` 83/83, `npm run build`, Pint по изменённым PHP-файлам. Playwright: UI 12/12 (1440/1024/390, состояния и ошибки, шрифты ≥13px, axe WCAG 2 A/AA); отдельный настоящий браузерный сценарий Laravel + PostgreSQL 1/1 — вход, сохранение и восстановление черновика после reload, две последовательные загрузки/замены изображения, заполнение бренда, завершение и reload. Никаких внешних HTTP/LLM/mail не вызывалось.

Для повторения браузерного интеграционного теста в отдельной testing-БД: задать testing env из выделенных локальных параметров, `APP_ENV=testing`, `E102_RESET_TEST_DATABASE=1`, PHP 8.4 и выполненный build; `php tests/Browser/E1-02/prepare-fixture.php` перед запуском принудительно очищает только БД, совпадающую с `runtime.test_database`, отличную от preview и имеющую `_test_` в имени. Затем поднять локальный PHP сервер на 127.0.0.1:8102 и выполнить `npx playwright test tests/Browser/E1-02/onboarding-e2e.spec.ts`. UI fixture использует отдельный Vite порт 5184. Параметры и секреты не записаны в git.
