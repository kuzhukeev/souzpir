## Принято по умолчанию
- Scope карточки не включает `routes/` и `app/Seller/Channels/Email/`: новый экран, меню действий и тестовую отправку реализовал без новых маршрутов и без правок `PriceMailSender` — всё через существующие `GET/POST` каталога с ветвлением по `view`/`action`, чужие файлы не трогал.
- «Отправить себе» использует тот же путь доставки, что и боевой `send_price` (без форсированного fake-mailer) — он уже безопасен по умолчанию через `seller.email_price_enabled=false`; отдельный «безопасный» режим потребовал бы правки `PriceMailSender.php` вне scope.
- «Частота обновления» на экране настроек отражает и меняет интервал существующей YML-ссылки; без подключённой ссылки поле отключено с подсказкой (нет отдельного поля для XLSX/CSV-импорта — он остаётся ручным).
