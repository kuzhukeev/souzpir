## Принято по умолчанию
- «Отправить себе» отправляет тестовое письмо на email текущего пользователя через безопасный array-mailer (по аналогии с `/seller/channels/email/test`), а не через боевой SMTP бренда — чтобы клик в кабинете не мог случайно отправить реальное письмо.
- «Частота обновления» на экране настроек отражает и меняет интервал существующей YML-ссылки; без подключённой ссылки поле отключено с подсказкой (нет отдельного поля для XLSX/CSV-импорта — он остаётся ручным).
