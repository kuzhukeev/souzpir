# SP-E4-06F · Импорт документов

## Сделано
- Сопоставление показывает исходные фрагменты и предложения в двух колонках; выбранные фрагмент и факт выделяются.
- Исходный текст сохраняется при редактировании предложения; отклонение убирает связанную пару.
- Число извлечённых фрагментов сохраняется в БД при просмотре файла и листа и отображается после перезагрузки.
- Миграция добавляет nullable fragments_count; старые записи без счётчика отображают «—».
