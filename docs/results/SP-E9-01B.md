# SP-E9-01B — сквозной fake-замер и публикация

- Локальный реальный сервер с HTTPS: анкета, создание и выбор вопроса, утверждение модели, fake-замер, подтверждение снимка, внутренний отчёт, публикация и открытие ссылки без входа; полный текст ответа в публичной версии отсутствует.
- Проверены ошибочный запрос (422), запрет записи наблюдателю (403) и доступ к чужому отчёту после смены бренда (404). Тестовые знания, грант и ответ подготовлены фикстурой; внешние запросы браузера, реальная почта и живой AI отключены.
- Изолированная PostgreSQL: Playwright, Node HTTPS proxy и PHP server на свободных портах; `npm run build`, TypeScript, ESLint, Pint, разбор YAML. Опциональный ручной CI `acceptance_e901b` создаёт отдельные БД и роль; CI после push не ожидался.
