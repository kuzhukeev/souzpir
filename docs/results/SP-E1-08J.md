# SP-E1-08J — объединённые тестовые сводки

- Fake-доставка объединяет новые seller-события и другие события бренда; без личного времени используется время seller или 09:00.
- Сформированные ожидающие seller-пакеты переносятся в общую очередь без повторной доставки уже поставленного события; тихие часы, права и настройки проверяются перед отправкой.
- Проверки: PHPUnit — 5 тестов, 33 проверки на изолированной PostgreSQL, включая старый пакет, дубль, бренды, права и ошибки; Playwright — 1; Pint.
- Скриншот: `.local/screenshots/SP-E1-08J/timing.png` (светлая тема, 1440).

## Ограничения
- Действует только при fake-драйвере и включённой seller-сводке; реальные доставки не менялись.

## Техдолг
- Для каждого ожидающего уведомления отдельно проверяются правила seller; при больших очередях потребуется пакетная загрузка.

## Принято по умолчанию
- Если получателю доступна seller-сводка по каналу и личное время не задано, другие события того же бренда и канала объединяются с ней.
- Сформированный пакет после переноса помечается отменённым с причиной `moved_to_fake_digest`, отправляется общая запись.

## Нужно от интегратора
- Удалить устаревшую подпись «Тестовые сводки ... формируются отдельно» в `resources/js/pages/Shell/Profile/NotificationTimingForm.tsx`: файл вне scope карточки.
