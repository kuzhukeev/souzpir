# SP-E6-03T — задача после напоминаний

- После последнего fake-напоминания задача менеджеру создаётся по истечении настроенного интервала, если клиент не ответил и диалог подходит по настройкам и исключениям.
- Настройка времени добавлена на экран; действующие задачи и уже обработанное напоминание повторно не создаются.
- Проверки: PHPUnit — 6 тестов, 66 проверок на изолированной PostgreSQL (fake-доставка, ответ клиента, права, бренды, ошибки); Playwright — 1; TypeScript, ESLint, Pint и генерация типов.
- Скриншот `.local/screenshots/SP-E6-03T/settings.png` (светлая тема, 1440); условия сверены с D-5.5 в журнале макетов.

## Ограничения
- Обработка происходит при очередном запуске существующего планировщика напоминаний; реальные отправки не выполнялись.

## Техдолг
- Для каждого подходящего диалога отдельно читаются последнее сообщение, напоминание и задача; при большом объёме понадобится пакетная обработка.

## Принято по умолчанию
- Интервал задачи — 24 часа после последнего напоминания, настраивается в пределах 1–720 часов; при нуле допустимых напоминаний задача не создаётся.
- Окно отправки ограничивает напоминания, а не создание внутренней задачи.

## Нужно от интегратора
- Нет.
