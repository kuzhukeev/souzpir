# SP-E5-03F — model Guard для последующих ходов

- Последующие API-ходы, подсказки и симуляция при включённом model Guard проверяют ответ через fake Gateway; перед каждым этапом заново подтверждаются источник, права, бренд и результат предыдущего этапа. Отказ или недоступность Guard не приводят к отправке.
- Старый транзакционный API-путь больше не создаёт фиксированный ответ или подсказку; прежние квитанции повторяются, режимы менеджера и выключенного расписания сохраняют поведение.
- PHPUnit: 10 тестов, 160 проверок, в том числе разрешение и отказ model Guard, повторы API и симуляции, роли режимов менеджера и расписания. Browser E5-03F: 1/1; Pint и ESLint прошли. Внешних вызовов нет.

## Остаток
- Защищённые вызовы инструментов последующих ходов: передача разрешённых инструментов в responder, проверка и выполнение полученных вызовов, обработка результата и повторный ответ.
- Повторная генерация после отказа детерминированного или model Guard с проверкой итогового ответа; сейчас отказ безопасно завершает ход без отправки.

## Принято по умолчанию
- При отсутствии подтверждённого результата Guard ответ не сохраняется и не доставляется.
