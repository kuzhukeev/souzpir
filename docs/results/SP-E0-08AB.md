# SP-E0-08AB — browser CI, сверка остатка с main

Первый этап (E4-08/fewshot-more) был сдан и влит ранее. В этом проходе сверены с текущим `main` (1bf280c9) оставшиеся пункты карточки, запуском Playwright на своём порту без живых вызовов. Код не менялся — пункты реально падают по разным причинам в разных модулях, фикс каждого выходит за объявленный scope (чужие страницы/компоненты) и требует отдельной узкой карточки по правилам очереди.

## Результат сверки (все падения подтверждены на main)

- Шард 2: `E4-08D/fewshot` (оба теста), `E4-10C/fewshot`, `E4-10E/sandbox`, `E5-01G/channels`, `E5-01I/channels`, `E5-07B/preview`, `E5-07C/preview` — все 8 падают (локаторы не находят элементы, вёрстка/тексты ушли вперёд теста).
