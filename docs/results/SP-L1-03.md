# SP-L1-03 · Согласие бренда на передачу данных в ИИ

Сделано:
- Раздел настроек бренда «Передача данных в ИИ» (вкладка на Settings.tsx): 4 переключателя (conversation_content, knowledge_internal, vision_question, knowledge_public). Проверено: UI через `AiDataPolicy.tsx`, пропсы `aiDataPolicy`/`permissions.manageAiPolicy` из `BrandSettingsController::show`.
- `BrandAiPolicy` (action) + `BrandAiPolicyController` (PATCH `/brands/{brand}/settings/ai-policy`): пишет `settings.ai_data_policy[класс] = ['any']|[]` в формате, который читает `Gateway`. Менять может только владелец (role owner), 403 для остальных — серверная проверка через `Membership`. Проверено тестом `test_owner_sees_deny_default_and_can_allow_a_class`, `test_admin_and_member_cannot_change_ai_policy`.
- Команда `brand:ai-policy {brand} --allow= --deny=`: без опций печатает текущую политику, неизвестный класс — ошибка, по умолчанию deny. Проверено `test_console_shows_current_policy_and_applies_allow_and_deny`.
- Триггер `vision_policy_change_guard` при активных vision-грантах: ошибка Postgres (`P0001`) перехватывается и превращается в понятное сообщение (422 для веб, ненулевой код для консоли), без 500. Проверено `test_changing_knowledge_public_while_a_vision_grant_is_active_is_blocked_with_a_clear_message`.
- Аудит через существующий `AuditWriter` (`brand.ai_policy.updated`).
- Изоляция брендов другой организации — 404. Проверено `test_brand_of_another_organization_is_not_reachable`.
- Интеграция с `Gateway::assertLiveAllowed` — тест через reflection на приватный метод: без согласия — `LogicException` с нужным сообщением, с согласием — проходит. Проверено `test_gateway_rejects_live_call_without_policy_and_allows_it_once_granted`.
- Валидация: отсутствующие/не-boolean поля — 422 без мутации. Проверено `test_update_rejects_missing_or_non_boolean_fields_without_mutation`.

Тесты: `tests/Feature/Launch/L1-03/BrandAiPolicyTest.php` (7 тестов, все проходят), регресс `tests/Feature/Shell/Brands/BrandSettingsTest.php` (44 теста) не задет. `check frontend` (lint/typecheck/test/build) rc=0, `check lint` (pint/composer validate) чисто.
