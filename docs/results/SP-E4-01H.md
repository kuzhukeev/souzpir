# SP-E4-01H — частично

- Добавлена выгрузка JSON существующего черновика со снимком знаний и метаданными фактов; доступ ограничен правом изменения и текущим брендом.
- Экран предлагает скачать копию, объясняет невозможность автоматического восстановления и блокирует создание нового черновика при существующем. Уточнено, что текущий тестовый прогон не проверяет содержимое черновика.
- Проверки: DraftBackupTest, ReleaseContinuationTest, GeneratedTypesTest — 5 тестов, 52 утверждения; Playwright E4-01H, TypeScript, ESLint, Pint; типы маршрутов перегенерированы.

## Остаток
- полноценный fake-прогон продавца по черновику и смысловые критерии; автоматическое сохранение и восстановление черновика при откате.

## Техдолг
- Выгруженную копию нельзя автоматически импортировать; существующий черновик при этом не изменяется.

## Принято по умолчанию
- При наличии черновика откат остаётся недоступен; скачивание копии само по себе не завершает и не публикует его.

## Нужно от интегратора
- Расширить защищённый runtime выбором черновика и подключить SimulationRuntime; определить контракт архивирования/восстановления второго черновика и выделить продолжение.
