# Защита трасс границ Seller

Изолированное исправление относительно `933b764`, предложено интегратору на review. Не является завершением SP-E3-03B и не подключает Seller runtime.

Публичные границы `InboundRecorder::record/ingest` и `EloquentConversationRepository::claimTurn/commitTurn` скрывают чувствительные параметры и отбрасывают внутреннюю цепочку исключений: вложенные ошибки JSON и PostgreSQL могут содержать входящие тексты, payload, результат обработки и привязки SQL. Сохраняются статусы HTTP, класс отсутствующей модели и класс ошибок логики; конкретные сообщения заменяются общим текстом, кроме фиксированного сообщения `Active brand is required.`, используемого проверкой гонки. Неизвестные ошибки возвращаются как `RuntimeException` без `previous`. Это намеренно уменьшает диагностичность; перед расширением runtime требуется безопасный способ наблюдаемости без содержимого сообщений и SQL bindings.

`PrivateTraceTest` принудительно включает запись аргументов исключений для каждого теста и восстанавливает настройку. Проверяются строковое представление, сериализуемые аргументы Seller-кадров и отсутствие `previous` для конфликтов, невалидного UTF-8, отказа PostgreSQL на NUL в JSON и ошибки результата; токен claim, текст и синтетические данные не должны появляться. Подмена изменённых файлов исходниками `933b764` на время контрольного прогона дала два ожидаемых падения: входящий текст отображался в трассе, невалидный результат выбрасывал исходный JsonException. Тестовые данные синтетические, внешние вызовы не выполнялись.

Тестовая PostgreSQL `souzpir_test_sp_trace` отделена от рабочего `souzpir_dev`, до запуска проверены `base_path` и реальный `current_database()`. Composer `vendor` физически скопирован в worktree, без junction/symlink на другой checkout. Все 23 теста каталога `tests/Feature/Seller/Conversations` прошли, 140 проверок, в том числе пять двухпроцессных сценариев; Pint и `git diff --check` пройдены. Основной checkout и рабочая БД не изменялись.

Ограничения: тесты не доказывают отсутствие утечки в вызывающем коде или сторонних обработчиках до вызова этих границ. Не исправлены устаревшая финализация при новом входящем сообщении, авторизация фонового principal, fence, учёт эффектов и reconciliation. Запуск настоящих AI/каналов и маркировка задачи как готовой по-прежнему запрещены до полного контракта и отдельной проверки.
