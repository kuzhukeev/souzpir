# SP-E5-04Q — шаблоны диалога

- Добавлено создание, редактирование и удаление шаблонов фраз для выбранного бренда; их можно вставить в ответ.
- Данные сохраняются в приватном локальном хранилище Laravel по организации и бренду; доступ к изменению ограничен правом работы с диалогами.
- Проверки: PHPUnit — 1 тест, 36 проверок (сценарий, права, изоляция брендов, ошибки ввода); Playwright — 1 сценарий; TypeScript, ESLint, Pint; типы маршрутов обновлены.
- Скриншот: `.local/screenshots/SP-E5-04Q/templates.png` (светлая тема, 1440).

## Остаток
- Генерация подсказки для manager через общие AI-стадии ожидает решения владельца; предложение новой задачи — подключить её после решения.

## Техдолг
- Локальное файловое хранилище требует сохранения и резервного копирования каталога private при переносе приложения; несколько серверов требуют общего хранилища.

## Принято по умолчанию
- Для нового бренда доступны прежние две стандартные фразы; после сохранения пустого списка показывается пустой список.
- Не более 50 шаблонов, название до 100, текст до 5000 символов; имя клиента подставляется как прежде.

## Нужно от интегратора
- Завести карточку продолжения по генерации подсказки manager после решения владельца об AI-стадиях; обеспечить постоянство приватного хранилища.
