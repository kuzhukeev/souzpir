# SP-E8-12C — обзор аудита сайта (частичная сдача)

- V-8.1: кольцо точной оценки, дата последней проверки и дельта к предыдущей проверке того же URL; диапазон и несопоставимые данные не превращаются в выдуманную оценку.
- Контроллер выбирает последние две проверки только текущего бренда; существующие группы выводятся с исходной семантикой.
- Проверки: PHPUnit 3 теста / 45 проверок (бренд, права, ошибки URL); Playwright 2; TypeScript, ESLint, Pint.
- Скриншот компонента V-8.1, fixture, светлая тема 1440: `.local/screenshots/e8-12c/overview.png`; макет журнала [115].

## Ограничения
- Частичная сдача: V-8.2–V-8.5 и V-9.1–V-9.2, включая очередь и этапы аудита, не завершены; аудит пока синхронный.
- Группы из SiteInspector сохранены без переименования: соответствие пяти группам макета не согласовано.

## Техдолг
- Изменение показывается только для точных оценок одного URL; сопоставимость методик и охвата требует отдельного контракта.

## Принято по умолчанию
