# SP-E3-05B — отправка напоминаний

- Планировщик подготавливает кандидатов и ставит отправку в очередь; job использует только FakeChannelDelivery.
- Перед доставкой повторно проверяются бренд, настройки, режим и актуальность кандидата; после успеха сохраняются сообщение, счётчик и отметка согласованной даты.
- При достижении лимита создаётся задача stale; повтор завершённого кандидата не отправляет сообщение заново.
- FollowupSendTest и FollowupJobTest: 4 теста / 23 проверки, включая отказ, повтор, чужой бренд и устаревший диалог; warnings отсутствует .env.testing. Pint пройден.
- Скриншоты не применимы: интерфейс не менялся.

## Ограничения
- Используется только fake Delivery, живые отправки не подключены.

## Техдолг
- Повторная обработка больших очередей кандидатов с синхронным драйвером может потребовать следующего запуска планировщика.

## Принято по умолчанию
- Задача stale создаётся сразу после успешного последнего разрешённого напоминания; согласованная дата отмечается флагом прототипа.

## Нужно от интегратора
- При подключении живого транспорта использовать защищённый канал доставки и отдельно согласовать его включение.
