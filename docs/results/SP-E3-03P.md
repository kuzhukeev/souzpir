# SP-E3-03P — защищённая запись обещания

Сделано: внутреннее действие `CreatePromise` читает исходный вызов `create_promise` через защищённый Gateway в проверенном первом ходе, записывает задачу продавца и обещание в состояние лида одной транзакцией, пишет аудит. Повтор с тем же ключом возвращает прежний результат, несовместимый повтор отклоняется.

Тесты: `tests/Feature/Seller/Engine/CreatePromiseTest.php` — 4 теста, 29 проверок, PostgreSQL; сценарий и повтор, чужой бренд, подмена claim, устаревший ход, отозванная сессия, отключённый модуль, неверный индекс. Pint на изменённых PHP-файлах; `git diff --check`.

Ограничения: действие пока не вызывается оркестратором первого хода и не завершает ход; пользовательского экрана нет, поэтому скриншоты неприменимы. Это работающая внутренняя часть задачи; подключение и завершение требуют следующей задачи.
