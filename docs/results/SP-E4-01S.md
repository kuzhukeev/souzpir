# SP-E4-01S — контекстные фикстуры

- Каталог расширен до 26 примеров полной карточки и 35 остальных контекстных примеров. Вместе с принятыми P/Q/R каждый критерий каждой персоны имеет явный пример или результат «неизвестно».
- Поля карточки взяты из personas.yaml, полнота — из REQUIRED/contact/full_card оригинального tools/report.py. Отсутствующие факты клиента не дописаны.
- События передачи, контакта и напоминания явно синтетические. Для 20 примеров нет завершения либо подтверждённых условий: оценка не создаётся.
- Проверки: DraftSeedFixturesE401STest — 3 теста, 502 утверждения; проверены права, другой бренд, полнота покрытия и отказ FakeDriver при изменённых доказательствах; Pint.
- Существующий скриншот `.local/screenshots/sp-e4-01s/run.png` иллюстрирует учебный пример, не живой прогон.

## Техдолг
- Каталог остаётся учебными данными: подключение к runtime принадлежит ранее заведённой SP-E4-01O и не менялось здесь.

## Принято по умолчанию
- Неизвестное не равно ошибке или успеху. Фактические тарифы, скидки, логистика и правовые условия не выдумываются.
- Полная завершённая карточка проверяется по сохранённым репликам; незавершённый диалог не получает итоговой оценки.
