# SP-E9-02C — результат

- Импорт организации и её брендов из подготовленной SQLite в отдельную локальную тестовую PostgreSQL; batch и повтор без дублирования.
- Откат сверяет снимки записей и зависимости по FK, при конфликте не удаляет данные; обе команды запрещены вне тестовой базы.
- Проверка: Pest tests/Unit/Migration — 12 тестов, 35 проверок; Pint; отдельный PostgreSQL и синтетическая копия, без внешних сервисов.
- Ограничение: имена и владелец только; membership и прочие данные не переносятся. Полноценный импорт и откат не готовы; предложить продолжение отдельной задачей.
- UI отсутствует; скриншоты не применимы.

## Техдолг
- Зависимости внутри JSON и вне внешних ключей откатом не обнаруживаются.

## Принято по умолчанию
- Повтор той же копии возвращает существующий batch; копия с изменённым содержимым отклоняется.

## Нужно от интегратора
- До рабочего переноса согласовать дополнительные поля, membership и проверку зависимостей вне FK.
