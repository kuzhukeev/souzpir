# SP-E5-08C — экспорт клиентов
- Общий архив продавца содержит customers.csv и customers.xlsx; records.jsonl сохранён для совместимости.
- Экспортируются контакты текущего бренда с городом; на странице клиентов есть переход к архивам.
- PostgreSQL: CustomerArchiveTest — 1 тест / 33 проверки, предупреждение об отсутствующем .env; проверены CSV/XLSX, изоляция, доступ, скачивание и пустой архив.
- Playwright E1-11 — 1 тест, 3 темы и 3 ширины; XLSX открыт openpyxl; ESLint, TypeScript, Pint и production build.
