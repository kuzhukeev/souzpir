# SP-E6-07: результат

Реализованы фактические лимиты и настройки уведомлений продавца, включая роли, каналы, персональный opt-out, выбор ежедневного времени в часовом поясе бренда, кабинетные сводки и тестовую доставку текущему пользователю. Реальные письма, Telegram и LLM при работе не отправлялись.

На выделенной базе PostgreSQL с временно подключённым общим NotificationRouter: 23 теста, 196 проверок, включая идемпотентность, гонки слотов, DST, отзыв доступа и неопределённые сетевые исходы. TypeScript, production build и браузерный сценарий сохранения выбранного времени, тестовой доставки и списка сводок прошли; экраны проверены на 1440/1024/390, с axe. Снимки: .local/screenshots/e6-07/.

До интеграции требуется основной router, session lease для мутаций, проверки включённого модуля при маршрутизации и перед доставкой, пункт навигации для получателей без права настройки, CI и повторный сквозной прогон. Сводки до этих проверок выключены по умолчанию. Контракты и особенности указаны в docs/modules/E6-07.md.
