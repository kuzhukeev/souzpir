## Техдолг
- `IntegrationsController::secret()` всегда отдаёт 503 для `type=webhook_secret` (строка ~104); ветка фактически недостижима из фронтенда (`integration_webhook_secret_available` зашит в `false`). Снятие 503 потребует также починки `activeApiKey()`, которая проверяет формат `id|token`, неприменимый к вебхук-секрету — отдельная небольшая задача, не нужна для работы реальной доставки.
