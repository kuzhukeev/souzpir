Модель: Terra

## Сделано
- Отчёт показывает до пяти сохранённых критериев с их фактическими статусами без свидетельств и секретных данных.
- Пять групп соответствуют идентификаторам инспектора; шкала каждой группы — 20 баллов с диапазоном при неполных данных. Отдельная проверка понимания ИИ остаётся отложенной.
- Важность показана числовым весом инспектора; для 16 проверок добавлены пояснённые примеры кода. Старый блок скорости удалён, фикстуры H/J/L обновлены.
- V-5.7: сохранённые приоритеты и шаги рекомендаций остаются привязанными к исходному подтверждённому отчёту; неподтверждённые значения не рассчитываются.

## Проверки
- PostgreSQL: 15 тестов, 217 проверок (права, бренд, ошибки, безопасная проекция); внешние запросы fake.
- Playwright E8-21H/J/L — 3 сценария; Vitest — 4 теста; TypeScript, ESLint, Pint.
- Скриншот `.local/screenshots/sp-e8-21h/audit.png` (светлая тема, 1440).

## Принято по умолчанию
- Равные веса не задают ранжирование: в отчёте выводятся первые пять проверок по ID; кодовые примеры иллюстративны и не выдаются за факты сайта.

## Нужно от интегратора
- V-5.7: для расчёта приоритета по отставанию нет сохранённого сопоставления конкурентов с критериями сайта и утверждённой формулы; приоритет и шаги остаются отсутствующими там, где их нет в подтверждённых данных.
