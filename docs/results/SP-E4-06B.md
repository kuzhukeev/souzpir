# SP-E4-06B · Импорт сайта в черновик

Подключён SiteKnowledgeImporter для одной страницы сайта бренда; приватный снимок показывается как предложения, в черновик попадают только выбранные строки. Перед сохранением повторно проверяются доступ и версия источника.
У факта источник url; точный адрес и версия источника связаны с фактом через аудит. Публикации нет. PDF/DOCX отмечены как будущая функция.
Проверки: SiteImportsTest — 1 тест, 19 проверок: fake crawler без сети, явный выбор, источник, изоляция бренда, отзыв доступа, ошибка URL и синтетический XLSX; TypeScript, ESLint, Pint, генерация типов.
Снимок: .local/screenshots/sp-e4-06b/site-import-1440.png (светлая тема, демонстрационные данные).
Ограничения: импортирует одну страницу за запрос, до 100 строк; длинные строки ограничиваются 500 символами.

## Техдолг
- URL источника доступен через аудит, в самой записи факта сохраняется только тип url: схема kn_facts не содержит адреса.

## Принято по умолчанию
- Каждый непустой фрагмент текста страницы предлагается как отдельный факт; выбор листа XLSX остаётся первым листом.

## Нужно от интегратора
- Для показа точной ссылки непосредственно в карточке факта потребуется расширение общего контракта/схемы; подключить ссылку на раздел импорта в общей навигации.
