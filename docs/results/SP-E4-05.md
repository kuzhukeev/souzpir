# SP-E4-05 — закрытые темы и Guard

- Добавлен редактор существующих закрытых тем, режима block/warn запрещённых обещаний и лимита слов в черновике.
- Тесты: ProhibitionsTest — 2 теста, 28 проверок, включая три случая предупреждений Guard, права, изоляцию, ошибки и конфликт версии.
- Проверки: Pint, TypeScript, ESLint экрана, генерация типов маршрутов.
- Скриншот: .local/screenshots/sp-e4-05/prohibitions-1440.png (светлая тема, демонстрационные данные).
- Ограничения: отключение правил и редактирование паттернов недоступны; действие после закрытой темы сохраняется, но runtime его не применяет.

## Техдолг
- Предупреждения Guard проверены на движке; запись предупреждений в runtime зависит от общего конвейера.

## Принято по умолчанию
- Для существующей темы без next предлагается возврат к разговору; паттерны доступны только для чтения.

## Нужно от интегратора
- Подключить действие closed_topics.next и enabled в Guard/runtime; добавить ссылку на экран и отдельную задачу для оставшейся части редактора.
