# SP-E5-02 — установка виджета
- Настройки бренда: разрешённые адреса сайтов, ключ и сниппет, отметка обнаружения, внешний вид, таймер и прокрутка приглашения.
- Публичный загрузчик без React проверяет origin, получает настройки и отображает кнопку; до подключения переписки честно показывает её недоступность.
- Проверено: 2 теста / 42 проверки, 2 предупреждения Pest; загрузчик, origin, права, изоляция бренда и ошибки ввода; TypeScript, ESLint, Pint, типы маршрутов.
- Загрузчик: 1477 байт gzip. Предпросмотр в браузере с fake config: открытие/закрытие; скриншоты `.local/screenshots/sp-e5-02/settings-1440.png` и `widget-1440.png` в основном checkout.
- Ограничения: сессии посетителей, переписка и полный e2e №7 не реализованы; сбор контакта, согласие, остальные триггеры и отдельная TS-сборка отсутствуют.
## Техдолг
- Отметка обнаружения показывает последний корректный запрос конфигурации, а не подтверждение полноценного диалога.
## Принято по умолчанию
- Виджет выключен до настройки; разрешены точные HTTPS-origin и локальный HTTP для разработки.
