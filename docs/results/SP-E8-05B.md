# SP-E8-05B — конкуренты и источники
- Восстановлены разделы последнего подтверждённого снимка: компании, поиск, отслеживание, детали, источники и отметки присутствия.
- Объединение названий сохраняет алиасы и отслеживание в одной транзакции по бренду; показатели раздела пересчитываются штатным VisibilityMetrics, без двойного подсчёта ответа.
- Сравнение двух компаний показывает ответы, долю голоса и модели из снимка.
- Площадки с отмеченным отсутствием сортируются по числу цитирований; неизвестное присутствие не считается отсутствием.
- Проверено: PostgreSQL, 3 теста / 89 проверок, 3 предупреждения Pest; метрика на фикстуре, CRUD на фиктивном снимке, реальное пустое состояние, права и бренд; TypeScript, ESLint, Pint и типы.
- Скриншоты: `.local/screenshots/sp-e8-05b/competitors-1440.png`, `sources-1440.png`, `compare-1440.png` основного checkout; демонстрационные данные, светлая тема, 1440.
- Ограничения: полная матрица сравнения и история замеров, подробная карточка площадки и действия не реализованы; рейтинг не учитывает присутствие конкурентов.
- Общий набор Product не запускался по требованию запускать только тесты задачи.
## Техдолг
- Исходный неизменяемый отчёт не пересчитывается после объединения; алиасы применяются при чтении этого раздела.
## Принято по умолчанию
- Если опубликованного снимка нет, показывается пустое состояние; маркировка площадки вводится пользователем.
## Нужно от интегратора
- Подключить алиасы к пересборке подтверждённого отчёта в общем Vision Core; вынести оставшиеся сравнения и рекомендации в продолжение.
