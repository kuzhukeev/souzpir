## Техдолг
- Judge текстовый, не ИИ-оценка смысла; реальный Judge с LLM и живая доставка входов из прототипа — отдельная операторская задача после разрешения владельца.

## Принято по умолчанию
- Сравнение детерминированное (нормализация регистра/пробелов), без обращения к AI Gateway/FakeDriver — избегает фикстур и стоимости ИИ, которую не нужно выдумывать для MVP.
- Входные данные (текст прототипа/движка) передаёт оператор вручную через `shadow:record`; автоматической доставки трафика прототипа нет — это часть живого операторского этапа вне scope.
