- В настройках активного Telegram-канала добавлена регистрация вебхука через существующий endpoint; показаны ожидание и ошибка.
- Кнопка доступна только пользователю с правом управления.

## Ограничения
- Защищённый seller runtime требует активную браузерную сессию, а Telegram webhook выполняется в публичном контексте. Входящие ходы и исходящие ответы не подключены; задача выполнена частично.

## Техдолг
- Отсутствует доступный внутренний entrypoint защищённого runtime для событий каналов.

## Принято по умолчанию
- Кнопка показана только для активного канала и использует сохранённые настройки, а не несохранённые поля формы.

## Нужно от интегратора
