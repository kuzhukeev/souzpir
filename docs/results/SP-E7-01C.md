# SP-E7-01C · Переходы из оценки

В существующей панели оценки для замечаний отдельных оценок добавлен переход во входящие базы знаний с ID оценки в адресе; пустая оценка отображается без ссылки. Оценка открывается существующей панелью D-7.3.
Проверки: QualityLinksTest — 1 тест, 34 проверки (день, пустая оценка, права, изоляция, неверная дата); TypeScript, ESLint, Pint; браузером проверены открытие панели и адрес ссылки.
Снимок: .local/screenshots/sp-e7-01c/evaluation-1440.png (светлая тема, демонстрационные данные).
Ограничения: точное предложение пока не выделяется; замечания отдельного supervisor-доклада не являются seller_evaluations и не связаны со входящими.

## Техдолг
- Обработанная оценка может больше не находиться во входящих; экран знаний не сообщает об этом по переданному ID.

## Принято по умолчанию
- Ссылка называется «Открыть входящие знаний» и не обещает точного выделения.

## Нужно от интегратора
- В модуле знаний обработать параметр incoming: найти и выделить соответствующую оценку либо показать состояние «уже обработано»; отдельно связать замечания supervisor-доклада с предложениями D-4.2.
