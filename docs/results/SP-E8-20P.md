# SP-E8-20P — частичная сдача

- Динамика доли голоса ограничена пятью отслеживаемыми конкурентами текущего бренда; собственный бренд не дублируется.
- В сравнении закреплён свой бренд, доступно добавление до четырёх компаний; источники карточки оформлены таблицей с числом ответов.
- Проверено: PHPUnit — 1 тест / 2 проверки; Playwright E8-20O и E8-20P — 3 сценария; TypeScript, ESLint, Pint.
- Скриншот `.local/screenshots/SP-E8-20P/company.png`: светлая тема, 1440, фикстура.

## Остаток
- Сохранение позиции конкурента и средняя позиция, показатели по моделям и намерениям: подтверждённые позиции сейчас не записываются в данные.
- Проверить права и изоляцию брендов интеграционными тестами с изолированной БД.

## Техдолг

## Принято по умолчанию
- Из отслеживаемых конкурентов показываются первые пять по времени добавления; неизвестная позиция не выдумывается.
