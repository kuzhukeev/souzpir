# SP-E6-01D — выбор служебных фраз по событию

Сделано: `ServicePhraseSelector` выбирает сохранённую фразу для ошибки, передачи менеджеру, вне рабочего времени, неизвестного факта, отказа от сообщений, напоминания и прощания. Дефолты редактора и селектора общие; пустая сохранённая фраза не отправляется.

Проверки: `ServicePhraseSelectorTest.php` — 3 теста, 7 проверок, включая fake-последовательность событий; `PersonaTest.php` — 3 теста, 90 проверок (права, изоляция брендов, ошибки ввода); `tests/Browser/E6-01D/phrases.spec.ts` — 1 тест; `npm run typecheck`; Pint.

Скриншот редактора, светлая тема, 1440: [Служебные фразы](../../.local/screenshots/SP-E6-01D/phrases.png).

## Остаток
Продолжение: SP-E6-01E.

- Автоматическая отправка выбранной фразы клиенту при реальных событиях Runtime не подключена. Формирование и фиксация первого/последующих ответов находятся в `app/ProtectedOperations/FirstTurnTextFinalizer.php` и `app/ProtectedOperations/SellerFollowup/FollowupFinalizer.php` вне scope карточки. ## Принято по умолчанию

- Неизвестное событие не выбирает фразу; отсутствующая сохранённая фраза использует дефолт редактора.

## Нужно от интегратора
