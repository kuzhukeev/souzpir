# SP-E8-16W — события хода замера

- Фиксируется время фактического завершения слота; при обновлении данных доказательств оно не меняется. API текущего бренда возвращает первые ответ и ошибку по сохранённому времени.
- На экране события расположены по времени, ошибки и ответы выделены цветом, у состояний моделей добавлены доступные пиктограммы. Если время неизвестно, отображается отсутствие данных.
- Старым ответам время не приписывается: миграция оставляет его пустым.
- Проверено: PHPUnit MeasurementEventsE816WTest — 2 теста, 54 проверки, включая fake-вызовы, ошибки, права и бренд; Playwright — событие и отсутствие данных; TypeScript, ESLint, Pint.
