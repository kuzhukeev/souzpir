# SP-E0-05G · Стоимость AI-сверки оператору

## Сделано
- Платформенный флаг AI_RECOVERY_OPERATOR_USER_ID задаёт единственного оператора по ID пользователя; при отсутствии флага сумма не передаётся.
- Только оператор с billing.manage и действующим доступом к экрану видит суммы подтверждённых сверок текущего бренда.
- Суммы берутся только из записей с доказательством провайдера, отображаются в USD с точностью до микродоллара; неподтверждённые вызовы исключены.
- После новой сверки экран обновляется вручную; отображается до 50 последних подтверждённых вызовов.

## Проверено
- PHPUnit: 2 теста, 46 проверок (флаг, права, текущий бренд, отсутствие доказательства, пустой список); изолированная PostgreSQL.
- Playwright: 2 теста (оператор, пустое состояние, обычный владелец и прежний сценарий сверки), fake API.
- TypeScript, ESLint, Pint, git diff --check — успешно.
- Скриншот: .local/screenshots/SP-E0-05G/recovery.png (светлая тема, 1440).

## Техдолг
- Нет.

## Принято по умолчанию
- Флаг задаёт одного платформенного оператора через окружение сервера; без него доступ к суммам закрыт.

## Нужно от интегратора
- При необходимости назначить оператора серверной переменной и перезапустить приложение; SP-E0-05H отвечает за остальной клиентский API.
