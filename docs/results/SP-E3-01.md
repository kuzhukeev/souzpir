# SP-E3-01: таблицы и срезы знаний

Реализованы таблицы черновика и неизменяемых публикаций, ограниченный организацией/брендом репозиторий, редактор фактов с версиями, публикация и откат. Контракт KnowledgeSnapshot и десять YAML-секций проверены на идентичность прототипу; тестовые фикстуры скопированы из исходного архива.

Тесты: полный набор ветки — 97 тестов, 635 проверок; отдельный сценарий конкурирующих процессов PostgreSQL; проверены несовместимые версии, доступы, повторяющиеся факты, источник/статус, публикация, откат и защита от изменений опубликованных данных. Выполнен Pint.

Это инфраструктурная задача без пользовательских экранов, скриншоты не применимы. Для внешних HTTP-эндпоинтов E4 требуется проверка seller.knowledge.read; редакторские операции используют KnowledgeRepository и version для конкурентных правок. Реальные подключения LLM не выполнялись. Дальнейшая интеграция с движком и UI предусмотрена отдельными задачами. Подробности: docs/modules/E3-01.md.
