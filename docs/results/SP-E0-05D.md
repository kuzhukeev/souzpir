# SP-E0-05D

Изолированная защитная проверка дополнена после независимого ревью: raw JSON tool arguments и duplicate keys, malformed JSON, camelCase имена, quoted assignments, Unicode escapes и известные формы синтетических секретов. Добавлены положительные примеры публичного содержимого и проверка отказа до fake transport. Настоящих секретов и внешних сетевых запросов не использовали.

Профильный набор: 60 тестов, 111 проверок в изолированном окружении с zend.exception_ignore_args=0; Pint прошёл. Сквозная проверка Gateway/transport и доверенная политика источников — последующая работа интегратора. Внешний JSON должен проверяться до первоначального decode: позднее уже исчезнувшие дубликаты недоступны. При zend.exception_ignore_args=0 аргументы выше в стеке требуют отдельного SensitiveParameter и generic исключения без previous. Эвристики не гарантируют распознавание всех секретов и могут ошибочно отвергать публичный текст. Live не включён и не разрешён.
