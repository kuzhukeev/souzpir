# SP-E0-05D

Изолированная защитная проверка дополнена после независимого ревью: raw JSON tool arguments и duplicate keys, malformed JSON, camelCase имена, quoted assignments, Unicode escapes и известные формы синтетических секретов. Добавлены положительные примеры публичного содержимого и проверка отказа до fake transport. Настоящих секретов и внешних сетевых запросов не использовали.

После ревью закрыт обход коротких Bearer-токенов и Basic-учётных данных, включая пустые части и percent, HTML и Unicode; добавлены публичные отрицательные примеры. Профильный набор: 74 теста, 137 проверок в изолированном окружении с zend.exception_ignore_args=0; Pint прошёл. Сквозная проверка Gateway/transport и доверенная политика источников — последующая работа интегратора. Внешний JSON должен проверяться до первоначального decode: позднее уже исчезнувшие дубликаты недоступны. При zend.exception_ignore_args=0 аргументы выше в стеке требуют отдельного SensitiveParameter и generic исключения без previous. Эвристики не гарантируют распознавание всех секретов и могут ошибочно отвергать публичный текст. Live не включён и не разрешён.

Интеграция: Gateway вызывает проверку до создания ai_calls и транспорта; набор Gateway/Privacy/Secrets прошёл 108 тестов и 362 проверки с zend.exception_ignore_args=0. Внешние отправки не выполнялись. Вышеописанные ограничения классификации и сырого JSON сохраняются.
