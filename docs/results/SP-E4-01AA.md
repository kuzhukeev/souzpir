# SP-E4-01AA — откат и история версий

- Экран отката использует явный метод репозитория rollbackToDraft: прежний черновик сохраняется, активная публикация не изменяется.
- Из публикации восстанавливаются отключённые факты, их логические идентификаторы и источники. Прежний rollback для Vision сохраняет активацию опубликованной версии.
- Неподтверждённые показатели диалогов и качества, а также автор и время отдельных строк diff отображаются без выдуманных значений.
