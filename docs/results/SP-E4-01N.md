# SP-E4-01N · Фикстуры прогона черновика

- Подготовлен проверяемый каталог полей для 28 сидированных персон; фикстура применяется только при совпадении персоны, поля и сохранённого значения текущего бренда.
- При отсутствии первого сообщения прогон начинает с имеющегося факта персоны; опубликованные знания не подменяются.
- Без фикстуры доступны проверяемые критерии числа вопросов и отсутствия HTML; произвольные смысловые критерии остаются неподтверждёнными.
- Проверки: DraftSeedFixturesE401N, DraftFixtureRuntimeE401M/L, ReleaseContinuationTest — 6 тестов, 244 проверки; Playwright E4-01N — 2 теста; TypeScript, Pint, генерация типов.
- Скриншоты 1440: `.local/screenshots/sp-e4-01n/run.png`, `restore.png`.

## Остаток
- Нужны проверенные записи смысловой оценки для полного набора персон и недостающих полей; автоматически оценивать их без источника нельзя.
- Общие protected first-turn стадии требуют TurnClaim опубликованного релиза и не подключены к черновику; действует изолированный session-bound fake-адаптер.
