# SP-E7-03C · Сравнение и калибровка

Сравнение принимает два выбранных набора прогонов, группирует реальные оценки по сценарию, показывает итог и изменения; непарные значения остаются пустыми. В калибровке доступны реальные диалоги со ссылкой, пакетное сохранение до 100 оценок и график расхождений; симуляции не выдают за диалоги.
Проверки: CalibrationTest и CompareTest — 5 тестов, 82 утверждения, включая изоляцию и права (предупреждения об отсутствующем .env); Chromium — 2 сценария; Pint, ESLint, TypeScript.

Сверка (fixture, светлая тема 1440):
- `.local/screenshots/e7-03c/compare.png` ↔ `142/fbe10b64-D-7.7-compare.webp`.
- `.local/screenshots/e7-03c/calibration.png` ↔ `143/88849080-D-7.8-calibration.webp`.

## Техдолг
- Постоянной сущности набора прогонов нет: два набора задаются явным выбором прогонов на странице.

## Принято по умолчанию
- При нескольких прогонах одного сценария сравнивается средняя оценка; для непарного сценария разница не рассчитывается. Для ещё не оценённых прогонов предлагается оценка 3.
