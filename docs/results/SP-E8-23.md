## Техдолг

После повторного редактирования завершённого действия `updated_at` перестанет отражать момент завершения; отдельного timestamp завершения в схеме нет.

## Принято по умолчанию
Стек намерений нормализован по сумме значений каждого замера: намерения могут пересекаться и исходные проценты не обязаны давать 100 %.
Для точной аннотации момента выполнения используется `actions.updated_at`, поскольку `completed_at` хранит только дату.
