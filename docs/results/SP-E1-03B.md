# SP-E1-03B — смена бренда и возврат на главную

- Запрос переключателя с ключом контекста перенаправляет на именованный маршрут dashboard; старый прямой POST без ключа — на auth.ready для совместимости существующих сценариев.
- Переключатель доступен, когда маршрут главной опубликован; перед сменой отменяются Inertia и React Query запросы, очищается кэш. После ответа очищается история Inertia.
- Проверены новый бренд на главной, отказ при отсутствии доступа и отсутствие данных прежнего бренда.
- Тесты: PHPUnit 44 / 491 утверждение (22 своих и 22 из трёх красных CI-файлов), Playwright 1; TypeScript, ESLint, Pint.
- Скриншоты: .local/screenshots/SP-E1-03B/brand-switch.png и brand-switch-open.png (светлая тема, 1440).
- Доработка CI: без QueryClientProvider переключатель и SSR отображаются; попытка смены блокируется с объяснением, пока нельзя гарантировать очистку прежних данных.
- Новые проверки: SSR Vitest 1/1; Playwright E1-03 и E8-18 3/3 (включая отказ без provider и очистку с provider); PHPUnit переключателя 5/56, TypeScript и ESLint.

## Ограничения
- Браузерная проверка клиента использует Vite-фикстуру; серверный маршрут проверен PHPUnit. Прямой POST без ключа оставлен совместимым со старым потоком.
