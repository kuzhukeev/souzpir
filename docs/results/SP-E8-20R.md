## Остаток
- Карточка конкурента пока показывает «Нет данных»: контроллер `app/Vision/Competitors/CompetitorsController.php` вне scope и не передаёт новые показатели на экран.
- Старые сохранённые снимки не содержат агрегатов; требуется согласовать их пересчёт из подтверждённых ответов. Показатели по конкретным моделям требуют сопоставления провайдера с моделью снимка.

## Техдолг
- Нет.

## Принято по умолчанию
- Учитываются только положительные целые позиции из полного подтверждённого списка; при отсутствии данных новые поля отсутствуют.

## Нужно от интегратора
