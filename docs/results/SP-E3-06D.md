# SP-E3-06D — адаптер симуляции (частичная сдача)

- `SimulateFakeJob` умеет передать число ходов в `RuntimeSimulation` через интерфейс `SimulationRuntime` при явном флаге; без привязанного адаптера и при живом AI включённый путь завершается ошибкой.
- По умолчанию флаг выключен, сохранён прежний `FakeSimulation`; настоящие защищённые ходы ещё не подключены.
- PHPUnit Product: 6 тестов / 36 проверок, включая изоляцию брендов, отсутствие runtime, запрет живого драйвера и существующую совместимость. Pint.
- Тестовый адаптер — заглушка, не защищённый runtime; внешние HTTP-запросы в новом тесте запрещены. Экранов нет, скриншоты не требуются.

## Ограничения
- Приёмка карточки не выполнена: нет защищённого job-entrypoint для open/turn и реальной проверки повторного ключа на защищённом пути.
- Включать флаг до появления защищённого адаптера нельзя; прежний fake-путь не является подтверждением защищённых ходов.

## Техдолг
- Конструктор job пока принимает массив старых fake-ходов; новый путь использует только их количество.

## Принято по умолчанию
- Неизвестный флаг `features.E3-06D.defaults.runtime_enabled` выключен; интеграция не меняет работу существующих вызовов.

## Нужно от интегратора
- Подключить доверенный job-entrypoint к общим защищённым стадиям, сейчас привязанным к браузерной сессии, и bind `SimulationRuntime`; проверить idempotency, открытие, последующие ходы и ошибку без живого AI. Общие стадии вне scope.
