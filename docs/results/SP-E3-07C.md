# SP-E3-07C — частичная сдача

- Добавлен тестовый офлайн-драйвер последовательности записанных вызовов: проверяет контрольную сумму, принадлежность сценарию и совпадение запроса; сетевого fallback нет.
- Проверен replay двух вызовов одного сценария, отказ при несовпадении и исчерпании записи.
- Проверки: PHPUnit `RecordedGatewayE307CTest` — 1 тест, 8 утверждений; Pint для изменённых PHP-файлов.

## Остаток
