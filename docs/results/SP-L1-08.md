# SP-L1-08 — комплект выкладки в прод

Инфраструктурная задача без экрана — сверка с макетами не требуется.

- `deploy/deploy.sh`: clone/checkout ref → composer install --no-dev → npm ci/build → migrate --force → кеш config/route/view → симлинк `current` → restart systemd+Caddy → чистка старых релизов (keep 5); секретов внутри нет.
- `deploy/rollback.sh`: откат на предыдущий релиз (`.previous-release`) одной командой.
- `deploy/systemd/souzpir-{queue,schedule}.service`, `deploy/Caddyfile.example` (Caddy сам терминирует TLS → php_fastcgi, без доверия клиентским forwarding-заголовкам по умолчанию, см. docs/runbooks/https-forwarding.md), `deploy/backup.sh` (pg_dump + ротация 14 дней через `RETENTION_DAYS`, пароль из `~/.pgpass`), `deploy/crontab.example`.
- `.env.production.example`: все env() из config/ (156 ключей, автопроверка тестом) + явные AI_BUDGET_MONTHLY_USD=30/AI_BUDGET_DAILY_USD=3 (пока не читаются кодом, добавлены по требованию карточки); APP_ENV=production, APP_DEBUG=false, LOG_LEVEL=warning, QUEUE_CONNECTION=database, живые каналы (AI/DELIVERY/NOTIFICATION/VISION) = fake/false; секреты пустые.
- `config/trustedproxy.php` (`TRUSTED_PROXIES`, default пусто/null) + принудительный `URL::forceScheme('https')` в `bootstrap/app.php` только при `APP_ENV=production`.
- `app/Http/HealthController.php` + `routes/features/L1-08.php` (`GET /health`, public-группа) + `config/features/L1-08.php` (пороги лага очереди и failed_jobs): 200/503 JSON — БД (`select 1`) и очередь (возраст старейшей `jobs`, число `failed_jobs`), без секретов. `/up` не менял.
- `docs/release/prod-runbook.md`: установка, выкладка, откат, бэкап/восстановление, включение живых флагов, HTTPS/прокси, `/health`.

## Техдолг
- `AI_BUDGET_MONTHLY_USD`/`AI_BUDGET_DAILY_USD` из карточки нигде не читаются кодом (лимиты сейчас только в БД `ai_budgets` через UI настроек) — добавлены в `.env.production.example` как документация намерения, не как рабочий конфиг; если бюджет должен настраиваться через env, нужна отдельная карточка.

## Принято по умолчанию
- Прямая схема Caddy (TLS сам + php_fastcgi) выбрана основной в шаблоне как безопасная по умолчанию без `TRUSTED_PROXIES`; схема с внешним прокси/LB — альтернатива в комментарии.
- `SESSION_DRIVER`/`CACHE_STORE`/`QUEUE_CONNECTION`=database на проде (не `file`/`sync` из `.env.example`) — обычные прод-дефолты Laravel для multi-process деплоя.
