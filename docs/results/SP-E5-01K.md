# SP-E5-01K — связь ранее сохранённого виджета

- При открытии списка каналов пользователем с правом настройки для ранее сохранённого виджета создаётся канал соответствующего бренда до первого обращения; повторное открытие не создаёт дубликат.
- Проверены отключение и повторное включение, граница бренда и существующий сценарий обращения.
- Проверки: PHPUnit, изолированная PostgreSQL: 3 теста, 97 проверок; Pint.

## Остаток
- Переключение виджета в режимы «Автономно» и «Подсказки» и автоматические ответы не включены. Публичная форма собирает контакт, а существующий FirstInboundRuntime требует авторизованную сессию; необходим согласованный публичный канал и запуск runtime без сессии менеджера. Кнопки режимов виджета остаются недоступными.
- Проверить интерфейс и макет после реализации режимов, включая browser и скриншоты.

## Техдолг
- Нет.

## Принято по умолчанию
- Связь создаётся при открытии списка каналов пользователем с правом настройки; режим нового канала — «Выключен».

## Нужно от интегратора
- Завести продолжение на остаток, определив публичный вход runtime и область связанных изменений.
