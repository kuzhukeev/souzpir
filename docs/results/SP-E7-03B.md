# SP-E7-03B · Калибровка оценок

Администратор видит оценённые прогоны своего бренда, сохраняет оценку 1–5 и комментарий; показана разница с оценкой судьи. Изменения фиксируются в аудите.
Проверки: CalibrationTest — 1 тест, 22 проверки (сохранение, сравнение, права, бренд, 2 ошибки ввода); TypeScript, ESLint, Pint, генерация типов.
Снимок: .local/screenshots/sp-e7-03b/calibration-1440.png (светлая тема, демонстрационные данные).
Ограничения: разница показана числом, без отдельной диаграммы; ссылка ведёт к списку прогонов.

## Техдолг
- Список ограничен 100 последними оценёнными прогонами.

## Принято по умолчанию
- Калибровка хранится отдельно для каждого пользователя и оценки; изменение заменяет его предыдущую оценку.

## Нужно от интегратора
- Согласовать registry.json: он указывает родителя seller_sim_turns, которого в текущей схеме нет; работающая таблица связана с seller_evaluations и через неё с seller_sim_runs. Добавить переход из общего экрана качества.
