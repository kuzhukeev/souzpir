# SP-E1-08 — безопасная смена email

- Прежние части S-7.1–S-7.3 уже в main; эта доработка меняет только подтверждение нового адреса.
- Письмо содержит подписанный адрес с токеном во fragment. GET и Inertia props не получают токен; React удаляет fragment из истории перед показом профиля.
- Подтверждение выполняется POST с токеном в теле. Middleware очищает тело до событий наблюдения запроса; проверяются текущая сессия, организация, выбранный бренд, срок и одноразовость.
- Реальный почтовый транспорт остаётся выключенным; сценарий проверен с fake sender.
- Тесты: EmailChangeTest — 13/13 (103 проверки); SecureAccountContextTest с фильтром email — 7/7 (84); Playwright email-fragment — 1/1. ESLint, TypeScript, Pint и генерация типов прошли.
- Скриншот: `.local/screenshots/sp-e1-08/email-confirm-1440.png`.
- Ограничение: при неизвестном исходе подтверждения восстановление относится к SP-E1-08B.
