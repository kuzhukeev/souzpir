# SP-E1-01F — результат

Реализованы контролируемый durable outbox восстановления, отсутствие адреса/открытого токена в payload задания и строке намерения, hash токена в стандартной таблице, одинаковый публичный ответ, ограничение частоты, срок, одноразовость и отзыв сессий. Конкурентные запросы сериализуются по пользователю; перед передачей повторно проверяются доступ, версия авторизации и HMAC адреса. Неоднозначная отправка не повторяется автоматически. SMTP остаётся выключенным и по умолчанию не привязан; фактических отправок не было.

Проверки выполняются только в отдельной PostgreSQL souzpir_test_sp_e1_01f, basePath и отличие preview проверены до миграций. Профильный набор: 8 тестов, 101 проверка, включая два конкурирующих процесса PostgreSQL и fake SMTP. Отдельно тест санитизации пройден при zend.exception_ignore_args=0: 1 тест, 8 проверок. Снимки не требуются: визуальная верстка не менялась.

Известные ограничения: URL восстановления может попасть в access logs веб-сервера/прокси вместе с email и токеном; требуется отдельное инфраструктурное решение до любого live запуска. См. docs/modules/E1-01F.md. Уже отправленное письмо нельзя отозвать; при обрыве worker требуется разбор оператором, автоматически неопределённая отправка не повторяется.

Старый tests/Feature/Shell/Auth/AuthFlowTest.php ожидает прямую Laravel Notification ResetPassword от legacy-флага; этот тест находится вне scope и должен быть адаптирован интегратором к новому fake transport/outbox. В проверке 10 прочих тестов AuthFlow прошли.
