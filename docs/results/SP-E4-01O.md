## Сделано
- В существующий session-bound fake runtime добавлено точное сопоставление проверенных пар каталога SP-E4-01Q с персоной текущего бренда.
- При изменении персоны, входа или ответа оценка из каталога не используется; черновик проверяется прежней авторизацией.
- Проверки: PHPUnit 1 тест, 11 assertions (совпадение, ошибки, права, бренд), отдельная PostgreSQL; Pint.
- UI не менялся; скриншоты неприменимы.
