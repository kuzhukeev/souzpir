# SP-E1-08C · Восстановление смены контекста

Выход и смена бренда сохраняют receipt и позволяют получить исходный результат после отзыва сессии без доступа к приватным данным. Повтор после reload сохраняет исходный ключ и цель переключения. Обновлены типы маршрутов.

Проверки: LogoutReceiptTest, BrandSwitchReceiptTest и два теста восстановления SessionIdempotencyTest — 6 проверок, 43 assertion; предупреждения об отсутствующем .env. Pint, ESLint, TypeScript, npm build; два browser-сценария Chromium прошли.
Скриншоты: `.local/screenshots/e1-08c/logout-retry-1440.png`, `.local/screenshots/e1-08c/brand-retry-1440.png`.

## Техдолг
- После потери ответа выхода и перехода на страницу входа старый маркер остаётся до повторного входа; приватные страницы закрыты.

## Принято по умолчанию
- После reload повтор запускается нажатием пользователя. Новая сессия с изменившимся XSRF очищает ключ незавершённого выхода.
