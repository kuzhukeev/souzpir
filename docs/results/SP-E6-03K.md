# SP-E6-03K — согласованное время контакта

- Для напоминаний по согласованному времени показывается сохранённое время контакта. Для напоминаний по тишине время не выдумывается; исходное время последнего ответа не подменяет план отправки.
- Массовая отправка по неподтверждённым согласиям и счётчик отписок остаются недоступными. Согласие на передачу контактов не используется как согласие на рассылку.
- Проверки: PHPUnit 5 тестов, 46 проверок (время, права, бренд, fake-транспорт); Playwright 1, TypeScript, ESLint, Pint. Скриншот `.local/screenshots/SP-E6-03K/followups.png`.

## Остаток
- D-2.5: массовая fake-отправка только по подтверждённому согласию, сохранение планового времени для всех типов отправок, реальные события отписки и их счётчик.

## Нужно от интегратора
- Для остатка необходимы подтверждённый источник согласия на рассылку, источник событий отписки и scope на миграцию для планового времени; без них нельзя корректно выбрать получателей или показать числа. Учесть остаток в существующей карточке либо конкретном продолжении.

## Техдолг
- Нет дополнительных замечаний.

## Принято по умолчанию
- `source_at` является согласованным временем только для причины `next_contact_at`; для `silence` это время исходного сообщения.
