# SP-E8-16D — ход замера

Сделано: ход замера показывает число полученных ответов и завершённых вопросов, индикатор прогресса, статусы моделей «Ожидает / Отвечает / Готово / Ошибка» по сохранённым слотам. Для активного замера есть переход к настройке уведомлений; для завершённого — к уточнениям.

Проверки: `MeasurementListTest.php` — 5 тестов, 115 проверок (права, изоляция брендов, ошибки данных); `tests/Browser/E8-16D/progress.spec.ts` — 2 теста; `npm run typecheck`.

- Статус модели с любым ошибочным слотом показывается «Ошибка», даже если другие слоты завершены успешно.

## Принято по умолчанию

- Ответы со статусами `ok`, `failed`, `uncertain` считаются обработанными; ожидающие и выполняющиеся — нет.
