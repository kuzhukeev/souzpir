# SP-E4-01M · Прогон черновика

- Fake-адаптер валидирует и применяет поля клиента, сигналы и возражения на каждом ходе к политике черновика.
- Добавлены две точные проверяемые фикстуры из сидированных персон; прочие запросы требуют совпадающих локальных фикстур.
- Без фикстуры разбора или смысловой проверки сценарий не считается пройденным; карточка прогона показывает извлечённые поля и недоступные стадии.
- Проверки: DraftFixtureRuntimeE401M/L и ReleaseContinuationTest — 4 теста, 93 проверки; Playwright E4-01M — 2 теста; TypeScript, Pint, генерация типов.
- Скриншоты 1440: `.local/screenshots/sp-e4-01m/run.png`, `restore.png`.

## Остаток
- Для полного набора сидированных персон нужны дополнительные проверенные фикстуры извлечения и смысловой оценки; у части персон нет первого сообщения.
- Общие защищённые first-turn стадии не подключены: они требуют отдельный TurnClaim опубликованного релиза и HTTP-контекст; адаптер остаётся изолированным fake-контуром.

## Техдолг
- Нет.

## Принято по умолчанию
- Встроенные фикстуры применяются только к точной фразе и допустимому ID намерения; другие данные остаются неподтверждёнными.

## Нужно от интегратора
- Оформить продолжение на каталог реальных фикстур и согласованный защищённый runtime черновика.
