# SP-E7-01 — оценки качества

- Добавлены список оценок по дням, доклад с пятью слоями и панель оценки с баллами, замечаниями и предложениями.
- Данные читаются из seller_evaluations текущего бренда; симуляции и диалоги различаются по связанному источнику.
- Тесты: QualityTest — 2 теста, 49 проверок: реальные записи, группировка, пустой день, права, изоляция, неверная дата.
- Проверки: Pint, TypeScript, ESLint экранов, генерация типов маршрутов.
- Скриншот: .local/screenshots/sp-e7-01/quality-1440.png (светлая тема, демонстрационные данные).
- Ограничения: в исходной таблице нет type=supervisor; экран не выдаёт оценки симуляций за оценки диалогов.

## Техдолг
- Без пагинации показываются последние 500 оценок бренда; старые дни могут быть неполными.

## Принято по умолчанию
- Дата группировки вычисляется в часовом поясе бренда; записи без ссылки на диалог или симуляцию отмечены как без указанного источника.
