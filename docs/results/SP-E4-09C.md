# SP-E4-09C

- Песочница читает проверенные fake-фикстуры для выбранной опубликованной версии; каждый ход использует накопленное состояние и текущую Policy.
- Сохранённые диалоги воспроизводятся по всем репликам через изолированный runtime; черновик и публикация сохраняют формат данных оценки.
- Добавлены проверенные fake-входы и результаты для запроса человека, реквизитов и крупного заказа. Уведомление о крупном заказе следует сигналу Policy; выполнение инструментов ограничено разрешёнными действиями и проверкой аргументов.
- При отсутствии результата показывается безопасный fallback; «повтори/повторите» повторяет предыдущий ответ только после проверки Guard и без повторного запуска инструментов. В инспекторе показаны выполненные тестовые действия. Golden fixtures не изменялись, реальная доставка не включалась.
