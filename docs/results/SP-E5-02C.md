# SP-E5-02C — сессия виджета
- Создаётся ограниченная сроком сессия посетителя; хранятся только хеш токена, origin и границы бренда.
- Согласие и контакт связываются с сессией; виджет показывает форму и корректную ошибку недоступного чата.
- Сообщения пока отвечают 503 без записи: существующий runtime требует сессию сотрудника и публичного адаптера нет.
- PostgreSQL: WidgetSessionTest — 1 тест / 21 проверка, предупреждение об отсутствующем .env; node --check, ESLint, Pint, генерация типов.
- Playwright: 1 browser fixture — сессия, повтор при 503 и привязка согласия; это не полноценный e2e №7.
- Скриншот `.local/screenshots/sp-e5-02c/widget-1440.png`, светлая тема, 1440, fixture.
## Техдолг
- У сессий пока нет фоновой очистки по окончании срока.
## Принято по умолчанию
- Срок сессии — 24 часа; срок действия проверяется на каждом обращении.
## Нужно от интегратора
- Расширить scope этой задачи на защищённый runtime: FirstInboundRuntime и FirstTurnCoordinator принимают только авторизованную сессию сотрудника; подключить безопасный публичный контекст, затем реализовать ход и полный browser e2e №7.
