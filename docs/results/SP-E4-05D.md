## Остаток
- Интеграционный тест защищённого Guard не запущен: тест требует непривилегированную роль PostgreSQL, имеющаяся тестовая роль — superuser. Проверить в Linux CI.

## Техдолг
- Сопоставление результатов Guard с ID правила использует описание и повторяет проверку паттерна; при изменении семантики Guard следует обновить сопоставление.

## Принято по умолчанию
- Считается одно срабатывание правила на проверенный ответ; тесты черновика и песочницы в статистику не входят.

## Нужно от интегратора
