## CI и fixture

После основной сборки приложения и layout fixture выполнить `npx vite build --config tests/Browser/E1-04/vite.config.ts`: output общий, `emptyOutDir=false`, layout не стирается. UI fixture доступна на существующем static server 5183 по пути `/tests/Browser/E1-04/ui-fixture.html`; URL можно переопределить `ORGANIZATIONS_FIXTURE_URL`.

Реальный e2e по умолчанию пропускается. Для запуска нужны отдельные testing PHP server и тестовая БД: `APP_ENV=testing`, `CABINET_ORGANIZATION_ID=01J00000000000000000000004`, `E104_FIXTURE_ENABLED=1`, `E104_FIXTURE_ORG=01J00000000000000000000004`, затем `php tests/Browser/E1-04/prepare-fixture.php`. Fixture проверяет окружение и имя тестовой БД, выполняет обычные migrations и очищает только свои synthetic записи, без migrate:fresh. Запустить отдельный сервер приложения на `127.0.0.1:8104` с тем же CABINET_ORGANIZATION_ID и testing DB, уникальными `APP_INSTANCE` и `SESSION_COOKIE`; затем `RUN_ORGANIZATIONS_E2E=1 npx playwright test tests/Browser/E1-04/organizations-e2e.spec.ts`. Адрес сервера переопределяется `ORGANIZATIONS_BASE_URL`. Fixture нельзя запускать параллельно с тестами, очищающими ту же тестовую БД.

API/jobs обязаны подключить guard по документированному контракту; ещё не реализованные экранные и серверные маршруты модулей не заявляются готовыми. Реальные внешние вызовы не выполнялись.
