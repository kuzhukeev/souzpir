# SP-E4-06 · Импорт знаний: работающая часть

TXT, CSV и XLSX читаются локально; строки показываются как предложения, пользователь выбирает факты и группу существующего черновика. Публикации нет, источник фактов — import.
Права seller.knowledge.write и изоляция бренда проверяются перед просмотром и сохранением. CSV/XLSX использует существующий CatalogReader.
Проверки: ImportsTest — 2 теста, 20 проверок (TXT/CSV, права, изоляция, ошибки); TypeScript, ESLint, Pint, генерация типов.
Снимок: .local/screenshots/sp-e4-06/import-1440.png (светлая тема, демонстрационные данные).
Ограничения: импорт сайта и адаптация приватных черновиков SiteKnowledgeImporter, выбор листа XLSX, PDF/DOCX не реализованы; XLSX отдельно не проверялся фикстурой.

## Техдолг
- Предложение из таблицы объединяет непустые ячейки строки; соответствие колонок и редактирование предложений пока отсутствуют.

## Принято по умолчанию
- Первая страница XLSX; до 100 строк по 500 символов; для сохранения нужна созданная группа фактов.
