# SP-CI-01 — покрытие PHP-тестов в CI

- До исправления четыре каталога Feature не входили ни в один suite: SP-E1-10C, SP-E1-10D, SP-E1-10E, SP-E1-10F.
- Все четыре добавлены в Shell. Проверка `scripts/ci/check-test-suite-coverage.py` встроена в php-lint и требует, чтобы каждый `*Test.php` из Feature/Unit входил ровно в один suite.
- Аудит: 255 файлов Feature/Unit, непокрытых и дублированных после правки нет.
- Локально: 9 новых для CI тестов прошли, 95 assertions. Широкий непараллельный Shell прогон на Windows прерван после сбоев существующих AuthFlow/Brands тестов; результат Linux CI ветки обязателен перед слиянием.
- Ограничения: проверка охватывает файлы `*Test.php` в Feature/Unit; другие имена тестовых файлов в проекте не применяются.
