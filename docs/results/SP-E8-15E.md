# SP-E8-15E — недельный расход расписания

При включении расписания явно показано отсутствие данных о недельном расходе тарифных слотов; число ответов не выдаётся за стоимость. Частота и права запуска сохраняют прежнее поведение.
Проверки: Playwright E8-15E — 2 сценария (три частоты, выключение, отсутствие права); ESLint. Новых серверных входов нет; изоляция брендов не менялась и отдельно не проверялась.
Скриншот: `.local/screenshots/SP-E8-15E/weekly.png` (светлая тема, 1440).

## Ограничения
Существующий планировщик запускает задачи только при `measurement_schedule_enabled` и `measurement_queue_enabled`; для нефейкового AI дополнительно нужен `live_measurements_enabled`. Все три по умолчанию выключены. Плановый замер использует один прогон.

## Техдолг
Нет.

## Принято по умолчанию
Без подтверждённого тарифного коэффициента расход не рассчитывается для любой частоты, включая ежемесячную.

## Нужно от интегратора
Предоставить подтверждённый источник тарифных коэффициентов и определить недельный расчёт для разных частот, чтобы заменить пустое состояние значением.
