# SP-E5-04B · Мои диалоги: работающая часть

Добавлен фильтр «Мои диалоги»: показывает назначенные текущему пользователю диалоги в текущем бренде; остальные режимы и поиск сохранены.
Проверки: MyDialogsTest — 1 тест, 25 проверок (менеджер, просмотрщик, изоляция бренда, неверный фильтр); TypeScript, ESLint, Pint. Экран проверен на 390 без горизонтального overflow.
Снимок: .local/screenshots/sp-e5-04b/my-dialogs-1440.png (светлая тема, демонстрационные данные).
Ограничения: редактирование/отправка подсказок, пометки и polling не реализованы; проверки гонок присвоения и отправки не проводились.

## Техдолг
- Для полноценной очереди суфлёра нужен runtime отправки и состояние подсказок.

## Принято по умолчанию
- «Мои» означает assigned_user_id текущего пользователя; неназначенные видны в общем списке.

## Нужно от интегратора
- Предложить продолжение для редактирования/отправки подсказок, пометок A.6, polling, очистки brand cache и явно заказанных race-тестов после готовности runtime SP-E3-08/09.
