# SP-E5-03E — частичная сдача: источник API

- API leads и turn принимают необязательный source: site или crm; источник записывается для успешных запросов и авторизованных ошибок, показывается в журнале D-9.9. Старые запросы отображаются как API.
- Повтор учитывает источник, а записи источников отделены от изменяемого состояния диалога и ограничены организацией и брендом.
- PHPUnit: 8 тестов, 165 проверок; Playwright: 1 тест, экран 1440; TypeScript, ESLint, Pint и Vite build прошли. PostgreSQL изолирован, драйверы fake.
- Скриншот: `.local/screenshots/SP-E5-03E/api.png`.

## Остаток
- action=open и сохраняемый выбор «Написать первым»: защищённый исходящий ход без клиентского сообщения через Policy, Responder и Guard, хранение, повтор, изоляция и UI; сейчас open возвращает 503.
- Заменить фиксированные fake-ответ и подсказку FollowupFinalizer на защищённые extractor/responder/guard и Gateway; проверить полный fake-сценарий, ошибки, повторы, права и бренд.
- Реализовать двухэтапный путь Gateway вне транзакции ResolveTokenTenant с повторной проверкой полномочий и сквозным тестом. Существующие защищённые стадии первого хода завязаны на входящее сообщение и сессию.

## Техдолг
- Источники хранятся в защищённых receipts; отдельное поле журнала упростит выборку, если будет расширен scope схемы.

## Принято по умолчанию
- При отсутствии source отображается API; значение не угадывается. Поддерживаются только явно переданные site и crm.
