# SP-E7-02 — сценарии и прогоны

- Добавлены список, создание и редактирование собственных сценариев с типом, поведением, первым сообщением, лимитом ходов и выбором критериев.
- Пресеты доступны только для чтения; отображаются сохранённые прогоны и их диалоги.
- Тесты: ScenariosTest — 2 теста, 45 проверок: создание, изменение, FakeSimulation и просмотр, права, изоляция и ошибки ввода.
- Проверки: Pint, TypeScript, ESLint экрана, генерация типов маршрутов.
- Скриншот: .local/screenshots/sp-e7-02/scenarios-1440.png (светлая тема, демонстрационные данные).
- Ограничения: запуск с выбором релиза не реализован; существующий FakeSimulation принимает уже готовые ходы и не генерирует диалог.

## Техдолг
- Список прогонов ограничен 30 записями; редактор поддерживает пять критериев из словаря прототипа.

## Принято по умолчанию
- Сценарии без признака custom считаются пресетами и не редактируются; первое сообщение необязательно.
