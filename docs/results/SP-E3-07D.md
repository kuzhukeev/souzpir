# SP-E3-07D — офлайн-адаптер replay

- Исправлен приём записанных ответов с пустым текстом и непустыми вызовами инструментов без сетевого fallback.
- Во всех 41 сценарии последовательно проверены 824 записанных вызова, включая 65 ответов только с инструментами и отказ после исчерпания записи; golden fixtures не менялись.
- PHPUnit: RecordedToolCallsE307DTest и RecordedGatewayE307CTest — 2 теста, 1765 проверок; Pint. Новый тест входит в существующий CI-набор Equivalence.

## Остаток
- Подключить адаптер к новому runtime и сопоставить реальные запросы; выполнить все 41 сценарий через runtime, проверить follow-up, ошибки и изоляцию брендов, включить полный runtime replay в CI и внести подтверждённые расхождения в `docs/sources/09`.
- Проверка записанных запросов не доказывает эквивалентность runtime; полномасштабный replay не выполнен.

## Техдолг
Эквивалентность нового runtime прототипу не подтверждена.

## Принято по умолчанию
