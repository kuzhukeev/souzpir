# SP-E7-01E — карточка оценки диалога

- Шкалы точками, замечания с ходами и сохранение несогласия с оценкой.
- «Оценить сейчас» запускает fake-Judge для последней завершённой неоценённой симуляции текущего бренда; ошибки показаны в карточке.
- Проверки: Quality и GeneratedTypes PHPUnit; Playwright 2; TypeScript, ESLint, Pint. Внешние HTTP-вызовы запрещены тестом.
- Скриншоты 1440, светлая тема: `.local/screenshots/sp-e7-01e/evaluation-1440.png`, `empty-1440.png`.
- Макеты: `C:/OSPanel/home/tasks.local/completed/66/15042fc7-D-7.3-evaluation.png`, `35915e2a-D-7.3-no-evaluation.png`.

## Ограничения
- Реальный Judge не подключён; fake-Judge требует подготовленный тестовый ответ для выбранного прогона, при его отсутствии сообщает об ошибке.
- Сохранение несогласия доступно ролям с `seller.settings.write`.

## Техдолг
- Персональная калибровка читается отдельным запросом на оценку; при большом числе оценок запросы стоит объединить.

## Принято по умолчанию
- Кнопка выбирает последний завершённый прогон бренда без оценки и после успеха открывает сегодняшний день оценки.
- Для несогласия нужны оценка от 1 до 5 и комментарий; повторная отправка обновляет личное мнение.

## Нужно от интегратора
- Предложение продолжения: подключить разрешённый Judge для реальных диалогов после готовности runtime.
