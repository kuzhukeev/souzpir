# SP-E7-01E — карточка оценки диалога

- Дровер показывает пять шкал точками, комментарий судьи и замечания с номером хода и цитатой.
- Администратор сохраняет оценку и комментарий несогласия; ранее сохранённое мнение подставляется повторно.
- Пустая карточка честно показывает недоступность запуска оценки реального диалога; симуляция не запускается вместо него.
- Проверки: Quality и GeneratedTypes PHPUnit; Playwright 2; TypeScript, ESLint, Pint.
- Скриншоты 1440, светлая тема: `.local/screenshots/sp-e7-01e/evaluation-1440.png`, `empty-1440.png`.
- Макеты: `C:/OSPanel/home/tasks.local/completed/66/15042fc7-D-7.3-evaluation.png`, `35915e2a-D-7.3-no-evaluation.png`.

## Ограничения
- Оценка выбранного реального диалога недоступна: имеющийся fake-Judge принимает только симуляции. Кнопка отключена до появления безопасного runtime для диалога.
- Сохранение несогласия доступно ролям с `seller.settings.write`.

## Техдолг
- Персональная калибровка читается отдельным запросом на оценку; при большом числе оценок запросы стоит объединить.

## Принято по умолчанию
- Для несогласия нужны оценка от 1 до 5 и комментарий; повторная отправка обновляет личное мнение.

## Нужно от интегратора
- Подключить оценку выбранного реального диалога после готовности безопасного runtime; маршруты и интерфейс диалогов вне scope.
