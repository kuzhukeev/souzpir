# SP-E7-01I — доклады качества

- D-7.1: даты докладов запрашиваются с сервера страницами по 10; период и номер страницы проверяются, переход показывает загрузку и ошибку сети.
- D-7.2: при сборе доклада сохраняется связь замечания с исходным диалогом; «Исправить» открывает диалог с проверенной отметкой доклада.
- Проверки: PHPUnit — 2 теста, 64 проверки на изолированной PostgreSQL (пагинация, связь, права, бренд, ошибки); Playwright — 2; TypeScript, ESLint, Pint и типы.
- Скриншоты `.local/screenshots/SP-E7-01I/reports.png`, `day.png` (светлая тема, 1440).

## Остаток
- D-7.3: защищённая fake-оценка реального диалога по кнопке и оставшиеся состояния drawer; существующий fake Judge принимает только симуляции.
- D-7.2: старые доклады без сохранённой связи не показывают «Исправить»; восстановление связей требует отдельной задачи.
