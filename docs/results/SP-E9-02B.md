# SP-E9-02B — проверка подготовленной копии

- Частичный срез: команда `migration:validate-organization-copy` проверяет ULID и названия выбранной организации и её брендов в SQLite-копии без записи.
- Проверки: 3 unit-теста, 5 проверок, Pint, `git diff --check`; чужие бренды исключены, файл не изменяется.
- Импорт в тестовую PostgreSQL, batch, повторный запуск и откат ещё не реализованы. Скриншоты не применимы.

## Техдолг
- Проверить дополнительные поля и форматы копий до полноценного импорта.

## Принято по умолчанию
- Подготовленная копия содержит поля `id` и `name` организаций и брендов; команда не выводит названия.

## Нужно от интегратора
- Завести продолжение: изолированный импорт с фиксацией batch и проверенным откатом при изменениях и зависимостях; не считать полный импорт готовым.
