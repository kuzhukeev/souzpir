# SP-E5-04C — частичная реализация

- В диалоге можно отметить ответ бота одной из шести причин A.6, добавить комментарий и лучший вариант; пометки сохраняются в `message_reviews`.
- Доступ проверяется по роли, активному бренду и назначению менеджера; сообщения клиента пометить нельзя.
- Список и открытый диалог обновляются каждые 15 секунд; локальное состояние формы очищается при смене диалога или бренда.
- Доработка review: fixture сама запускает Vite, сценарий больше не зависит от общего адреса CI; ESLint пройден.
- Проверки: `phpunit tests/Feature/Seller/Dialogs` — 4 теста, 91 проверка; `tsc --noEmit`; Playwright форма на 1440 и 390 — пройдено; Pint для PHP.
- Скриншот: `.local/runtime/e5-04c-review.png` (светлая тема, 1440, тестовые данные).
- Ограничения: очередь суфлёра, редактирование, отправка и пропуск подсказки не реализованы; интерфейс существующего диалога не заменяет экран очереди.

## Техдолг
- Нет.

## Принято по умолчанию
- Менеджер может помечать только ответ бота в назначенном ему диалоге.
