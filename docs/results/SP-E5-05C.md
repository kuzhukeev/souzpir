# SP-E5-05C — напоминания клиентам
- В карточке клиента можно создать напоминание с текстом, сроком и менеджером; оно видно в задачах и карточке.
- Срок и назначение проверяются на сервере; при наступлении срока используется существующий outbox уведомлений.
- PostgreSQL: CustomersTest, 4 теста / 134 проверки, 4 предупреждения Pest об отсутствующем .env; TypeScript, ESLint, Pint, генерация типов.
- Скриншот: `.local/screenshots/sp-e5-05c/reminder-1440.png`, светлая тема, 1440, демонстрационные данные.
## Техдолг
- Существующий тип события уведомления называет напоминание просроченным обещанием.
## Принято по умолчанию
- Срок вводится в часовом поясе браузера; менеджер по умолчанию — назначенный на последний диалог.
- При наличии диалога напоминание также привязано к последнему диалогу; менеджер может назначить только себя.
## Нужно от интегратора
- При откате миграции nullable conversation_id сохраняется, поскольку могут существовать задачи без диалога.
- При необходимости отличать текст уведомления от обещания потребуется общий контракт события уведомления.
