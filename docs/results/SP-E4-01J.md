# SP-E4-01J

- Локальный прогон черновика теперь строит диалог из первого сообщения и фактов персоны, сохраняет состояние продавца между ходами и проверяет guard и поддерживаемые критерии на каждом ходе.
- Откат автоматически сохраняет текущий черновик; список копий и восстановление доступны редактору бренда. Активная публикация при этих действиях не меняется.
- Добавлены маршрут восстановления, сгенерированные типы и два экрана проверки: `.local/screenshots/SP-E4-01J/restore.png`, `.local/screenshots/SP-E4-01J/run.png`.
- Тесты: PHPUnit 5/5 (92 проверки), Playwright 2/2, TypeScript и ESLint прошли; Pint прошёл для изменённых PHP-файлов.
- GeneratedTypesTest локально не стартует из-за записи временного файла Symfony Process в системный каталог Windows; генератор типов выполнен напрямую.

## Ограничения
- Прогон детерминированный и использует локальные policy, few-shot и guard; полноценный защищённый runtime-диалог и семантическая проверка произвольных критериев остаются отдельной задачей.

## Техдолг
- Сохранённые копии используют существующий статус `building` с записью аудита; отдельный статус архива упростит жизненный цикл.

## Принято по умолчанию
- Неизвестный критерий считается неподтверждённым; клиентские реплики после первой формируются из фактов персоны до `max_turns`.
