# SP-E1-07B · Использование

Добавлены дневной график и таблица доступных показателей, текущий бренд и экспорт CSV; данные получаются через UsageReader и ограничены текущим брендом. Для таблицы добавлена пагинация, для периода — ограничение в 93 дня.
Проверки: DailyUsageE107BTest — 1 тест, 31 утверждение (сценарий, роли, изоляция, неверные даты); GeneratedTypesTest — 2 теста; Chromium — 2 сценария; Pint, ESLint, TypeScript. PHP предупреждает об отсутствующем .env.

## Техдолг
- Дневная разбивка делает отдельный запрос к порту за каждый день; период ограничен 93 днями.

## Принято по умолчанию
- Нулевые и недоступные показатели не создают строки; разные единицы не суммируются, график масштабирует каждый показатель отдельно.

## Нужно от интегратора
- UsageReader не предоставляет стоимость или тарифные единицы по модулям: график и CSV показывают доступные счётчики без вымышленных цен. Для полного соответствия S-4.2 нужен отдельный источник тарификации и накопительная диаграмма.
