# SP-E5-02F — виджет: лимит сообщений (D-9.4) + активная проверка установки (D-9.2c)

Лимит сообщений (D-9.4) сдан и принят ранее (merge a755b72e) — без изменений.

## Остаток: активная проверка установки (решение владельца 07.11, Q1)
- Новый `WidgetInstallationChecker`: GET первого разрешённого сайта с защитой от SSRF — только http/https, порты 80/443, DNS резолвится и проверяется до запроса (запрет 10/8, 172.16/12, 192.168/16, 127/8, 169.254/16, 0.0.0.0/8, ::1, fc00::/7, fe80::/10), редиректы обрабатываются вручную (`allow_redirects:false`) с повторной проверкой каждого адреса, не более 3; таймаут 5 с; тело читается максимум 1 МБ; свой `User-Agent`; поиск `public_key` виджета в HTML. Статусы: «Код установлен» / «Код не найден на странице» / «Сайт недоступен» (HTTP-код или «таймаут») / «Проверка не удалась».
- Пассивный сигнал (`last_seen_at`) сохранён рядом как отдельная строка «Виджет работает, последний сигнал …».
- Частота: не чаще раза в 30 секунд — отметка `install_checked_at` в `widget_settings` (новые колонки, миграция `database/migrations/E5-02F/`), повторный вызов в окне возвращает прежний результат без запроса.
- UI (`Index.tsx`, вкладка «Установка»): статус-строка с иконкой + кнопка «Проверить установку»; текст «Активная проверка сайта не выполняется» убран. Сверено с макетами `70/37df8e4f-D-9.2c-detected.webp`, `70/79c7e5d4-D-9.2c-not-detected.webp`.
- Проверено вручную (`artisan serve` + Vite dev, 1440, светлая тема, реальный логин): скриншоты `.local/screenshots/sp-e5-02f/widget-install-detected-1440.png` (сохранённый статус «Код установлен») и `widget-install-active-check-failed-1440.png` (живой клик «Проверить установку» в песочнице без исходящей сети корректно даёт «Проверка не удалась: не удалось определить адрес сайта», запроса наружу не было).
