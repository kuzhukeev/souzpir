# SP-E5-01 · Список каналов и Telegram

Сделано: экраны каналов и настроек Telegram, режим per канал, число диалогов за 7 дней, подтверждаемая остановка ботов. Токен и секрет вебхука шифруются, чат менеджеров сохраняется шифрованным.
Вебхук проверяет секрет, принимает обновления Telegram, сохраняет текст в диалогах и дедуплицирует `update_id`. Действия настроек пишутся в аудит без реквизитов.
Тесты: `tests/Feature/Seller/Channels/Telegram/TelegramTest.php` — 2 теста, 49 проверок; Pint, typecheck, ESLint страниц и Vite build прошли.
Скриншоты: `.local/screenshots/sp-e5-01/channels-1440.png`, `.local/screenshots/sp-e5-01/telegram-1440.png` (светлая тема, 1440).
Ограничения: это рабочий входящий срез. Нет автоматической регистрации вебхука, исходящей доставки, сообщений в чат менеджеров и запуска seller runtime; предложить отдельную задачу после E3-08. Реальный Telegram API не вызывался.

## Принято по умолчанию

- «Выключен» соответствует `manager`; входящие сообщения продолжают сохраняться для менеджера.
- Статус `active` на карточке означает сохранённый токен, а не подтверждённое подключение к Telegram.
- «Диалогов за 7 дней» считает диалоги с последним сообщением клиента за этот период.

## Нужно от интегратора

- Завести продолжение для регистрации вебхука и исходящей доставки после появления seller runtime; локальный HTTP не годится для вебхука Telegram.
