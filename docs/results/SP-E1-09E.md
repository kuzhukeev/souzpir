# SP-E1-09E — имена объектов и экспорт журнала

- S-6.1: имена и ссылки контактов, диалогов, знаний, вопросов, замеров, отчётов, персон, задач, каналов, рекомендаций и публикаций; русские фразы действий и фильтров.
- Меню ⋮ открывает детали или объект. CSV содержит имя объекта, название бренда и модуль; формулы обезвреживаются.
- Не найденный или недоступный объект остаётся идентификатором без ссылки; технические события без карточки доступны в деталях журнала.
- Проверки: PHP 7 тестов / 180 утверждений; Playwright E1-09E и E1-09C; TypeScript, ESLint, Pint.
- Дополнительно: оба browser-сценария E1-09D переведены на меню строки и прошли локально; прежние проверки сохранены.

## Техдолг
- Реестр читает объекты отдельно для строк; пакетная загрузка потребуется при росте журнала.
- Drawer уведомления не показывает текст последней ошибки (`last_error`) — бэкенд его не возвращает в списке; при необходимости добавить отдельным полем.

## Принято по умолчанию
- Ссылки ведут в существующий раздел, если отдельной карточки объекта нет. Чужой бренд не получает имя и ссылку.
- Для новых неизвестных типов действий — нейтральная русская подпись; исходный код события сохраняется в данных журнала.
- Меню уведомления не содержит пункта «Открыть объект» (у уведомления нет связанного объекта со ссылкой), только «Детали уведомления».
