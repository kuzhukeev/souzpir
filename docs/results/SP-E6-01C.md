# SP-E6-01C — служебные фразы в ответчике

Сделано: адаптер переносит все семь сохранённых служебных фраз и быстрые ответы в поле опубликованного промпта ответчика. Повторное сохранение заменяет прежние фразы без дублей. На экране есть локальный fake-пример для проверки текущей фразы и быстрого ответа.

## Остаток
Продолжение: SP-E6-01D.
Автоматический выбор служебной фразы по событию Runtime и соответствующий fake-прогон диалога остаются вне scope `app/Seller/Runtime/`.

## Техдолг
Промпт получает быстрые ответы как подсказки менеджера; отдельное поведение движка для каждого типа ответа пока не задано.

## Принято по умолчанию
Пустая фраза пропускается в промпте и в локальном примере обозначается «Фраза не задана».

## Нужно от интегратора
Завести продолжение для выбора фраз по событиям в `Runtime/` и проверить fake-фикстуры после изменения промпта.
