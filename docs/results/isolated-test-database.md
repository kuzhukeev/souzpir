# Изолированная очистка тестовой базы

Пользователь разрешил очищать только проверенную отдельную тестовую базу вместо отката намеренно необратимых рабочих миграций. `IsolatedDatabaseMigrations` проверяет testing-окружение, согласованность имени и подключения, отличие от preview-базы, фактическую идентичность PostgreSQL и принадлежность базы выделенной роли без административных полномочий. Проверка выполняется до создания схемы и до очистки. Рабочие миграции и конфигурации рабочего сайта не изменены.

На отдельной PostgreSQL `souzpir_test_c02_summary_review` прошли `IsolatedDatabaseMigrationsTest` (3 теста, 13 проверок), ранее падавший `BoundaryGatewayTest` (4 теста, 78 проверок) и Pint. После завершения тестов в `public` проверено отсутствие таблиц. Сбой проверки запрещает очистку. Внезапная остановка процесса может оставить тестовые данные до следующего успешного прогона.

Это первый перевод на общий механизм, а не исправление всего набора: другие тесты с Laravel `DatabaseMigrations` пока не переведены; полный набор и CI не запускались.
