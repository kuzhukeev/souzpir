# SP-E8-05 — внутренний отчёт
- Отчёт строится из подтверждённого замера; есть обзор, метрики моделей, методика и разделы V-5.2–V-5.8.
- Из снимка выводятся упоминания компаний, подтверждённые пробелы, проверенные факты, источники и доступные рекомендации.
- Совместимые снимки сравниваются по метрикам, изменениям вопросов и новым компаниям; неполные ответы не считаются отсутствием бренда.
- Проверено: 4 теста / 56 проверок PostgreSQL (права, изоляция, ввод, DTO); TypeScript и Pint.
- Скриншот: основной checkout `.local/screenshots/sp-e8-05/sections-1440.png` — компонент со светлой темой, демонстрационные данные, 1440.
- Ограничения: сайт, рекомендации и подтверждённые факты зависят от данных снимка; без них показаны пустые состояния. Нет кнопки передачи действия в чужой модуль.
- Детализация конкурентов и площадок — SP-E8-05B; публикация и TTL — SP-E8-05C.
## Техдолг
- Сопоставление учитывает вопросы, модели и число прогонов; изменение профиля может влиять на разницу.
## Принято по умолчанию
- Неизвестное присутствие на источнике не считается отсутствием; данные непроверенных ответов не показываются как факты.
## Нужно от интегратора
