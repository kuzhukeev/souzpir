# SP-E1-10E — чтение лидов по брендовому ключу

- GET `/api/v1/seller/leads` и GET `/api/v1/seller/leads/{id}` читают контакты текущего бренда по ключу с правом `leads`.
- Ответ содержит ID, имя и время создания; телефон, email и внешние ID не выдаются.
- 2 feature-теста, 9 проверок на отдельной PostgreSQL: свой и чужой бренд, отсутствие ключа и неверное право; Pint, генерация типов и diff check.
- Серверный API без экранов; скриншоты не применимы. Запись лидов этим срезом не включается.

## Техдолг
- Список ограничен 50 строками; при больших объёмах нужна курсорная пагинация.

## Принято по умолчанию
- Минимальный «лид» для чтения — запись `contacts`; стадия продажи остаётся в диалоге и не выводится как свойство контакта.
