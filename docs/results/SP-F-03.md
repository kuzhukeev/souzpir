# SP-F-03 — каркас кабинета

Сделаны CabinetLayout, единый реестр и русский словарь навигации, 11 пунктов продавца с иконками, учёт permissions, активного URI и реально зарегистрированных GET, ширина 280/72, запоминание состояния, мобильное меню, breadcrumbs, заголовок с настоящими shared props. Отсутствующие экраны честно помечены «Скоро». Кнопка выбора бренда по умолчанию недоступна до исправления конечного маршрута E1-03; при явном включении вызывает реальный endpoint и не подменяет ответ. Подробнее `docs/design/layout.md`.

Проверки: `npm run typecheck`, `npm run lint`, `npm test -- --run` (71/71), `npm run build`; Playwright с установленным Chrome на отдельном Vite-порту 5183 — 8/8, в том числе axe WCAG 2 A/AA, 1440/1024/390, отсутствие горизонтального overflow, мобильный Escape/focus, локальное сохранение панели, permissions, запрет преждевременной смены и запрос с ID. Тестовый стенд с синтетическими данными не подтверждает серверный end-to-end или фактическую интеграцию ещё не существующих страниц.

Просмотрены screenshots: `.local/screenshots/layout/layout-1440.png`, `layout-1024.png`, `layout-390.png` в worktree; они не входят в git. Preview существующих макетов не менялся. Необходима интеграционная генерация shared TypeScript i18n после появления `lang/ru/navigation.php` и подключение layout будущими страницами. Смена бренда остаётся отключённой до E1-03; заглушки поиска и каналов сознательно не выдают фиктивный функционал. Дополнительные разделы Видения реализуют владельцы соответствующих экранов.
