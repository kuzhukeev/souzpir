Падение — реальный 422→302 от сервера: `GET /seller/dialogs/{id}?mode=all&search=&sort=newest` редиректит назад с ошибкой `"search": "Поле «search» должно быть строкой."`. Причина — стандартный Laravel middleware `ConvertEmptyStringsToNull` превращает `search=''` в `null`, а правило `'search' => ['sometimes','string','max:100']` в `App\Seller\Dialogs\DialogsController::index` (строка 33) не допускает `null`, хотя сам код по умолчанию трактует отсутствие search как `''` (строка 91). Открытие любого диалога из списка с пустым полем поиска (обычное состояние экрана) всегда даёт эту ошибку — баг не только теста, а экрана «Диалоги» целиком; блокирует сценарии 6, 7 и 8 (все идут через этот клик).
