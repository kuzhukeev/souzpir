# SP-E8-20N — источники и действия

- В таблице и панели площадки показано число цитирований из валидных записей подтверждённого снимка отдельно от числа ответов.
- В рекомендациях видны цитирования, ответы, статус сохранённого действия текущего бренда; для сложности без сохранённой метрики показано «Нет данных».
- Уже сохранённое действие не создаётся повторно через экран источников.
- Проверено: PHP Unit 4 теста / 97 утверждений, включая POST действия, права, изоляцию брендов и две ошибки ввода; Playwright 1 сценарий; TypeScript, ESLint, Pint.
- Скриншоты: `.local/screenshots/sp-e8-20n/sources.png`, `source-drawer.png` (светлая тема, 1440).

## Ограничения
- Связь с действием определяется точным сохранённым описанием площадки; после ручного изменения описания статус на экране источников не показывается.

## Техдолг
- Для устойчивой связи при редактировании действия нужен явный идентификатор источника в общей схеме действий.

## Принято по умолчанию
- Сложность площадки не вычисляется по косвенным признакам: пока нет подтверждённого поля, показывается «Нет данных».

## Нужно от интегратора
- Если нужна связь после редактирования описания, добавить отдельное поле источника в общем контракте действий; текущая реализация работает без изменения чужого модуля.
