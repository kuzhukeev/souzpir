# SP-E5-08B · Разные клиенты
- Действие «Разные» сохраняет упорядоченную пару в текущем бренде, скрывает её из совпадений и пишет аудит; повторный запрос не создаёт дубликат записи.
- Из карточки клиента добавлены ссылки на дубли и импорт с учётом прав; экран показывает сохранение, ошибку и пустое состояние.
- Проверено: PHPUnit ImportExport и Customers — 7 тестов / 219 проверок, включая изоляцию, права и ошибки; Playwright E5-08 — действие и пустое состояние; TypeScript, Pint и типы.
- Скриншот: `.local/screenshots/sp-e5-08b/duplicates-1440.png` основного checkout, синтетические данные, светлая тема.
## Техдолг
- Поиск пар по-прежнему попарный; при росте числа клиентов потребуется индексированный поиск.
## Принято по умолчанию
- Отметка «Разные» действует для пары независимо от порядка контактов; ручное объединение остаётся доступным.
## Нужно от интегратора
- Нет.
