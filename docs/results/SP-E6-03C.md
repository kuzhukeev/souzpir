# SP-E6-03C — правила вне темы и негатива

- Policy применяет опубликованное действие `handoff` при достижении заданного порога сообщений вне темы; без действия сохранён прежний `spam`. Порог негатива уже читается из снимка policy.
- Проверки: OffTopicPolicyE603CTest — 2 теста, 7 проверок; PolicyTest — 11 тестов, 28 проверок; Pint. База и внешние вызовы не использовались.
- Экран не менялся; скриншот отсутствует. Изоляция проверена на отдельных снимках знаний в unit-тесте, не на HTTP/БД.

## Остаток
- D-5.6: защищённый follow-up использует фиксированный ответ и не вызывает Policy; `FirstTurnTextFinalizer` не принимает результат handoff. Для рабочего поведения нужны изменения за пределами scope и fake/feature-тесты runtime и изоляции брендов.

## Техдолг
Нет.

## Принято по умолчанию
Без сохранённого действия серии вне темы сохраняют прежний переход в spam.

## Нужно от интегратора
Разрешить изменение защищённого follow-up и финализатора первого хода или подготовить общий job/turn-вход, который применит Policy опубликованного снимка; после этого проверить runtime без живых вызовов.
