# SP-E3-03C — внутренний Responder
- Собраны опубликованные snapshot и prompt, projection, построение запроса и интерпретация ответа fake-интерфейса.
- Проверяются организация, бренд, публикация и checksum шаблона; data classes передаются явно.
- Результаты completed, in_progress, uncertain и ошибки различаются; ответ остаётся кандидатом для Guard.
- Тесты: 4 unit-теста / 30 проверок без БД и сети; Pint пройден.
- Техдолг: источник и состояние проверяются при чтении; повторная проверка перед эффектами остаётся за runtime.
- Принято по умолчанию: системный prompt допускает глобальную опубликованную версию или версию текущего бренда.
- Нужно от интегратора: SP-E3-03B подключает защищённый runtime и fake transport; запись, tools и доставка здесь не выполняются.
