# SP-E6-03 — поля, воронка и напоминания

- Экран показывает реальные порядок полей, типы клиентов, стадии и пороги из опубликованного snapshot.
- Добавлены проверка и сохранение интервалов, окна и текстов напоминаний в настройки бренда; их читает существующая подготовка followup.
- Тесты: PolicySettingsTest — 3 теста, 50 проверок: snapshot, настройки и применение интервала/окна, права, изоляция, неверный ввод.
- Проверки: Pint, TypeScript, ESLint экрана, генерация типов маршрутов.
- Скриншот: .local/screenshots/sp-e6-03/policy-1440.png (светлая тема, демонстрационные данные).
- Ограничения: изменение правил вне темы и негатива недоступно; показаны опубликованные значения. Подготовка не выполняет доставку.

## Техдолг
- На экране редактируется первый текст из массива; остальные сохранённые тексты сохраняются без изменений.

## Принято по умолчанию
- Без второго интервала сохранено поведение первого интервала × номер напоминания; пустые тексты используют существующий fallback.
