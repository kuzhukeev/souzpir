# Результат SP-E1-01

Реализованы регистрация первого владельца существующей организации с bootstrap-секретом, приглашение через Team, вход, подписанная проверка email через подтверждающий POST, одноразовый password reset, TOTP и version-based отзыв сессий. Экраны S-0.1–S-0.5 и MFA сверстаны React/Inertia с Tailwind и доступными элементами, без нарезки изображений. Подробности: docs/modules/E1-01.md.

Проверки: полный PHP-набор в изолированной PostgreSQL с исходным bootstrap и временной `session` group — 97 тестов / 676 assertions до последних локальных расширений; auth suite с ffec413 AuthenticateSession — 9 тестов / 109 assertions; RFC 6238 векторы и запрет replay; Chromium e2e настоящий пароль→MFA→вход→выход и mobile 390 с axe — 2/2; desktop screenshot 1440 и mobile screenshot сохранены в `.local/screenshots/auth/`. Frontend typecheck/lint/build прошли, Pint применён. Тесты используют fake notifications/HTTP; реальной доставки не было.

Обязательная интеграция: session route group и AuthenticateSession из ffec413; дополнительно подключить `App\Shell\Auth\EnforceAuthVersion` после AuthenticateSession ко всем защищённым web/session routes и проверить старую cookie-сессию при сбросе/изменении MFA; CI HTTP серверу задать CABINET_ORGANIZATION_ID=01J00000000000000000000000. Тесты старого базового SHA при ffec413 меняют actingAs в общей сессии и из-за старого password_hash_web получают 401: `NotificationCoreTest::test_http_settings_endpoint_requires_authorized_active_brand_and_audits`, `::test_viewer_can_change_only_own_notification_settings_in_authorized_brand`, `IsolationTest::test_empty_grants_are_wildcard_only_for_owner_admin_and_disabled_membership_is_denied`; актуальный main уже исправлен интегратором через изоляцию сессий.

Первый владелец требует защищённый bootstrap-код; AUTH_EMAIL_DELIVERY_ENABLED по умолчанию false. Почтовый транспорт, создание и безопасная передача первого кода, утверждённые тексты условий и внешняя эксплуатация — операторские требования. Landing `/auth/ready` временный до готовой главной; MFA-подключение без QR и управление сессиями развиваются в E1-08. Первый owner не создаёт вторую организацию, функции удаления организации отсутствуют.
