# SP-E5-07B — частичная сдача

PriceMailSender возвращает false при исключении почтового транспорта или некорректном отправителе; письмо с существующим прайс-файлом и изоляция бренда сохранены. Экран настроек по-прежнему честно указывает, что автоматическая отправка не подключена.
Проверки: PriceDeliveryE507BTest — 3 теста, 28 проверок (Mail::fake, вложение, выключение, отказ, отсутствующий файл, ошибки, права и бренд); Playwright — 1 сценарий; ESLint, TypeScript, Pint. PostgreSQL 16 отдельный; PHP предупреждает об отсутствующей .env.
Скриншот `.local/screenshots/SP-E5-07B/email.png` (светлая тема, 1440).

## Остаток
Защищённый send_price пока не вызывает PriceMailSender; задача менеджеру при отказе не подключена и сквозной сценарий не выполнен. Переход из общей навигации также не добавлен. Предлагается интеграционное продолжение.

## Техдолг
Нет.

## Принято по умолчанию
Исключение транспорта означает неуспешную отправку; сам отправщик не записывает исключение в лог.

## Нужно от интегратора
Разрешить изменение FirstTurnCoordinator и ToolRunner либо предоставить защищённый порт вызова PriceMailSender и создания задачи менеджеру; подключить навигацию через её владельца. Для приёмки завести сегодня карточку на остаток.
