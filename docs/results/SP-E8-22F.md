# SP-E8-22F — рекомендации и действия

- Действия показывают сохранённый приоритет и шаги, число разных вопросов, порядковый номер и дату следующего активного замера. Отчёт использует только сохранённые поля и число известных вопросов.

- PHPUnit: 2 теста, 42 проверки (fake, права, бренд, ошибки и расписание); Playwright E8-22F: 3 теста; TypeScript, ESLint, Pint. Скриншот `.local/screenshots/SP-E8-22F/actions.png`.
