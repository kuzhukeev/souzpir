# SP-E3-09
- Добавлен контракт ChannelDelivery с командой и квитанцией; завершённый bot-ход передаёт сохранённое сообщение fake-адаптеру.
- Fake проверяет организацию, бренд, диалог и роль сообщения; повтор ключа возвращает квитанцию, конфликт отклоняется. suggest и manager доставку не вызывают.
- `ToolRunner` читает остатки из последнего завершённого импорта своего бренда без цен; прайс возвращает только fake-квитанцию при включённой настройке и сохранённом файле.
- Проверки: Delivery — 4 теста / 23 утверждения; ранее FirstInboundRuntimeTest — 4 / 112 и FollowupHttpTest — 1 / 19; Pint. Изолированная БД `souzpir_test_e309`.
- Ограничение: доступен только fake-канал, реальной отправки и экранов нет; скриншоты неприменимы.
## Техдолг
- Fake-дедупликация использует настроенный cache с TTL 30 дней; для реальных адаптеров нужна долговечная идемпотентность транспорта.
## Принято по умолчанию
- Fake-квитанция имеет статус `fake_sent`; содержимое сообщения в cache не сохраняется.
