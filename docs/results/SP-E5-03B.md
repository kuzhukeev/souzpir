# SP-E5-03B — журнал ошибок API

- Добавлена запись отклонённых запросов после завершения основной транзакции и отдельный журнал для администратора бренда.
- Хранятся endpoint, HTTP-статус, категория и время; bearer и payload не сохраняются.
- Тесты: ApiFailureTest — 2 теста, 21 проверка: 401/403/422/500, откат, секреты, права и изоляция.
- Проверки: Pint, генерация типов маршрутов; живых вызовов не было.
- Скриншот: .local/screenshots/sp-e5-03b/failures-1440.png (светлая тема, демонстрационные данные).
