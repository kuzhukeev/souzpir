# SP-E4-04 · Темы вопросов

Сделано: D-4.6 список тем из реального снимка знаний, поиск, количество фактов и частота по сообщениям бренда за 30 дней; D-4.7 редактор в черновике.
Сохранение: название, описание, примеры, привязанные группы фактов, ответ по умолчанию и вопрос-мостик сохраняются в `intents` через `KnowledgeRepository::saveDraft`; версия, аудит и публикация работают через существующий репозиторий.

Типы маршрутов перегенерированы. Доработка CI: browser-тест запускает и завершает fixture с отдельным Vite-кешем; повторно пройдены Playwright 1/1, TypeScript, ESLint.
