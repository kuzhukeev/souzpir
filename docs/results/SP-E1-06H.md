## Ограничения
- Массовая передача диалогов отмечена «Скоро»: существующая операция передаёт по одной задаче, не диалоги.
- Создание новой ссылки открывает общий мастер без автозаполнения; старое приглашение автоматически не отзывается, доставки письма нет.
- Переключатели модулей остаются v2 по карточке.

## Техдолг
- Меню ведёт к общему блоку редактирования; адресных якорей отдельных действий пока нет.

## Принято по умолчанию
- Активный диалог — назначенный участнику диалог в режиме менеджера текущего бренда; без настройки кабинетный канал включён по правилам существующего обработчика.

## Нужно от интегратора
- Предложение продолжения: безопасная массовая передача диалогов и повторная выдача приглашения с предзаполнением и определённой судьбой старой ссылки.
