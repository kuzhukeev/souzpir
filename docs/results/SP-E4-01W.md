Модель: Terra

## Сделано
- Fake-прогон добавляет одну проверенную реплику каталога Q после фактов неизменённой исходной персоны, если позволяет лимит ходов.
- Частично известные критерии сохраняются отдельно: подтверждённые значения не теряются, неизвестные остаются null; строгий API и session-bound fallback сохранены.
- Проверки: PHPUnit 1 тест, 17 assertions (генерация, частичный результат, права, бренд, изменение входа); Pint, отдельная PostgreSQL.
- UI не менялся, скриншоты неприменимы.

## Остаток
- Подключить draft-preview к общим защищённым first-turn стадиям без подмены опубликованного релиза.
- Применить каталоги R/S по полному доказанному контексту и событиям: текущий предварительный прогон не создаёт нужные события.
- Экран результатов вне scope: он пока обозначает частично неизвестную проверку как недоступную.

## Техдолг
- Полный успех сценария по-прежнему требует подтверждения всех критериев; неизвестное не считается успешным.

## Принято по умолчанию
- Проверенная реплика добавляется в конец, не заменяя сохранённые факты, и только при совпадении seeded-персоны.

## Нужно от интегратора
- Зарегистрировать продолжение для protected-адаптера, контекстных событий R/S и отображения частичных результатов.
