# SP-E8-22D — частичная сдача

Добавлен сервис привязки существующего действия к подтверждённой рекомендации по ID отчёта и исходному индексу; приоритет, шаги и ID вопросов сохраняются отдельно от изменяемого названия. Карточка действия показывает сохранённые данные либо пустое состояние; API отчёта возвращает индекс.
Проверки: RecommendationLinkE822DTest — 1 тест, 12 проверок (права, бренд, неверные ID/индекс); Playwright E8-22D — 2 сценария; ESLint, TypeScript, Pint, генерация типов. Тесты на отдельном PostgreSQL 16; PHP предупреждает об отсутствующей .env.
Скриншот `.local/screenshots/SP-E8-22D/recommendation.png` (светлая тема, 1440).

## Остаток
V-9.1/V-9.3: создание привязки из кнопки отчёта и сквозной пользовательский сценарий не подключены; создание действия и экран отчёта находятся вне scope. Предлагается продолжение с их интеграцией и проверкой сохранения при переименовании и завершении.

## Техдолг
Нет.

## Принято по умолчанию
Идентификатор рекомендации — пара ID подтверждённого отчёта и исходного индекса; отсутствующие поля остаются пустыми.

## Нужно от интегратора
Завести сегодня продолжение: при создании действия передавать ID отчёта и индекс, вызывать RecommendationLink::attach в разрешённом контексте и возвращать данные экранам; изменения SiteController/SiteOperations и страницы отчёта вне scope.
