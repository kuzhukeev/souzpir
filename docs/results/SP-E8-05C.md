# SP-E8-05C · Публичный отчёт

Сделано: управление публикациями выбранного бренда, одноразовая выдача ссылки, выбор TTL, отзыв, публичный серверный read-only отчёт с агрегатами. Токен хранится только как SHA-256; внутренние тексты не попадают в публичную проекцию.
Публичный запрос возвращает 410 после срока или отзыва, 404 для неизвестного токена; выдаёт `noindex`, `no-store`, `no-referrer`. Добавлен React SSR entrypoint и конфигурация сборки.
Тесты: `PublicationsTest.php` — 3 теста, 54 проверки; `PublicationDataTest.php` — 1 тест, 2 проверки. Pint, typecheck, ESLint, клиентская и SSR сборки прошли.
Скриншоты: `.local/screenshots/sp-e8-05c/manage-1440.png`, `.local/screenshots/sp-e8-05c/public-1440.png` (светлая тема, 1440); мобильный публичный экран проверен на 390.
Ограничения: публичный отчёт намеренно содержит только агрегаты. Глобальный Inertia SSR сервер не запускается этим модулем; публичный HTML рендерится Laravel. Ссылка из внутреннего отчёта на страницу публикаций пока отсутствует из-за ownership.

## Техдолг

- При выкладке исключить токен `/v/*` из access logs обратного прокси.

## Принято по умолчанию

- Сроки ссылок: 1, 7 и 30 дней в конфигурации, до отдельного продуктового решения.
- Значение `now >= expires_at` означает истечение; публичная проекция не меняется при обновлении внутреннего отчёта.
