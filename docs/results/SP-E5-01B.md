# SP-E5-01B — транспорт Telegram

- Добавлены заменяемый транспорт, HTTP-адаптер setWebhook/sendMessage, отправка клиенту и чату менеджеров с изоляцией брендов.
- Добавлен защищённый endpoint регистрации вебхука с публичным HTTPS APP_URL; аудит хранит только результат, без токена и секрета.
- Тесты: TelegramTransportTest — 2 теста, 22 проверки: HTTP fake регистрации/отправки/отказа, права, изоляция, неверные данные и аудит.
- Проверки: Pint, TypeScript, генерация типов маршрутов; живых запросов не было.
- Скриншот: .local/screenshots/sp-e5-01b/telegram-1440.png (существующие настройки, светлая тема, демонстрационные данные).
- Ограничения: транспорт по умолчанию выключен; endpoint регистрации не подключён кнопкой к существующему экрану.

## Техдолг
- Результат сетевой отправки — bool; классификация причин и повторы остаются вызывающей стороне.

## Принято по умолчанию
- Используются только сообщения Telegram, таймаут 10 секунд; URL формируется из APP_URL, без пользовательского ввода.

## Нужно от интегратора
- Подключить регистрацию к экрану и после разрешённой конфигурации заменить DisabledTelegramTransport на HttpTelegramTransport.
- SP-E5-01C: подключить TelegramSender к seller runtime и политике доставки/повторов.
