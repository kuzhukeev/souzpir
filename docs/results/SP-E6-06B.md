# SP-E6-06B — расписание в runtime

Перед запуском защищённого хода проверяются настройки текущего бренда и его часовой пояс: вне окна или в праздник ход сохраняется как подавленный без вызова AI. Для нераспределённого диалога у менеджера выбирается допустимый участник текущего бренда; пустой пул оставляет диалог без назначения.
Проверки: ScheduleRuntimeE606BTest — 4 теста, 13 проверок (время, праздник, fake AI, права, другой бренд, пустой пул); Pint. Отдельный PostgreSQL 16; PHP предупреждает об отсутствующей .env.
Скриншот `.local/screenshots/SP-E6-06B/schedule-reference.png` — ранее снятый экран SP-E6-06, 1440, светлая тема; UI в этой задаче не менялся.

## Остаток
D-11.1: общий режим suggest не переводит существующий диалог bot в подсказки. D-11.2: назначение срабатывает при следующем входящем сообщении в режиме менеджера, не в момент передачи; позиция кругового выбора не сохраняется. Предлагается включить остаток в SP-E6-06C.

## Техдолг
Нет.

## Принято по умолчанию
При отсутствии расписания действует прежняя круглосуточная доступность; назначение выполняется для входящего диалога в режиме менеджера, если он ещё никому не назначен.

## Нужно от интегратора
Уточнить область SP-E6-06C для остатка режима suggest и назначения при передаче; задача также сохраняет позицию кругового выбора.
