# SP-E4-08B — плохие образцы и добавление из диалога

Сделано: плохие образцы с причиной можно добавить, изменить и удалить в черновике знаний. Поиск доступных диалогов и выбор реплики менеджера через `DialogReader`; текст реплики и источник сохраняются в положительный образец после серверной проверки прав, организации, бренда и версии черновика. На экране есть состояния загрузки, пустого списка и ошибки.

Проверки: `tests/Feature/Seller/Knowledge/Fewshot/` — 4 теста, 58 assertions; Playwright — 1 сценарий на 1440/390; TypeScript, ESLint, Pint — пройдены. Типы маршрутов перегенерированы.

Скриншоты (светлая тема, 1440): `.local/screenshots/sp-e4-08b/bad-1440.png`, `.local/screenshots/sp-e4-08b/from-dialog-1440.png`.

Ограничения: в диалогах без сохранённых сообщений `role=manager` выбирать нечего; текущий `DialogReader` возвращает до 50 диалогов на один поиск.

## Техдолг

Пагинация списка диалогов потребуется при большом числе записей.

## Принято по умолчанию

Из диалога берётся только реплика с `role=manager`; текст образца сервер читает из сообщения, источник — сокращённый ID диалога.

## Нужно от интегратора

Если модуль диалогов пока не записывает реплики менеджера с `role=manager`, включить это в его следующую задачу; здесь чужой модуль не менялся.
