# SP-E0-08 — общие props и frontend-контракты

Добавлены типизированные Laravel Data DTO, opt-in генерация типов Spatie transformer 3, Ziggy route declarations, типы permissions и translation keys. `HandleInertiaRequests` передаёт безопасную проекцию пользователя, lazy tenant/permissions, theme, словарь, request ID и Ziggy без query string. Preview остаётся анонимным; публичный route без web group не получает props кабинета. `usePermissions` использует существующий E0-03 hook; typed i18n helper возвращает обычный текст.

Данные modules/unread до наличия настоящих contributors представлены `null`, не фиктивным нулём/выключенным состоянием. Интегратору требуется обновить общий `core.md` и подключить источники согласно `docs/contracts/frontend.md`. Middleware очищает Inertia shared props после каждого web-запроса; отдельной проверки конкурентного Octane не проводилось.

## Проверки

- PHP на изолированной PostgreSQL test-базе: **82 tests / 645 assertions PASS**, включая семь проверок shared props, смену бренда, permissions, anonymous preview, web→public в одном процессе, редирект/исключение и успешный/ошибочный drift check.
- TypeScript, ESLint, Vite build: PASS. Vitest: **37 tests PASS**, включая typed permissions, i18n и Ziggy route helper; 33 браузерных preview-сценария PASS.
- `scripts/generate-types/generate.php --check`: PASS; тест подтверждает, что изменённый generated-файл даёт ненулевой exit code.
- Зависимости Laravel Data, Spatie transformer 3, Ziggy PHP/JS зафиксированы отдельно интегратором в `5d86d9e`. Manifest/lock и shared frontend bootstrap в ветке задачи не изменялись.

Техническая задача не создаёт новых экранов; отдельные screenshots не применимы. Реальных внешних отправок и LLM-запросов не было.
