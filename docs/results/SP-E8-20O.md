# SP-E8-20O — частичная сдача экранов компаний

- Звезда в списке показывает сохранённое отслеживание; карточка открывается широкой боковой панелью.
- Карточка показывает упоминания, долю голоса, число вопросов, модели, намерения и вопросы, где конкурент назван без бренда, по подтверждённому снимку.
- График использует до 20 подтверждённых сопоставимых замеров; неподтверждённые цитаты и отсутствующая средняя позиция обозначены как отсутствие данных.
- Проверки: PHPUnit 5 тестов / 154 утверждения (сценарий, права, бренды, две ошибки ввода), Playwright 3 сценария (свой и сохранённый E8-20L), TypeScript, ESLint, Pint; генерация типов без изменений.
- Скриншоты: `.local/screenshots/sp-e8-20o/companies.png`, `company-card.png` (светлая тема, 1440).
