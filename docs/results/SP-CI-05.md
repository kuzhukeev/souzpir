# SP-CI-05 — балансировка browser shards

## Что сделано

- Исходный зелёный main CI #439: browser (1)/(2)/(3) — 216/303/170 с; ранее владелец наблюдал 244/306/198 с.
- В `browser-smoke.sh` каждый CI job сначала получает штатные списки трёх Playwright shard, затем переносит 29 тестов `E8-02/pages.spec.ts` из shard 2 в shard 3.
- Выборка содержит каждый тест ровно один раз; при изменении распределения без этого файла штатные списки сохраняются. Окружение discovery совпадает с окружением запуска.
- Локальный список: 183/184/125 → 183/155/154 теста. Зелёный CI ветки #460: browser (1)/(2)/(3) — 285/222/252 с, разброс сократился с 133 до 63 с; полный прогон — 545 с.

## Выполненная проверка

- `bash -n scripts/ci/browser-smoke.sh` прошёл.
- Playwright `--list --test-list` подтвердил 155 и 154 теста во втором и третьем shard; сравнение списков показало отсутствие потерь и дублей.
- Никакие тесты и код приложения не менялись.
