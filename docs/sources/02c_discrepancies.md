# 02c. Реестр расхождений: ТЗ ↔ макеты ↔ код

Статусы: **подтверждено** — расхождение видно в файле макета и в тексте ТЗ/коде; **предположение** — вывод из косвенных признаков; **требует уточнения** — нужен ответ заказчика. Решение по умолчанию следует приоритету источников: указания пользователя → ТЗ → код → макеты.

Формат: ID · экран · требование ТЗ (раздел/строка) · макет (папка/файл, элемент) · что отличается · влияние · решение · статус · задача backlog, которая реализует решение (`10_backlog.md`).
