# 06. Дизайн-система, макеты и адаптивность

Эталон общих элементов — папка 13 (`completed-under-50mb/13/…S-1.2-attention-*.webp`): тёплый светлый фон, левое меню 260 px и шапка 64 px, тёмно-синяя типографика, синие линейные иконки, зелёные кнопки действий, белые карточки с мягкой тенью. Проверено: эти признаки присутствуют на большинстве макетов (журнал `02b`), отклонения перечислены в `02c` (R-S-06, R-S-07, R-V-08, R-V-16, R-D-02). Пофайловая раскладка — `06b_screen_layouts.md`.

## 1. Токены (Tailwind 4, `@theme`)

Значения ниже — из ТЗ §1.3 там, где они заданы (цвета тем), и из макетов папки 13 для остального (**предположение**, уточняется при пиксельной сверке в задаче F-01).

```css
@theme {
  --color-bg: #F6F3EE;            /* тёплый фон (папка 13) */
  --color-surface: #FFFFFF;
  --color-border: #E6E1D8;
  --color-ink: #10264A;           /* тёмно-синий текст */
  --color-ink-muted: #5B6B85;
  --color-icon: #2F6FE4;          /* синие линейные иконки */
  --color-action: #1F9D55;        /* зелёные действия */
  --color-action-hover: #178447;
  --color-danger: #D64545; --color-warning: #E0A100; --color-info: #2F6FE4; --color-success: #1F9D55;
  --radius-card: 16px; --radius-control: 10px;
  --shadow-card: 0 1px 2px rgb(16 38 74 / .06), 0 8px 24px rgb(16 38 74 / .06);
  --font-sans: "Manrope", system-ui, sans-serif;   /* ТЗ §1.2 */
  --spacing-sidebar: 260px; --spacing-header: 64px;
}
```
Темы бренда (ТЗ §1.3): `[data-theme=confectionery|pyro|neutral]` переопределяют `--color-action`, `--color-icon`, акцент шапки и логотип-плейсхолдер; текст и фон не меняются (контраст сохраняется). Переключение темы — атрибут на `<html>` из shared props.

Типографика: H1 24/32 semibold, H2 18/26, body 14/20, caption 12/16; числа в KPI 28/34. Иконки — только `lucide-react`, 20 px, stroke 1.75, цвет `--color-icon` (в кнопках — наследуют).

## 2. Каркас

- Сайдбар 260 px фиксированный: логотип бренда + название, переключатель бренда (S-2.x), блок модуля с 11 пунктами (ТЗ §1.1), внизу — промо-карта (если включена, R-S-12) и пользователь. Состояния пункта: default / hover (фон `--color-surface`) / active (зелёная полоса слева + зелёный текст, как в папке 13) / disabled («Скоро», серый, бейдж). Сворачивание до 72 px (иконки) — персистентная настройка.
- Шапка 64 px: хлебные крошки (единый компонент, R-S-06), поиск (где предусмотрен ТЗ), колокольчик с счётчиком, меню пользователя.
- Основная область: `padding 24px`, занимает всю ширину после сайдбара; **не масштабируется пропорционально**. Внутренние сетки — 12 колонок с `gap 24px`. Формы — `max-width 880px` (настройки) / 760 px (мастера), выровнены влево. Ориентиры по использованию ширины — Carrot quest и Roistat (плотные таблицы, фильтры в одну строку, правые панели).
- Брейкпоинты: ≥1440 (широкий), 1024–1439 (средний), 768–1023 (планшет: сайдбар сворачивается в иконки), <768 (мобильный: сайдбар — drawer, шапка с «гамбургером», таблицы → карточки).

## 3. Компоненты (ТЗ §1.4 — 16 компонентов, расширено)

Button (primary зелёная / secondary белая с рамкой / ghost / danger; размеры md 40 px, sm 32 px; loading), Input/Textarea/Select/Combobox/DatePicker/TimePicker, Checkbox/Switch/Radio, Chips (теги, тон персонажа), Tabs (подчёркивание), SegmentedControl (режимы), Card, KpiCard (значение, дельта, подпись), DataTable (сортировка, закреплённая первая колонка, строки-карточки на мобильном, пустое состояние), FilterBar, Badge (словарь Приложения Б: стадии, исходы, приоритеты, готовность «Скоро»), Drawer (правый, 480/640 px), Modal (confirm, с вводом подтверждения), Toast, EmptyState (иконка, текст, CTA), Skeleton, StepProgress (единый для мастеров, R-V-08), Breadcrumbs, Avatar (инициалы, R-S-07), Timeline (лента сообщений с мета-панелью Guard/Goal), CodeBlock (сниппет виджета с копированием), ProgressBar (лимиты), Tooltip, Pagination, FileDrop.

Состояния каждого компонента: default, hover, focus-visible (кольцо 2 px `--color-icon`), disabled, error, loading. Состояния страницы: loading (skeleton), empty, error (с «Повторить» — зелёная кнопка, R-D-02), partial (данные частично).

## 4. Доступность
Контраст текста ≥ 4.5:1 (проверка токенов тем), клавиатурная навигация по всем интерактивам, `aria-*` у табов/дроверов (Radix), фокус возвращается в точку открытия, формы с `label`/`aria-describedby`, живые области (`aria-live=polite`) для ленты диалога, уменьшение анимаций по `prefers-reduced-motion`.

## 6. Адаптация макетов к ширине — правила
- Макеты нарисованы под ~1440 px с фиксированным контентом; при 1920 px контент заполняет область (таблицы, графики, колонки), а не центрируется с пустыми полями — исключение формы и мастера.
- Три стиля вкладок/прогресса в макетах сводятся к одному компоненту.
- Мобильные макеты (S-0.x, D-2.3/2.4, V-5.P) используются как ориентир; где мобильного макета нет — правила §2.
- Публичный отчёт V-5.P: контейнер 1200 px, печатная версия.

## 7. Приёмка визуала
Для каждого экрана: скриншот при 1440 рядом с макетом (структура, цвета, иконки, состояния), проверка 1920 (заполнение ширины), 1024 (сворачивание), 390 (мобильный), a11y (axe без критичных), состояния empty/error/loading присутствуют, если есть в ТЗ/макете.
