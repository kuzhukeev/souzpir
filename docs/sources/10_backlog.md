# 10. Детализированный backlog для Codex

Порядок: фундамент и контракты → перенос и проверка логики → настройки и интерфейсы → сквозные сценарии. Объём: S (≤ 0.5 дня), M (1–2 дня), L (3–5 дней), XL (> 5, дробится при реализации на подзадачи с тем же ID-префиксом).

**Общий Definition of Done (для всех задач):** код + миграции + тесты из колонки «Приёмка/тесты» зелёные в CI; `04c` путь для каждой настройки проходит целиком (UI → валидация → Action → хранение → применение → права → тест); аудит-лог пишется для мутаций; экран проверен на 1440/1024/390 и axe; строки UI — на русском через i18n; нет захардкоженных цен/лимитов; документация задачи (README раздела) обновлена; задача не считается выполненной при статичном интерфейсе или пустом API.

Колонка «Параллельность» — с какими задачами можно вести одновременно; «Конфликты» — задачи, трогающие те же файлы (вести последовательно).
