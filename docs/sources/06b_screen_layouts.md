# 06b. Раскладки по экранам: макет → воспроизведение → адаптация

Для каждого экрана ТЗ: файлы макета, паттерн раскладки (`06_design_system_and_layouts.md` §5), что воспроизводится из макета (визуальный характер и состав элементов), что адаптируется (ширина, адаптивность, уточнения по ТЗ и `02c`), ответственная задача backlog (индекс в конце `10_backlog.md`). Паттерн назначен по описанию экрана в ТЗ (разделы S/V/D) и сверен с макетом; содержимое экрана определяется ТЗ — при конфликте реализуется ТЗ. Макеты не оставлены без просмотра: 303 файла проверены по содержимому, 5 — на уровне композиции (`00_inventory_and_coverage.md`).

## Паттерны

| Паттерн | Воспроизводится | Адаптируется |
|---|---|---|
| Auth-карточка | Центрированная карточка ≤ 440 px на тёплом фоне, логотип, поля, кнопка primary, ссылки; состояния ошибок/загрузки как в `*-states` | Карточка не растягивается; на мобильном — полная ширина с отступом 16 px. |
| Мастер (шаги) | Индикатор шагов `StepProgress`, одна карточка шага, кнопки «Назад/Далее» внизу, подсказки справа | Карточка формы max-width 760 px по центру основной области; боковая подсказка уходит под форму при < 1024 px. |
| Дашборд | Шапка с селектором периода, ряд KPI-карточек со спарклайнами, ряды графиков/таблиц по ТЗ, пустые состояния | Сетка 4→2→1 колонки по ширине (1440/1024/390); карточки тянутся на всю ширину основной области. |
| Плитки/карточки | Сетка карточек-плиток (модуль, канал, раздел, компонент) с иконкой, статусом, 1–2 действиями; ниже — вспомогательный список по ТЗ | Сетка 3→2→1 колонки; карточка min-width 280 px; действия внутри карточки не выносятся в меню «⋮» на десктопе. |
| Список/таблица | Панель фильтров, таблица `DataTable` с действиями «⋮», пагинация, пустое состояние `EmptyState` | Таблица занимает всю ширину; при нехватке — горизонтальный скролл с закреплённой первой колонкой; на мобильном — карточки строк. |
| Канбан/таблица | Переключатель «Канбан / Таблица», три колонки Новые · В работе · Сделано с карточками, drawer по клику | Колонки равной ширины с внутренним скроллом; на < 1024 px — только табличный вид с группировкой по статусу. |
| Детальная (2–3 колонки) | Левая колонка список/лента, центр — содержимое, правая — карточка сущности (слоты, задачи, действия) | Колонки по доле ширины (минимумы 320/420 px); на < 1024 px правая колонка — drawer, на мобильном — поэкранная навигация. |
| Форма настроек | Карточки-секции с полями, переключателями, кнопка «Сохранить» в sticky-футере, подсказки справа | Форма max-width 880 px, выровнена влево в основной области; в широких экранах справа — пояснения. |
| Настройки + список | Верх — карточка-форма настроек источника/подключения; ниже — таблица объектов (ключи, позиции, документы, архивы, обращения) с действиями | Форма max-width 880 px; таблица на всю ширину; на мобильном — карточки строк. |
| Вкладки + содержимое | `Tabs` под заголовком страницы, содержимое по типу вкладки (форма, таблица, график) | Как у типа содержимого вкладки; вкладки на мобильном — горизонтальный скролл. |
| Отчёт | Шапка с метриками, секции с таблицами/графиками, «Поделиться»/«PDF» | Полная ширина; таблицы с горизонтальным скроллом; печатная версия для PDF. |
| Публичная страница | Без сайдбара, шапка с логотипом бренда, секции отчёта | Контейнер max-width 1200 px; мобильный — одна колонка. |
| Заглушка «Скоро» | Иконка, заголовок, текст «что понадобится», кнопка «Оставить заявку»/«Сообщить, когда появится» | По центру основной области; поля B-уровня (если есть) — отдельной карточкой над заглушкой. |
| Модалка / drawer | Открывается поверх родительского экрана: форма или карточка с заголовком, телом и действиями внизу | Модалка 480–640 px по центру; drawer 640 px справа; на мобильном — полноэкранный лист. |
