# 02. Матрица соответствия экранов: ТЗ ↔ макеты ↔ код

Источник строк — все экраны ТЗ (`src/tz.md`, разделы 2–4; номер строки ТЗ указан). Колонка «Макеты» — файлы из `completed-under-50mb/<папка>/`. Колонка «Проверка»: «проверено» = изображение открыто, текст прочитан; «только композиция» = у части файлов экрана (мобильные/skeleton) мелкий текст читался частично — требует ручной проверки подписей при реализации. Колонка «Состав…» — выдержка из журнала просмотра (`02b_mockup_journal.md`), где каждый файл описан отдельно. Формальные расхождения с ID — в `02c_discrepancies.md`. Задачи backlog, реализующие экран, — в `10_backlog.md` (колонка «Ссылки»).

Легенда готовности — ТЗ §0.4 (A/B/C/D). «v2» — элементы, которые ТЗ относит к C и которые в v1 показываются только для чтения.
