# Изолированная проверка процессов очереди

Только отдельный локальный PostgreSQL с тестовой БД `souzpir_test_*`, отдельной ролью и синтетическими заданиями. Создать БД и применить миграции оператор должен заранее. Не направлять эти команды на рабочую очередь; сетевой доступ ограничен loopback. Пароль тестовой роли при необходимости задаётся через `DB_PASSWORD` в текущем процессе.

В PowerShell из своего worktree, подставив собственные путь PHP, БД, порт и роль:

```powershell
$runtimeArgs = @{ Php = 'C:\OSPanel\modules\PHP-8.4\php.exe'; Database = 'souzpir_test_example'; Port = 55930; User = 'example_test' }
.\scripts\runtime\test-runtime.ps1 -Action status @runtimeArgs
.\scripts\runtime\test-runtime.ps1 -Action worker-once @runtimeArgs
.\scripts\runtime\test-runtime.ps1 -Action scheduler-once @runtimeArgs
```

`worker-once` обрабатывает не более одного задания `souzpir-test-e007:default` и сам завершается; `scheduler-once` выполняет один проход при отключённой регистрации расписаний. `status` показывает агрегаты разрешённых тестовых очередей. Постоянный worker и планировщик не запускаются; принудительная остановка выполняется Ctrl+C в окне команды. Команды задают testing, fake-драйверы, отключают внешнюю доставку и подключаются только к `127.0.0.1`. Не записывайте реальные данные и секреты в тестовые задания: стандартный worker может выводить имена заданий и ошибки.

Проверка настоящих расписаний, их идемпотентности и безопасного журналирования ошибок потребует отдельного этапа; включать рабочие процессы по этой инструкции нельзя.

## Автоматическая проверка постоянных процессов

`tests/Feature/Runtime/PersistentProcessesTest.php` в Linux CI запускает постоянный worker с отдельной временной таблицей и синтетическим заданием, затем проверяет его остановку. Scheduler выполняет пустое тестовое расписание при отключённой регистрации доменных расписаний и также останавливается. На Windows обе проверки явно пропускаются. Доставка остаётся отключённой; настоящие расписания и безопасные логи этим тестом не проверяются.
