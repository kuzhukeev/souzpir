# Фронтенд-контракт и генерация

`App\Data\Shared\SharedPropsV1` и связанные Laravel Data DTO задают форму внутренних Inertia props. В `HandleInertiaRequests` идентификаторы, имя и email пользователя передаются явной проекцией без скрытых полей модели. Organization, brand, brands и can берутся из зарегистрированных feature contributors; tenant-зависимые closures разрешаются после `ResolveTenant`. Публичный SSR/отчёт не использует web group и не получает эти props. Локальные preview/dev остаются анонимными и демонстрационными.

До подключения реальных источников `unread: null` и `modules.seller/vision: null` означают «данные недоступны»: эти значения не следует показывать как ноль или отключённую подписку. Реальный unread должен предоставлять соответствующий contributor уведомлений; включённость модулей — источник конфигурации модулей. Это временное уточнение к более раннему non-null примеру в `core.md`; изменение общего контракта выполняет интегратор.

Права берутся из E0-03; публичный `usePermissions` следует его правилам и считает неизвестное значение ложным. Права в props — подсказка для интерфейса, каждое действие всё равно авторизуется серверной политикой. Весь массив разрешённых ключей генерируется из `config/permissions.php`.

`translations` — плоская карта из `FeatureRegistry::translations()`, ключи вида `Tenancy/Access/messages.invalid_role`; дубли и нестроковые значения отвергает loader. `useTranslation()` и `createTranslator()` принимают только сгенерированные ключи и заменяют `:name` без HTML-интерпретации. Вставлять текст как обычный текст React; plural rules и дополнительные языки в v1 не реализованы.

`ziggy` содержит URL, именованные маршруты и объект location без query string; динамические `generated::*` исключены. `resources/js/types/generated/routes.d.ts` — декларации Ziggy для типизированного `route()` из `ziggy-js` со строгой проверкой имён. Сами URL не являются разрешением доступа.

## Генерация и CI

Из корня проекта при установленных PHP-зависимостях:

```text
php scripts/generate-types/generate.php
php scripts/generate-types/generate.php --check
```

Генератор сканирует `app/` и преобразует только явно отмеченные `#[TypeScript]` Laravel Data DTO и enum через Spatie transformer 3; `mixed` в TS становится `unknown`. Он также формирует типы разрешений и ключей переводов, а маршруты — через Ziggy. Сгенерированные файлы принадлежат интегратору и не редактируются руками. При добавлении DTO, route, permission или перевода требуется повторная генерация и включение результата в интеграционный коммит. PHPUnit запускает `--check`; при расхождении CI завершается ошибкой. Генерация не обращается к данным пользователей.

Inertia хранит shared props в factory; middleware очищает их в начале и в `finally` после web-запроса, чтобы следующий публичный ответ того же процесса не получил cabinet props. Проверены последовательные запросы, редирект и исключение. Параллельное выполнение запросов в одном процессе и поддержка Octane в рамках этой задачи не проверялись.
